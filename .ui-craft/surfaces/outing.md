# Short rescue outing

2026-11-16. The user approved a short combined loop: random environment puzzle OR cleanup, followed by turn-based trust negotiation at the animal, then return to station. Target a few minutes, not a difficult puzzle campaign.

- New /outing.html preserves the old prototypes. Start immediately in a random approach branch. Options allow repeatable branch/profile and direct negotiation testing.
- Reuse LabScene, pathfinding and existing animal SVGs. Approach completion means reaching the animal, never automatic rescue. Food is reserved for negotiation.
- Puzzle variations are mirrored known-solvable templates, not an unlimited procedural generator. Cleanup varies debris type/coverage with a bounded accessible frontier. No untested claim of endless content.
- Negotiation uses one visible alert value, three visible distances and readable posture/cues. Four contextual actions, deterministic consequences, disabled during short reaction resolution. No hidden catch roll, no irreversible failure, no combat injuries.
- Keep established mint/coral palette, rounded Chinese display face, stable portrait scene, icon-led buttons, 44px targets. The signature is a large expressive animal that changes pose and proximity in response to each turn.
- Success leads to a lightweight station interaction, not the old care save. No account, backend, monetization or animal quality tiers.
