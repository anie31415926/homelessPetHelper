# 开路小游戏接入 Main 闭环方案

日期：2026-11-20。任务：[提交与开路核对](协作任务/20261120-Main提交与开路核对-01a1f74d.md)。

## 已确认方向与实施前缺口（现已补齐）

用户指出进入逆塔防前应先经历开路小游戏二选一。[总纲](游戏设计总纲.md#b-外出与寻路)已有“场景解谜 / 清理开路随机二选一、通路后救助”的方向；安全通道连通即可，不要求清空全部杂物。救助后半段承接当前 Main 的猫狗逆塔防，不退回旧回合交涉。

实施前 MainLoopPresenter.EnterSiege 调用 GameLoopSession.TryEnterRouteFreeRescue，Unity尚无开路规则和面板。现已新增独立规则、静态Prefab和实际完成门槛，Main改走TryStartOpeningRoute → TryEnterRescueAfterOpening；旧route-free API保留用于确实无开路的流程，并拒绝绕过正在进行的开路。HTML原型位于src/outing与src/playlab，试做授权不等于正式数值定案。

OutingCoordinator 已有 TryStartOpeningRoute、TryAdvanceField 和未解决回站结算，OutingSession 已记录 HasOpenedRoute；这些是可复用的阶段底座，不是已经验证实际道路连通的小游戏。

## 首版操作与授权（已确认最小试做）

2026-11-20用户明确允许按HTML原型实现最小版，并要求遵守代码与工程规范。以src/outing的开路完成语义与src/playlab的挪箱、桥、撤回、工具清理为试做依据；不包含自动捕获/引导或旧交涉。下列样例布局/工作量为本次获准试做，不升级为最终平衡。箱子按原型沿直线滑动且全程不可穿越阻挡，允许点选落点或拖放；不擅自限制为只能移动一格。

- 每次外出固定抽取一种开路方式，随机二选一；打开暂停或重建面板不重新抽取。猫狗都可搭配两种方式，不把动物品种写死为开路分支。
- 场景解谜：挪开箱子、在允许的位置搭桥，让出发口到动物处有实际连通道路。点选箱子后选同一行/列的合法落点，搭桥选允许缺口；非法操作给原因且不改变状态，支持撤回一步以避免软锁。不新增消耗品或失败惩罚。
- 清理开路：选择与杂物对应的工具，拖动清理；只允许清理从入口可到达区域边缘的障碍，避免隔墙清理。工具不匹配、未够到的操作不扣除进度；只需清出到动物身边的安全通道，不要求全部清空。不照搬站内洗梳的全身比例门槛。
- 两种首版均用无图片白板和各一个可解样例，布局、杂物类型、工作量等进入配置，文案进入文本表。先验证操作/成功判定，不批量生图或扩展无限随机关卡。

具体例子：解谜选择挡路箱子→合法挪开→选桥位搭桥→规则检查连通→允许进入逆塔防；放到被占用位置拒绝并保留当前棋盘，可撤回重做。清理先选对应工具→清入口边缘一块→继续向里清出通道→规则检查连通→允许进入逆塔防；选错工具或触及封闭区域提示原因并保留进度。首版不设资源耗尽，因此不会因工具用完卡死。

## 接线与状态所有权

目标链路：救助站 → 城市地图选点并实际出发 → 固定本次开路分支与关卡 → 道路真实连通 → 现有猫狗逆塔防 → 回站 → 检查/护理 → 站内检查点保存。

1. Game 装配层固定 outing 身份、种子、关卡身份和当前求助；开路规则只持有场地、障碍和操作状态，不创建第二只动物、不修改站内居民。随机源显式可控；当前地图 seed 是固定配置，接入时要避免每次新外出永远同一分支，同时确保同次会话不重抽。
2. 新增纯 C# 开路规则，实际连通以四邻域路径校验为准。表现只提交操作意图，不能用“我完成了”的布尔值或跳过按钮放行。
3. Session 持有开路实例的生命周期。实际开始时调用 TryStartOpeningRoute；进入逆塔防前核对当前会话、关卡/实例、阶段、暂停和规则完成状态，再提交 ApproachCompleted 并绑定既有 SiegeRescueActivity。拒绝不得先推进 Flow、绑定半成品或收时间。旧 route-free API 保留给确实无开路的调用者，Main 不再使用它。
4. 使用静态 Prefab、显式序列化绑定和既有安全区规范。新增专用开路面板，MainGameRoot/Presenter 显式装配；保留站内/地图/Siege 已有图片与音频绑定，不重复运行旧创建工具覆盖已有资产。新资源和目录配齐 meta。
5. 暂停、失焦、切后台冻结输入与进行中的清理；恢复不补隐藏时间。完成后旧指针、旧回调、重复点击不能再次推进阶段；回站/销毁释放操作与订阅，下次外出创建新实例。
6. 主动中止开路沿用 TryReturnUnresolved：求助重新参与世界变化，按已到阶段结算一次。进入逆塔防后继续沿用现有成功/未解决回站，不把通路连通当救助成功。
7. 延用站内检查点存档边界：外出中退出回最后站内检查点，不新增开路/战斗中途存档，不迁移当前 main.station v1 结构。恢复不重放外出、重复入站或补离线时间。若后续要求保留跨次地点的局部清路成果，先确定与四档杂乱的映射及恢复规则，另扩存档；不默默全清地图。

## 时间与兼容

现有配置增量为探索5、开路10、逆塔防阶段15、交接5游戏分钟，属于已有试做值，不是正式平衡。当前 route-free 完整救助为25分钟；实际经历开路后应为35分钟。开地图后取消仍为0，开始开路后中止按阶段为15，进入逆塔防后未完成返回为30，完整回站35；最终以现有 OutingTimePolicy 和已到达阶段计算，禁止 UI 自行再累加一遍。

既有历史存档中的世界分钟不回填，已救猫狗不重刷，不把此前缺失开路追算给玩家；新外出才使用新链路。需要核对满员、主人直接交接和无求助探索等已有分支，避免把非普通救助错误强制改成逆塔防。

## 实现与试玩入口

打开[Main场景](../unity/HomelessPetHelper/Assets/Scenes/Main.unity)，从站内点击外出、地图选求助点并出发，就会随机进入一种开路；本次外出分支固定，猫狗均可搭配任意一种。当前每种各一个7列8行样例，普通新外出使用新种子，自动化通过显式随机依赖控制输入。

- 挪箱搭桥：选中箱子，再点同一行/列的合法落点，也可拖动；选“搭桥”后点水沟允许位置。可用“撤回一步”。样例解法：将上方通道箱子向下一格、再向左一格，随后在右侧水沟搭桥。
- 清理杂物：选拾杂物/除杂草/洗泥斑，按住并在棋盘上拖动。绿色区域代表入口可达；先清其相邻阻挡，再向里推进。泥斑不挡路，可保留边缘杂物；清出通道即可。
- 未连通时“走近它·开始救助”禁用；连通后点击才进入原猫狗逆塔防。开路连通不会自动入站或代替战斗胜利。
- 暂停/失焦/后台停止接触，回前台后手动继续；取消拖拽、关闭面板、回站与重开均释放指针。保留原“外出中退出恢复最后站内检查点”的提示和行为。

规则位于Assets/Scripts/Modules/Approach，布局/端点/障碍/工作量在Assets/Settings/Game/ApproachConfig.json，玩家文字在同目录ApproachText.json。静态资源位于Assets/Prefabs/Panels/Panel_Approach.prefab；后续在Prefab Mode编辑。tools/unity.ps1的ApproachAssets仅用于隔离创作，已有面板不重建，也不运行旧Main创建工具。
