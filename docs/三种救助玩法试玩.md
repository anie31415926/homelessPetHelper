# 三种救助玩法试玩

日期：2026-11-16。阶段：玩法比较，不是最终玩法定案。

## 试玩入口

启动 `npm run dev` 后访问 `/playlab.html`。默认直接进入场景解谜，顶部可随时切换三种玩法。

- `/playlab.html?mode=puzzle`：场景解谜。
- `/playlab.html?mode=cleanup`：清理开路。
- `/playlab.html?mode=guide`：引导回家。
- `/rescue.html`：之前的迷宫与网兜原型，独立保留。
- `/`：最初的养宠原型，独立保留。

三种新试玩均用 2D 表现，复用同一套动物美术和竖屏界面，减少美术精度对玩法判断的干扰。没有新增 3D 庭院版本。

## A. 场景解谜：雨后的小仓库

### 验证什么

观察地形、搬移障碍、选择过河位置，再让动物自己走到安全点，是否比固定出网更有“我帮到了它”的成就感？

### 可操作内容

- 选中木箱后，拖到同一行 / 列的空地，或使用下方四方向按钮逐格挪动。
- 木箱不能穿墙、过水、重叠或压到动物，也不能堵住救援箱。
- 木板工具可在左、右两个虚线桥位之间选择。两侧障碍不同，不是任意点一下都能完成。
- 食物工具可在可走地面上放置食物，包括救援箱位置。
- 小猫只有在路线真正连通时才会出发；A* 计算实际路线，不是固定动作序列。
- 撤销可恢复箱子、木板、食物与动物位置，避免走错后只能重开。
- 小猫抵达救援箱后完成。移动途中暂不能改路，以免道具穿过正在行走的动物。
- 键盘可 Tab 到木箱，用方向键挪动；地面、桥位和工具支持键盘操作。

### 当前边界

一张网格解谜关，两只木箱，一块可调整的木板，无刚体物理、跳跃或复杂工具背包。

## B. 清理开路：长满荒草的小院

### 验证什么

连续清理的触感、从杂乱到干净的变化，以及清理过程中逐步发现动物，能否共同构成主要乐趣？

### 可操作内容

- 捡拾处理瓶子与杂物，修剪处理杂草，冲洗处理泥斑。
- 按住场景并移动工具，按持续接触时间清理，不按鼠标事件数量计算。
- 清理中的杂物会逐渐变小、变淡；完成后出现短暂清理反馈。
- 只能处理从门口可到达的区域及相邻杂物，不能隔着整片杂物直接清到后院。
- 两只动物藏在院子后面；剪掉遮挡并打通路径后，它们会露出来。
- 可直接点动物或按“接回”，让它沿已清出的通道走回救援箱。
- 两只动物都安全抵达即完成，不强迫清掉所有泥斑。
- 也可 Tab 到具体杂物，按 Enter / 空格进行当前工具的一次清理。

### 当前边界

32 处杂物，三种工具，两只动物。一关可有不同开路顺序，但不是随机生成庭院，也没有升级工具、装修或经营系统。

## C. 引导回家：河畔的弯弯小路

### 验证什么

动物有自己的注意力、需要玩家保持合适距离和步速，是否能带来更强的陪伴感，而不是单纯增加等待？

### 可操作内容

- 点地面让救助员走过去，或使用下方方向键；电脑支持方向键 / WASD。
- 救助员和小狗都沿可通行路线绕开长椅和花丛。
- 玩具是开关，开启后会吸引附近、逐渐放松的小狗。
- 默认慢走；关闭后速度更快，但贴近时冲得太急会让小狗紧张退开。
- 离得太远，小狗会停下来；没有被玩具吸引时，附近的球也可能让它分心。
- 食物放在救助员脚边，可帮助吸引和安抚。每轮三份，但不用食物也能完成。
- 把逐渐安心的小狗引到救援箱附近，它会自己走进去。
- 没有失败倒计时或不可逆的信任损失，可以停下来重新接近。

### 当前边界

一只小狗，一处玩具分心点，一段带障碍的路线。行为是清晰的状态规则，不是完整动物 AI，也不表示性格养成已完成。

## 公共行为

- 顶部切换保留本页各关进度，未选中的关卡停止推进。
- 暂停会同时停止计时、清理、动物移动与信任变化，切后台也不推进。
- 重新开始只重置当前关，不清除其他玩法进度。
- 成功后可选“不太想 / 还行 / 想再玩”，不评价也能继续。
- 反馈仅保存在当前浏览器的 `fluffy-rescue-lab-v1`，不上传，不读取或修改原养宠存档。
- 关卡进度刷新后重置，偏好反馈保留。存储受限时仍可正常试玩。
- 减少动态效果时取消走路摇晃等装饰动画，保留必要的移动与操作反馈。

## 比较时看什么

1. 不看操作次数谁更少：三种玩法动作单位不同，不能把数字直接当成绩比较。
2. 哪种过程本身有趣，而不是只想赶紧结束？
3. 哪种更像在救助一只有意愿的动物，而不是清障或搬箱子？
4. 哪种愿意立刻再来一关？
5. 觉得不好玩时，是核心规则不喜欢，还是手感、提示、速度还不够好？

这些问题待用户实际试玩后填写。自动化通关通过只验证流程与约束，不证明玩法好玩。
