# 战场对象复用与视觉主次

2026-11-24，用户要求核对对象池，并让逆塔防、清障解谜的游玩对象成为主体，场地分隔和装饰退为次要。

## 对象复用现状与补充

- 现有 `SiegeCellPool` 已复用手牌和试验列表Cell，容量受手牌/列表上限控制，面板释放时停用输入并销毁池内控件。
- 战场单位、塔、弹道和区域由同一个uGUI网格绘制，不为每个实体创建GameObject，因此也不存在逐单位Instantiate/Destroy的热点。业务单位仍是轻量C#记录；当前没有为它们额外建立GameObject池。
- 清障消散/放置动效已有16个结构体槽位，表现快照缓冲继续复用。
- 本轮新增会话状态内的 `SiegeEffectPool`：弹道、合成、拍击、横扫、维修、护持等效果统一租用记录。按需增长，活动效果上限192，过期归还；满时回收最旧效果并保留新效果的稳定顺序。归还清除所有坐标、时间、半径、类型和图标字段，防止残留。
- 池无静态持有，随战斗状态结束释放；Clone独立复制活动记录且不共享空闲池。最多保留本场效果所需的有界记录，不为追求零GC无限预热。连续100轮×192个效果身份集合复用由专项测试检查；不宣称整个战斗零分配。

## 视觉调整

复用原图集、材质与布局，无新增图片或资源导入。

- 分隔树篱从1.15格降至0.68格，降低对比和不透明度，停止纯装饰摆动；保留淡色连接底纹，使边界可识别。无图集的后备几何也同步减体量、减对比。
- 碎石从0.35格降至0.22格并淡化；解谜水域仍保留辨识度。
- 木箱由0.85格提升至1.02格，清理杂物及消散效果由0.9格提升至1.02格，桥保留完整表现；操作物保持原色和自身动效。
- Main战场单位/塔/拖动预览/搬运物/血条共用放大的PropScale，最小屏幕尺度从0.6提高至1.35；不改变规则位置、范围、伤害和占格。选中/换路线路更细、更淡。
- 目标动物在开路和战斗均放大1.6倍，保留脚下锚点、身份和动作时钟。
- 点击塔使用格子塔实际显示坐标，过滤已毁塔；此前检测沿用旧路线投影，会造成自由格子塔的可见位置和点击位置不一致。渲染压力用例补实际点击验证。
