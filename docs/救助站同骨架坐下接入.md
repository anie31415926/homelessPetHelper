# 救助站同骨架坐下接入

2026-11-24。用户反馈拉取后仍是旧站/坐图片模式，并要求坐下更流畅。

## 根因与实现

原救助站 `StationHabitatRenderer` 调 `PetMotionPlayer` 的 4 号坐姿，站/坐/卧各用一组图网格；此前用户认可的短腿臀尾触地版仍仅在浏览器。现站内 actor 改用 `StationCatPlayer`，36骨（30运动骨+6美术锚点）、15个共用蒙皮附件/同一8层atlas。动作采样只写同一骨架，不切整姿态图、不透明淡入或伸缩腿骨。

浏览器的萌系版本同步改为形状保持三次Hermite曲线：相邻关键段共享切线，下降不在每个关键点停车，站立/坐稳端点收速。坐下时长当前为1秒（首次接入为2.4秒，按用户试玩反馈缩短）；原脸/短腿比例和认可端点、臀尾连接与接地保留。步行重用同骨架的对角小步；离线IK烘焙原生局部位置/四元数曲线，运行时没有IK求解或序列帧。

站内坐稳保持终态；点选保留当前姿势时间，起身原地1.6秒完成再平移，暂停不推进展示时间。Unity蒙皮缓冲按帧刷新，采样后立即冻结时下一帧补一次render，以呈现最终姿势。RawImage朝向按源坐标转换，镜头/地面全动作固定。

## 生成与编辑

从仓库根运行 `node tools/pet-sit-unity.mjs`，源数据写入 `art-source/pet-sit-chibi-20261123/unity-export.json`，`--check`逐字节核对；同时生成站内专项fixtures。IK使用Three官方实现，仅作者阶段运行。曲线以60Hz采样，误差0.00003的线性简化，常量兄弟轴保留，避免Unity矢量/四元数组采样丢失。

将数据放隔离Unity工程的 `PetSitSource/unity-export.json`，运行 `HomelessPetHelper.Editor.StationHabitat.StationCatAssets.Apply`。工具只增量编辑已保存的actor Prefab与本批mesh/clip/material，不重建站内面板。新asset/meta/actor须整体保留；正式编辑仍走Prefab Mode。只改坐下时序时可运行 `StationCatAssets.UpdateSitClip`，保留actor、网格与其他clip不重建。

## 资源与边界

复用认可atlas（344×712 /169040bytes），Unity导入明确Texture2D、1024上限、不读写、无mip、无压缩、Bilinear/Clamp。源图保留供浏览器，唯一台账条目转temporary/first-play，因为Main已有静态引用；这不是按需下载或正式来源许可验收。

每只猫继续拥有512²离屏目标，基础颜色缓冲约1MiB；rig/纹理/曲线共享。当前15个附件/12856顶点，单atlas基础RGBA32约957KiB；源PNG字节与导入像素量、目标包体分开。测试记录Editor CPU/分配，不宣称微信真机性能已验收。

本次没有同骨架侧卧的认可原型，因此原Lie休息阶段暂用同骨架坐稳姿势承接，保留原休息点/时长与业务。狗保持原图。完整呼吸/表情、侧卧与正式行走精修后续处理，不回退旧坐卧换图。动物身份/脏污/护理与存档不受展示动作推进。
