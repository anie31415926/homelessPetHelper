# 实时资源救助战斗

2026-11-24，已按用户确认接入 Main 正式救助流程。己方采用自由坐标部署，守方按格占位；统一实时推进，保留菜单、教学和后台暂停。历史独立回合试验入口和旧重放算法保留，不将其执行按钮规则套入 Main。

## 操作与规则

- 拖动手牌到己方合法范围，松手立即扣费、出兵并补牌；也可选牌后点击落点。取消战斗中的执行按钮，结束后保留回站操作。
- 单位从实际落点移动到最近开放路线，随后沿路线前进；攻击、显示和存档共用实际坐标。部署范围按起终点方向裁切，并映射到当前镜头；越界、资源不足、暂停、结束或达到单位上限时不生成、不扣费。
- 对手独立积累资源，选择合法空格扣费建造。存活及建造中的塔均占格，摧毁后可重新使用；不依赖旧固定塔位。
- 合成选满材料后立即尝试，换路选择目的路线后立即尝试；旧弃牌操作在实时模式停用。教学改为部署及换路两步，旧回合暂停选项隐藏。
- 救助目标、同一个体身份、脏污及回站连续状态保留。

## 性能与保存

部署预览直接只读校验，提交在当前状态原子校验后执行，移除预览/落牌时的整场复制。界面使用独立、可复用的表现缓冲，不向UI暴露可变规则状态；HUD只在显示值变化时刷新。攻击目标改为单遍选择，常用查询和自然合成减少临时集合，圆环网格减段并限制效果数量。

移除每次下令同步保存，保留原有5秒检查点、暂停/后台/返回与终局保存。检查点同步调用内用严格相等的捕获见证避免重复重放；见证在finally清除，磁盘加载仍完整校验和重放。输入后到下一次检查点之间，异常终止可能回退该时间窗内进度。

重放升级到v2，记录自由落点和显式实时模式切换。恢复v1时先按旧规则重放，再在Main绑定时切换实时。配置兼容仅接受当前配置或精确的已发布旧战斗配置指纹，不放宽到任意旧内容。已验证旧算法重放后切换及新模式重放/保存恢复；未用发布前真实用户磁盘档做端到端迁移验收。
