# 关卡指引与分层弹窗

2026-11-22，用户认可首次强指引、独立目标面板及按职责拆分弹窗，追加音乐等设置、确认及多层级管理。本轮先接已有小院清路与救助，不扩展其他地点规则。

后续用户要求收紧UI、生成素材，并选择手绘版暂用及统一全屏黑遮，最新布局/控件与本轮验证见[紧凑UI记录](紧凑UI与水彩控件.md)。下方首次实现的职责与规则仍适用，旧截图和指纹仅对应当时快照。

## 职责与层级

- 暂停：继续、设置、返回救助站；关卡说明移到右侧独立「目标」入口。
- 设置：总音量/音乐/音效音量及各自静音；即时试听，保存后持久保留，取消恢复进入时的值。恢复默认需确认，仍须保存才落盘。
- 目标：实际通路状态/信任进度与救助状态，保留现有玩法说明，可重看操作指引。阅读时暂停局内模拟。
- 确认：返回救助站、恢复默认、重看指引；回站说明外出未保存的边界。取消只关当前确认层。
- 指引：独立遮罩、高亮和业务输入门禁；成功清除/挪箱/搭桥/部署才推进。
- 普通提示：保留原场内短提示，指引完成和保存失败使用独立短提示，不占固定画面。没有扩展奖励/交易或新飘字业务。

典型链为暂停→设置→恢复默认确认，最大4层、独立排队上限8项。只有最上层显示和接收输入，使用同一张全屏遮罩；业务不改Canvas排序。返回键逐层关闭，设置页返回等于取消未保存修改。切后台/失焦保留当前层并暂停，原来没有弹窗时打开暂停；回前台后不会自动继续关卡。

## 当前遮罩与安全区

共享Widget已移到根Canvas末尾，黑遮独立于安全区；ModalBackdrop和GuideMask覆盖整个画布，卡片/文字/按钮放在统一SafeContent安全区。纯黑88/255仅绘制一层，子确认层不叠黑，模态打开时收起引导，最后一层退出后撤掉遮罩并恢复原输入状态。指引保留允许操作的孔，普通提示不遮暗；见[规范](conventions/topics/ui.md#当前工程的全屏遮罩约定)与[手绘接入任务](协作任务/20261122-手绘接入与全屏遮罩-01a1f74d.md)。下方首次指引实现的规则保持，旧验证只适用于当时快照。

## 代码与数据

Framework/UI为轻量有界PopupStack与纯GuideSession、GuideStep、GuideMaskGraphic以及跨程序集ILevelOverlay契约，不依赖Game。Game/UI显式装配页面、音频草稿与暂停所有权；模块只报告输入与实际成功，费用/时限/动作仍由原规则入口决定。没有第三方UI框架、反射发现或运行时拼装面板。

静态Widget_LevelOverlays预制体在两个原面板内显式绑定；原有GUID与美术分支保留。Editor/LevelUi作者仅一次性增量创建新增分支，在隔离副本的Prefab Mode完成；后续修改保存的Prefab，不重新创建旧界面。

LevelUiText.json为文案源；LevelGuidance.json描述contextId、含版本mechanicId、步骤文案、允许操作和成功条件。当前首学清理、挪箱搭桥、救助部署；其他地图仅复用同机制学习记录，不默认套小院格子。指引可按需扩充，合体/改道未新增强制教学。

清理指引选择拾杂物→清理入口杂物→选择除草→清除入口杂草；解谜指引选箱→挪到旁侧→搭桥；救助指引选牌→选择路口→实际提交部署。无效输入/按住未完成/错误落点不推进。遮罩开放暂停和目标作为随时离开的入口；暂停取消触摸但保留已选箱/计划。目标不存在时结束本次演示并提示查看目标说明，不标记教学完成。救助重看指引只在可选择行动且有可部署手牌时启用；执行动作期间仍可阅读目标说明。指引只高亮当前资源足够的手牌，避免被无效部署卡住。通路已经完成时不再重开清路指引。

学习完成独立存于guidance-progress的guidance.completed分区（微信键homeless-pet.guidance.v1），不保存局中状态，也不改main.station版本。整段成功才写入，已完成版本不重复写，新增版本单独学习；读档失败保留原档并阻止写入，写失败提示下次可能重教；完成列表是必填字段，缺字段/非法内容不会被当作空进度自动覆盖。声音继续用audio-preferences与既有AudioService；当前没有BGM素材，不新增音频资源。
