# 地图 UI 规范检查与整改

2026-11-23。用户要求“接下来看看地图界面，让其符合规范”。本轮按[排版规范 v1.0](UI排版与可读性规范.md)、[视觉样式 v1.1](UI视觉样式规范.md)和[UI工程专题](conventions/topics/ui.md)整改 Main / 旧地图预览共用的静态地图面板。协作范围、失败历史和最终回执见[任务](协作任务/20261123-地图UI规范整改-01a1f74d.md)。

## 实际问题与改动

| 原问题 | 当前处理 |
| --- | --- |
| 大块白底、深绿白字按钮和平面黄牌与共享手绘 UI 不一致 | 复用 `Paper`、`Action`、`Secondary`；奶油纸底、浅绿主操作、浅杏返回，深绿文字 |
| 地点选中仅换颜色 | 选中纸牌同时显示深色轮廓，基准3U；锁定仍显示名称/状态，地标插画不染色 |
| 暂停开启是方形标记 | 保留原暂停 Toggle，用共享爪印表达开启状态，文字语义保留 |
| 禁用按钮偏暗 | 接共享 `PaperButtonState`，浅纸底、深字与现有出发限制说明；恢复时还原主/次按钮 |
| 详情与预计耗时、限制都参与滚动，短屏/4:3会裁掉后两者 | 地点标题/描述独立滚动；预计耗时、安置位要求和限制移到 Mask 外固定摘要，返回/出发始终固定 |
| 长详情缺少更多提示 | 实际溢出时显示非交互上下图形，内容不溢出时收起；切点回顶，空摘要不占行 |
| 同类操作反馈不统一 | 返回、前往、暂停复用 `LevelMotion` / `UiMotionFeedback`，仅动画视觉子层，热区不动 |

主任务仍是看地图、选地点、确认条件并出发。顶部保留标题/安置位/时间与右侧暂停，关键信息避开顶部中央；背景全屏、操作使用统一安全区。地图仍是最大连续区域，中部地图/详情使用布局权重分配，不将某个百分比当所有机型的保证。详情可滚动边缘允许自然露出部分文字，限制与主操作不参与该裁切。

## 保留的能力与编辑方式

- 双轴大图拖动、轻惯性、四边限位、从建筑拖动防误选、多指所有权、选点聚焦与普通刷新不抢视野保留，详见[大地图记录](大地图拖动与布局.md)。
- 地形、7地标图片、原归一化锚点、点击根及原 `.meta` / GUID 保留；6个可选点仍是当前内容样本，稳定ID和1/4/7点扩展回归保留。
- 地点回访、事件/出发限制、开路与逆塔防、存档规则不变；本轮未新增玩法、缩放、地图切换或森林开放。
- 复用现有 `T_UI_LevelControls.png`、`LayoutMetrics.asset`、`LevelMotion.asset` 和 `PetRound-Game.ttf`；22处字体引用一致，没有新增图片、字库或生产文案。后续新文案仍按字库子集流程处理。
- `CityMapView` 只接数据与展示状态；纸牌Sprite、轮廓与滚动提示均为Inspector显式引用，缺失绑定立即报错，不在运行时按名查找或拼UI。

编辑入口：`unity/HomelessPetHelper/Assets/Prefabs/Panels/Panel_CityMap.prefab` 的 Prefab Mode。`SafeArea` 下标题、主画面、固定 `TravelSummary` 和操作组分别维护；长文继续由原详情 ScrollRect 接管。不要把摘要重新放进详情 content。

`CityMapUiRefinementAuthor` 是本轮隔离批处理的一次性增量工具，使用 `PrefabUtility.LoadPrefabContents` 保存现有Prefab；检测已经有地图MotionScope时拒绝重复执行。日常不重跑它或旧地图创建器，避免覆盖素材和绑定。

## Mask 与动效检查

本轮新增动效只用于地图/详情裁切容器之外的操作按钮；地标保持静态。原地图和详情的 RectMask2D 仍启用，没有通过关闭Mask或 `maskable=false` 绕过裁切。按钮稳定命中根与带内缩的视觉子层分离，沿用共享 Hover / Press 及复位行为。

专项布局检查覆盖所有新增动画控件的热区、安全区和Mask祖先；原拖动回归覆盖地图两端、点选射线与暂停/失焦/关闭重开。Mask边缘其他地标允许自然裁切，这属于拖动地图的可见边界，不是动画被剪掉。

## 2026-11-24 全屏地图与按需详情

用户提供清新可爱的纵向场景参考后，要求地图占满屏幕、常驻最多一个角落小返回，长提示只能进入弹窗、气泡或Toast。本节替代旧版本固定顶部状态/底部摘要布局，旧记录保留其当时事实。

- 现有地图移到根Canvas全屏，保留底图、地标独立图层、稳定ID、锚点与拖动限位。原图比例为3:4，在较长手机屏上按cover铺满，因此可横向拖动查看两侧；未来换成长地图仍由同一尺寸规则决定可拖动方向，不为机型拉伸图片。
- 浏览时仅保留短地点名和左上角的小返回。地点名沿用现有PetRound，奶油字和柔和绿细轮廓；大纸牌和常驻“有/暂无求助”说明收起，未替换字体文件或新增图集。
- 点地点打开独立详情，正文包含地点/求助、当前容量与时间、预计耗时和限制；出发需再点主动作。默认推荐不自动打开详情。关闭、出发均在正文Mask外，正文超长独立滚动，弹窗宽高受安全区限制。
- 本地详情由既有PopupStack管理。模态只用一层纯黑88/255遮罩铺满根Canvas，拦截底层点选/拖动；关闭恢复浏览。返回先关详情，再返回救助站；进入/回站的业务、存档、时间与双向转场保留。
- 临时外部反馈接既有Widget_Toast，显式绑定安全区，不拦输入，关页/失焦清理；出发限制仍在详情中持续可读，不依赖Toast消失时间。
