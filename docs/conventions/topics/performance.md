## 4.6 每帧代码与 GC

- **必须**对 `Update` / `FixedUpdate` / `LateUpdate` / `OnGUI` / 高频事件等稳态热路径控制分配，默认预算 0 B；引用类型 `new`、隐式数组/`params`、字符串格式化、捕获闭包、装箱与 LINQ 需重点检查。低频初始化和非热路径按测量结果取舍，不全局禁用可读的语言特性。
- **必须**以目标平台 Profiler 的 `GC.Alloc` 调用栈确认分配来源。值类型 `new` 不等于堆分配；具体 `List<T>` / `Dictionary<TKey, TValue>` 的 `foreach` 通常不分配，转为接口枚举或发生装箱时需另测，禁止仅按关键字定罪或机械改写。
- **必须**避免热路径中的场景查找、反复组件获取与批量返回数组的查询；组件引用在 `Awake` 或显式初始化阶段缓存。持有者结束生命周期时解除外部引用/订阅，单纯给自身字段置空不等于释放资源。
- **推荐**缓存不变文本、仅在值变化时刷新，或使用项目文本组件的低分配格式化 API；`StringBuilder.ToString()` 仍会产生字符串，不得宣称使用 `StringBuilder` 就已零分配。
- **必须**区分受 `timeScale` 影响的玩法时间与不受其影响的 UI/超时计时；连续运动使用匹配的 delta time，禁止按帧 `++` 累加模拟时间。固定步长逻辑使用 `fixedDeltaTime`，业务时钟见 [§4.11](csharp.md#s-4-11)。
- **推荐**高频逻辑降频或改事件驱动（脏标记 + 一次性刷新）；倒计时、体力显示按显示精度到点刷新，而非每帧重建文本。

## 9. 性能、内存与包体

<a id="s-9-1"></a>

## 9.1 帧预算

| 指标 | 目标（中低端真机） |
| --- | --- |
| 平均帧率 | ≥ 项目目标帧率（60 fps，低端机降级策略明确） |
| 主线程单帧 | 不超过帧预算的 70% |
| 每帧托管堆分配 | 稳态 0 B |
| GC 触发 | 滚动、弹窗动画等连续交互期间 0 次 |
| 启动到主界面可交互 | 按立项基线，逐版本对比不得劣化 |
| 弹窗打开到可点击 | 按立项基线，不得因同步加载或动画阻塞 |

- **必须**新增每帧逻辑同步给出耗时/分配评估；归档设备、场景、样本时长与 Profiler 证据。Deep Profile 仅用于定位，其开销会改变耗时，禁止将深剖面数据直接当作最终性能验收基线。
- **禁止**以"编辑器不卡"或单一机型作为验收结论。

<a id="s-9-2"></a>

## 9.2 内存

- **必须**建立内存基线（PSS / Unity Profiler 分项：UI 图集、纹理、托管堆、音频）。
- **必须**评估大对象、图片、协议缓冲区的大小、分配频率与存活期；高频分配优先复用/池化，低频对象不强制池化，池容量与清理策略见 [§4.12](csharp.md#s-4-12)。禁止无业务需要地长期保留大数组，亦禁止为减少分配制造更高的常驻内存。
- **必须**静态集合、事件中心、单例中的对象引用在销毁时移除。
- **禁止**无上限增长的缓存（头像、排行榜快照、日志、历史记录），必须有 LRU / 数量上限。
- **推荐**切后台释放可重建缓存，对低内存回调做降级；休闲项目频繁前后台切换，此项必须验证。

<a id="s-9-3"></a>

## 9.3 渲染与 UI 重建

- **必须**控制 DrawCall / SetPass 与 Overdraw；移动端禁用非必要实时阴影与全屏后处理。
- **必须**避免 `Canvas` 整体重建：动静分层，禁止频繁改 `Color.alpha`（用 `CanvasGroup`）。
- **禁止**对不可见 Cell 做动画、粒子、逐帧刷新。

<a id="s-9-4"></a>

## 9.4 启动与热更

- **必须**启动流程分阶段且可观测（SDK 初始化 → 随包配置加载 → 资源校验 → 账号/远程配置（非阻塞）→ 主界面）；首屏前禁止同步加载大资源。
- **必须**广告 / 埋点 SDK 初始化延后或异步，禁止阻塞首次可交互；远程配置拉取**禁止**作为进入主界面的前置条件。
- **推荐**启动期预热高频 Shader / 对象池，避免首次打开弹窗卡顿。
- **必须**启用远程更新时具备版本号、下载取消/重试、校验与失败恢复；大包需支持断点续传或分块复用，短小配置可整体重试，不能为所有文件机械要求同一下载机制。选型、更新边界与回退限制见 [§9.5](updates.md#s-9-5)–[§9.7](updates.md#s-9-7)。
