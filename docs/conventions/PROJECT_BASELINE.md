# 项目基线（编码必读）

<a id="s-1"></a>

本文件是新立项 Unity 正式客户端的默认模板。开始任务时先核对实际仓库；现有 Web/其他引擎原型不因此自动变成 Unity 工程。项目专属决定集中记录在本文件，专题提供实现细则。

## 模板默认约束

| 项 | 基线 |
| --- | --- |
| 产品 | 手机竖屏休闲、小团队迭代；核心玩法和基础启动离线可用 |
| 技术目标 | Unity 2022.3 LTS / C#，语言上限按目标编译链确认；Unity 精确补丁版本及 API 兼容级别从工程读取 |
| UI | 单主场景 + 面板/弹窗栈；默认 1080×1920 设计基准，使用统一 CanvasScaler 和安全区策略 |
| 平台 | Android/iOS 为模板目标；实际支持平台、系统版本、机型及渠道待立项确认 |
| 性能 | 默认目标 60 fps，低端机可明确降至 30；稳态热路径默认 0 B 分配，结论以目标真机为准 |
| 联网 | 账号/排行榜/活动/广告/内购按产品接入；离线玩法与联网权益的权威边界分开 |
| 更新 | 区分配置、资源、代码更新；代码热更按实际需求和平台规则选型，不默认接入 |

已有工程的明确决策与用户当前要求优先于模板默认值。发现冲突应说明影响并按任务范围处理，不擅自迁移技术栈或改产品基线。

## 必须知道的工程边界

- UI 使用静态 Prefab 与明确绑定，动态 Cell 走既有复用机制；禁止运行时按名字找控件或手拼面板树。交互区避开刘海/挖孔/Home 条，长屏、小屏及长文案要适配。
- 遵循单向程序集依赖、运行时与 Editor 隔离；SDK 经适配层接入。生成 `partial` 与手写扩展必须在同一程序集/命名空间。
- 配置与资源有统一访问入口；核心配置/资源随包，远程失败使用兼容的有效版本。Prefab、代码与配置不得混用不兼容版本。
- 面板开关/重用要复位并释放展示任务；广告、内购、切后台会打断流程。交易由业务服务持有，面板关闭不能丢交易，重复回调不能重复发奖。
- 新增/移动资源维护 `.meta` 与 GUID；按工程的版本管理及锁策略协作。不要从模板里的 P4 规则推断当前仓库正在使用 P4。
- 发布 SDK、资源、存档、更新系统或性能相关改动时，读取对应专题并验证目标平台；编辑器可运行不代表 IL2CPP/AOT 真机可用。

## 项目事实与待确认项

当前规范没有绑定实际 Unity 仓库。以下均为**待确认项**；表中候选和占位词不是已经采用的依赖，也不是安装授权。

| 决策项 | 当前状态 / 确认来源 |
| --- | --- |
| 工程根目录、精确 Unity/包版本、API/异步方案 | 待确认；读取实际工程配置和依赖 |
| UI 框架、绑定生成器、生成命令/目录 | 待确认；旧文 `UPF` 是占位 |
| 配置生成器、schema/源表、生成命令 | 待确认；`Luban` 为候选/占位 |
| 资源系统、远程内容发布与存储 | 待确认；Addressables / YooAsset 等为候选 |
| 代码热更与更新范围 | 未选定；HybridCLR / xLua 为候选，不默认启用 |
| 版本管理、分支/锁策略、模块 Owner | 待确认；P4 / Git 为替代方案 |
| 支持平台/渠道、最低设备、性能/包体预算 | 待确认；按立项和真机基线记录 |
| 后端权威、存档恢复、支付/广告与隐私方案 | 待确认；按实际产品/服务端契约记录 |
| 构建/测试/生成命令、CI 与报告位置 | 待确认；从工程现有脚本和配置确认，不编造命令 |

确定后将对应行改为实际结论，并记录依据/决定人、日期和适用版本；配置文件中的客观事实可直接核实，框架引入或产品变更仍按任务授权和工程决策流程执行。禁止每个专题各维护一份相互冲突的选型清单。
