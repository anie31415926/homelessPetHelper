## 实现结果

| 原问题 | 现在的表现与归属 |
| --- | --- |
| 保存失败后只停操作，Toast被冻结在alpha 0 | `StationSceneChrome`有独立、持续可见的阻断纸板，覆盖Main实际保存失败和加载失败；说明退出重试，保留原数据，不出现未实现的修档按钮。普通Toast保持原暂停契约 |
| 洗/梳各自的不可用原因缺失 | `StationPreviewSession`直接读取已有`StationCoatCare.GetBeginFailure`，详情正文显示每项的真实原因；与短Toast独立。允许后自动隐藏，不改权限或健康规则 |
| 菜单图标被深绿乘色且含义不清 | 右上保留144U热区，改成紧凑“菜单”文字入口；彩色图标作者默认白tint，避免再次染黑 |
| 站内没有声音设置入口 | 正式Main菜单接共享`Widget_LevelOverlays`和`LevelOverlaySession`，复用音量、静音、设置保存/取消、恢复默认确认及节奏选项，不复制存储逻辑。子层退出恢复菜单和玩家原来的暂停选择，只显示一层全屏黑遮 |
| 禁用按钮乘色偏黑 | 共享`PaperButtonState`在不可用时切到奶油Paper，tint为`#F5F2E9`，保留深绿文字和alpha 1；可用时恢复原Action/Secondary，包含父CanvasGroup禁用。固定命中根及动效范围不变 |
| 暂停开启方块生硬 | 使用现有共享爪印作为明确开启标记，Toggle继续管理显隐/淡变，与按钮状态色统一 |

禁用/hover/按下及错误文字参数收在`LayoutMetrics.asset`，无每个面板复制颜色。状态组件仅缓存显式引用、逐帧比较可用性，变化时才写sprite/tint；没有稳态查找、LINQ或托管分配代码。具体GC/帧预算仍须目标平台Profiler验证。

现用纸按钮覆盖站内、地图、清障、救助和共享弹窗；其余已保存UI文本也统一新字体。旧白板里的非纸按钮、动物/场景图形不强套纸底。预览场景没有正式音频/偏好持有者时隐藏设置入口，正式Main显式启用。观察围栏与选中框的场景美术精修保留为后续事项。

五个实际运行状态依次为：独立护理权限、站内设置、恢复默认确认、保存失败、加载失败。来自本轮隔离Unity，不是重画UI；三动物权限画面为Editor样本，其他四项来自隔离Main及内存存储夹具。

## 免费字体与许可

选用**寒蝉全圆体 ChillRoundF v3.0**的圆润常规字形，派生名为`PetRoundGame`，运行文件为`Assets/Art/Fonts/PetRound-Game.ttf`。对比站酷快乐体后，后者笔形更跳跃、偏装饰，小字号多行正文不如全圆体稳定，因此保留一套字体兼顾正文和标题。

- [官方仓库](https://github.com/Warren2060/ChillRound)，固定提交`46dda1602729b58de96e3fdee9f918d7aaa64727`，源文件`ChillRoundF v3.0.ttf`为6,168,772字节。
- [官方许可证](https://github.com/Warren2060/ChillRound/blob/46dda1602729b58de96e3fdee9f918d7aaa64727/LICENSE)为SIL OFL1.1，允许免费商用、嵌入及随软件分发；保留版权与全文，不单独售卖字体。
- 上游有Reserved Font Name，裁剪派生已修改全部本地化family/full/PostScript/unique名称，保留copyright；[完整许可](../unity/HomelessPetHelper/Assets/Art/Fonts/ChillRound-OFL.txt)同时保存为文本和嵌入字体name table，随字体二进制分发仍带许可。
- 来源哈希、抓取二进制和候选许可留在`test-results/station-ui-refinement/research/`；选用源SHA256为`7dae804b344f7bc1a1c8426b9515e9b54d7baac3e123263d0bae94d0a305a732`。

裁剪后**738 cmap / 238,392字节（232.8KiB）**。现有Noto文件实测180,680字节，增加57,712字节（56.4KiB），没有把完整中文字体导入Assets。Main与Loading用同一字体；Main依赖回归明确排除旧Noto，旧字体只留历史Editor引用和对比。

[重建工具](../tools/build-game-font.py)支持固定源哈希、静态/variable源、输出路径与派生名称，并正确解码Prefab/JSON的Unicode转义、检查中文/ASCII字形。使用fonttools4.68.0，工具独立库只放忽略证据目录，未安装全局Python依赖或新增运行时框架。相同命令重建与保存资产逐字节一致，输出SHA256为`c276d9f30d78502e28fe9cb2805423c1027bfa2eef182836e5442c7206b54470`。命令及导入约束见[字体README](../unity/HomelessPetHelper/Assets/Art/Fonts/README.md)。

新文案必须重建子集、验证缺字和小屏换行；该文件不是任意中文输入字库。未来允许用户自定义名字时要另设字库策略，不能默认当前子集覆盖。
