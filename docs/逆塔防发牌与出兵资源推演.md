## 最新确认：双行动条、玩家决策暂停、点数费用保留

用户明确：用进度条表达玩家与动物各自一个回合所需的时间；较强、较难救助的动物可以行动更快，强弱与动物状态关联；到玩家回合时可以暂停，让玩家考虑策略。其余前轮供给方向认可。随后经澄清，用户选择“行动条控制出手，保留点数费用”，不是把出兵/合体费用全部替换成计时条。

**后续认可**：用户对双条推进、玩家窗口全场冻结、玩家回合开始补牌/回费、动物已有进度保留及强招需要实际应对窗口的说明回复“没有问题”，询问接下来还需确定什么。上述不再重复等待方向确认；每回合具体操作额度、胜败结算和首批单位/炮台能力仍待拍板，未获得编码授权。

这替代下文“玩家选牌时不暂停”的纯实时候选。下文三张手牌、短牌袋、资源上限、费用等继续作为首轮讨论/试做起点，不宣称已完成平衡；每 2 秒独立补给及 6 秒换牌等旧数值不能直接作为新时序已确认的参数。

### 当前已确认与待细化的分界

- **已确认**：玩家和动物各有行动进度；行动速度可不同，并关联动物当前状态；玩家回合开始补牌/回费并全场暂停思考，确认后恢复推进，动物已有进度保留；出兵与合体继续有点数费用；强招预告要给玩家真正的应对窗口。
- **继续沿用的方向**：随机供给、同手允许重复、少量手牌且未使用留存、稳定而有限的点数供给、有限换牌、免费自然合体/花费点数主动合体。具体数值按新节奏校准，不重新要求用户确认这些方向。
- **仍待细化**：每个玩家窗口允许几次出兵/合体、每次具体补牌/回费数量、动物主动招式和布塔的选择规则、单位/炮台自动交战的数值，以及状态到速度的映射。不能将行动条认可扩大为这些细节全部获批。

### 推荐的时序解释

1. **推进阶段**：玩家条与动物条按各自速度增长；部队行军、塔火力、施工及局内倒计时沿同一战斗时钟推进。动物条满时，在其合法动作中执行攻击、布塔或其他防守，再进入下一次蓄条；动物行动不要求额外弹出等待玩家确认的窗口。
2. **玩家条满**：进入策略窗口，全场冻结。建议在该回合开始时一次性补牌/恢复点数，再让玩家看清当前局面；不能每次打开界面重复领取。
3. **思考与预览**：可看路线、手牌、合体材料、主体位置、费用和动物预告；不推进部队、炮台、施工、双方行动条、补给、换牌冷却或局内倒计时。不在暂停时先实际落兵、再继续安全落第二只第三只。
4. **提交行动**：校验并消耗合法费用，执行本次允许的操作后恢复推进，玩家条重新计时。动物尚未满的进度继续保留，不随玩家回合清零。无合适操作时需要明确的跳过/蓄势出口，不能卡在策略窗口。

上述推进/冻结/恢复与玩家回合开始补给的方向已获后续认可；每窗口操作额度仍待确认，不把前轮算账示例直接当作暂停内无限操作获批。最新候选见下一节，不继续沿用一项主行动作为已定规则。

### 状态与强度的候选映射

可先用玩家 4 秒、普通动物 6 秒、高警戒动物 3 秒作为说明例子：动物在两个玩家窗口之间可能有更多行动，改变的是战斗节奏，不是现实思考时限。秒数仅示意，不是默认值或测试结果。

紧张/警戒、疲惫、疼痛、注意对象等可影响动作频率与选择，但不把“受伤”简单当成更弱，也不将所有负面状态统一映射成快攻。状态变化后的速度更新建议保留已积累的进度，改变后续增长速度，不用重置或突然补满暗中增减一个回合。

### 需要守住的公平与表现边界

- 动物的快回合不能绕过已确认的预告可读性。重要横扫等强招应至少经过一次玩家能实际应对的决策窗口；否则动画虽有预警，但玩家没有出手机会，仍等于无法应对。
- 动物行动条与具体招式范围是不同信息：条表示它何时行动，姿态/地面范围表示它准备做什么，不能只有一条抽象计时让玩家猜技能。
- 炮台和部队沿途持续作用建议使用自身自动交战节拍，动物行动条控制动物主动招式/布塔，不把每座塔与每只部队都再做一条常驻大进度条；具体归属尚待确认。
- 双方同时满条的顺序建议玩家策略窗口优先，再按已固定的动物预告处理，不把同刻事件顺序留成不可见的随机结果。
- 暂停只提供思考，不提供恢复资源、冷却、刷牌或安全反复出兵的收益。普通暂停、切后台同样不推进战斗；不计算恢复后的现实离线时长。

本轮只修正设计记录，未创建双条系统或更改现有游戏、聊天示意、图片、Unity/Prefab，未执行时序模拟或玩法测试。

## 首版还需拍板的规则

用户已认可核心方向，后续不需要先把完整塔库、全部动物状态和所有数值设计完。建议只先明确以下三类规则，确认后即可界定独立试玩范围；本节均为新建议，不是已确认规则或开工授权。

1. **玩家窗口的操作额度**：建议每回合最多出一张牌，另可主动合体一次，两者各自扣费；可以只出牌、只合体或跳过。这样第三只出场后能接付费合体，但不能暂停中连出三张再免费成型。换牌与出牌是否共用本回合额度需要一并明确，自然合体只由实际场上条件触发，不把预览算真实部署。
2. **局内胜败与单位抵达后的处理**：建议不用拆掉所有塔，单位突破近身防守后完成一次救助作用，推进同一条化解防御进度，完成后退场，不留在动物脚下无限重复计分。目标达成即结束本次玩法挑战，超时记本次未完成、允许重试，不加入死亡或整局 Game Over；如何承接正式接受、现场医护与回站仍不借试验伪造。
3. **首批实际能力**：建议三种基础单位分别偏硬推、机动和护送，各一个三合一结果；一种普通拦截炮台，加猫的守门、横扫及有限补塔。具体单位能做什么、如何处理炮台及合体能力需确认，但不要求先准备全部远期内容。

行动条时长、回费数量、费用、耐久、射速、路长和总时限可采用明确的可调试验参数，不把它们当永久平衡。应保证一轮有正常出兵机会，再观察合体与多路投入是否值得；不等所有精确数字逐个讨论完才允许试看。

清路的额外投入预算仍未定。第一版若先验证核心攻防，建议固定两条已打通路线作为测试起点，明确这是验证切片，不是假装实现完整清路，也不把免费全清定案。正式清路承接在核心循环成立后继续细化。

## 1. 前轮供给提案：纯实时与固定补给（时序已由顶部修正）

本节保留前轮讨论依据，其中“玩家选牌不暂停”已被顶部最新确认替代。供给与费用方向获认可，但独立固定秒数如何接入玩家行动条须按新时序细化，不照表直接实现。

| 项目 | 首轮讨论值 | 意图与边界 |
| --- | --- | --- |
| 手牌上限 | 3 张，允许同类重复 | 少量输入，能留下一张等待合成材料；不是旧样本的同组去重 |
| 补给节拍 | 每 2 秒游戏内战斗时间一次 | 同一个节拍恢复资源与补牌，不设两条互不相关的进度 |
| 资源 | 开局 4，上限 6，每节拍 +1 | 可以开场组织一波，但不能无限攒一整局的费用 |
| 补牌 | 每节拍最多填补一个空位 | 出兵不立即补牌，更不刷新其他未使用牌；已持有牌留存 |
| 满手 | 不补新牌、不暗中消耗抽袋序列，也不积攒待领取牌 | 不出现隐藏仓库、满手后瞬间倾倒很多补给或后台攒牌 |
| 单位费用 | 首轮以 2 为普通单位基准，特殊单位以后讨论 1～3 | 首先验证角色分工，不拿价格替代单位设计 |
| 主动三合一 | 暂收 1 资源，材料必须是已部署的三个同类 | 已付过三次出兵成本，只收调度便利费；不能花费购买缺失的第三只 |
| 自然三合一 | 附近材料满足条件时免费 | 保留路线与集结的收益，不能所有局面都强迫付费合体 |
| 换一张 | 候选为每 6 秒可弃一张，留空等下一补给补齐；不扣出兵资源 | 给坏手牌一个有限出口，不允许同一瞬间无限免费刷新，不暂停战场 |

只有一条战斗资源，不额外加入抽卡币、合成币或能量升级建筑。资源、补牌、换牌冷却与战场共用游戏内时钟，暂停及后台冻结，不通过现实等待获取额外供给；具体暂停操作另行确认。

牌面体现随机可选材料，资源体现何时能投入；二者不是同一东西。允许保留手牌规划，但手牌不是可合成的安全材料区。三个单位全部出场后，才进入免费或主动三合一判断。

## 2. 随机但避免材料长期断供

建议先用少量基础单位验证，不一开始塞大量类型稀释三合一机会：

- 先以三种能独立推进的基础单位作为供给核心，分别偏持续推进、机动、保护。保护单位也需要有基础作用，不让整手都只能等另一张输出牌。
- 可试短抽袋：三种基础单位各 3 张，组成 9 张袋，打乱顺序抽取，耗尽再重建。具体数量与是否按相遇变化仍待确认。
- 同手允许出现相同单位，不沿用旧样本的同组去重。短袋只约束材料供给，抽到第三张不意味着前两只已在场或仍然存活，不自动保证合成。
- 不采用每次独立抽取后声称一定能凑齐的做法。短袋同样可能跨袋出现间隔，仍要验证单位存活时间、行军时间与补给速度是否相容。
- 不根据动物刚出的技能偷偷替玩家改成最佳克制牌，也不把救助成功藏进接受概率。

新供给模型不直接删改现有选项容器、锁牌、趣味项或 JSON。旧图钉在“未使用牌自然留存”的新候选中可能没有必要，但须用户确认后才能决定去留。

## 3. 一小局怎么展开

### 起点假设

三路骨架、左下出兵、右上猫咪不变。清路阶段暂以中路和左/上边路已通、另一条边路未通为例，不代表强制只能开两路。清路费用和预算仍未定，本例不偷偷从战斗资源扣除，也不将全清免费作为已批准规则。

为控制复杂度，本例只有一种普通单体炮台：中路外塔位已有一座，边路内塔位已有一座。其他位置只是空塔位，猫仅有一次有预告的补塔机会；塔数与补塔次数均为推演假设，不是正式参数。

塔优先拦截进入自身射程的前排，不因玩家合成就暗中改为无限射程。单位进入交战位置可以停留处理炮台，拆掉后继续推进。这是交战行为，不把路侧炮台假装画成横跨整路的物理墙；具体拆塔耐久和攻击效果尚未设计。

### 前段：资源先投哪里

开局 4 资源，以普通单位每只 2 资源为例：

- 中路连续部署两只：形成集中前线，对中路外塔施压，后续同类可能赶上自然合体，但在塔下待久了会损失材料。
- 中路、边路各一只：攻击分散，单路推进弱，但长边路较早开始行军，后续才有配合猫近身防区的可能。

不能看到猫开始横扫后，才从左下新发一只边路单位，就宣称它赶上这次收招窗口。长路的价值来自提前部署或前沿改道，不靠瞬间到达。

### 中段：同一份资源在合成与续兵之间分配

设后续某时刻：场上中路有两辆同类小车，手中已有第三辆和一张机动单位，当前资源为 3。

| 输入 | 资源账 | 场上选择 |
| --- | --- | --- |
| 第三辆出兵，再主动合体 | 3 - 2 - 1 = 0 | 以存活的前排为主体，在前沿升级；不让新出的材料长途追赶，但花完资源，暂时无额外出兵能力 |
| 第三辆出兵，争取自然合体 | 3 - 2 = 1 | 省合成费，但第三辆需要实际走到附近，前两辆承担塔火力；不是必然赶得上 |
| 机动单位走边路 | 3 - 2 = 1 | 保留另一方向的推进机会，前两辆继续作战且仍可能被打掉，不冒充无损保存材料 |

三条都是待验证的策略，不凭文字判定哪条最优。合体不默认重置损耗或获得无敌，耐久继承需另行确认。

### 后段：猫把有限防守放在哪儿

中路塔被拆后，猫的下一次补塔机会在已可见的候选塔位预告施工。可以推演补中路内塔对抗主力，也可以补边路外塔拦增援；不是允许无预告无限针对玩家。

玩家可能继续集中突破，也可能利用提前在边路行军的部队或前沿改道能力换方向。某一路打到动物近身防区，就进入守门和横扫的局部周旋；其他塔不默认全部清掉才有资格推进。

拆过的塔在本例中保持拆除成果，不靠刷塔返资源推动经济；是否允许有限重建以后另议。最终突破如何表达动物愿意接受救助仍未确认，本页不凭推演结算真实救助成功。

## 4. 为什么暂不采用另外两种资源来源

- **抽一次也扣出兵资源**：随机材料本身已有限制，再为找材料付费，容易把乐趣变成刷牌税；抽牌暂不单独收费。
- **主要靠拆塔或击退目标回资源**：领先的一路会越拆越有钱，失败的一路却可能彻底断供；首轮以稳定补给保证调整机会，不先加击杀、拆塔回费或利息。

固定资源上限、局内有限时间和场上材料受损共同约束等待。不能靠“时间有限”直接证明没有最优屯费策略，仍须比较攒满后一波、持续出兵、自然合体与主动合体的实际收益。

## 5. 接下来必须验证的四件事

1. **补牌与材料存活能否匹配**：短袋不等于前两只一定撑得到第三只，需同时看发牌节拍、路线长度、塔射速和同类单位寿命。
2. **廉价单位会不会成为刷牌工具**：固定补牌节拍避免廉价牌连出立即刷完整袋，仍需检查换牌与费用是否让某类过强。
3. **主动合体会不会变成廉价前线传送加满血**：材料聚到主体是已认可便利性，不撤销；费用、损耗承接与合体能力需共同限制无脑收益。
4. **断牌和断费是否长期重叠**：观察玩家有多少时间既没可用牌又没资源；不能把大半局等待当成策略，也不能把数值定死后只为通过演示调整动物。
