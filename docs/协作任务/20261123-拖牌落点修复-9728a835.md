## 当前事实与下一步

根因：`SiegeFieldView.DragCard` 把 `ScreenPointToLocalPointInRectangle`（以父节点 pivot 为原点）的结果直接赋给
`anchoredPosition`（以 anchor 点为原点）。prefab 中 `_dragGhost` 的 `anchorMin = anchorMax = (0,0)`，
父节点全屏拉伸且 `pivot = (0.5,0.5)`，两者相差「父左下角 → 中心」向量，1080×2400 下约 (540, 1110)。

下一步：抽出可测的 anchor 换算方法并在 `DragCard` 调用，补 PlayMode 用例覆盖三种 anchor 组合。
