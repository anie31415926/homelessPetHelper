## 两种做法

1. Qwen 文生图贴片（`tools/dog-comfy-patch.mjs`）：无参考 → 照片级毛发；加参考图 → 画出整只狗并带紫色背景。两次都不符合“单块水彩毛皮”。
2. 像素克隆（`tools/dog-patch-clone.mjs`）：从底稿自身取毛皮 → 均值/方差对齐目标区 → 椭圆羽化遮罩 → 512 RGBA。第一次出现明显矩形色块，加颜色对齐后基本隐形。

## 关键结论

- 把三块贴片合进底稿再跑 `tools/dog-rig-prototype.mjs`（新增 `DOG_RIG_SHEET`/`DOG_RIG_OUT` 环境变量），空洞几乎不变：idle-c 415 → 423，test-strong 589 → 601。
- 原因：单图蒙皮的空洞是**网格几何**撕裂（背景透出），不是纹理缺失；贴纹理救不了几何洞。贴片只在拆层后（头为独立网格、颈后由躯干网格覆盖）才有意义。
- 因此贴片的定位改为：作为 body/leg 层的现成“遮挡补绘像素”，替掉美术手绘那一步。
