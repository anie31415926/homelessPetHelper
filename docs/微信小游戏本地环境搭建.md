## 纠正此前兼容性判断

旧预检中 `WXBase.cs` 报 `AssetBundle` 不存在是真实失败，但“必须修改 SDK asmdef / 团结引擎差异导致”的归因不准确。本项目精简 manifest 未启用 `com.unity.modules.assetbundle`；隔离副本启用该内置模块后，**未经修改的官方 SDK Runtime 与 Editor 程序集均成功加载**，没有为此添加 InstantGame 包或移除 SDK 引用。

另一次普通 WebGL 探针从 Standalone 活动平台直接调用构建，出现 `WebGLInput` 不存在；在进程启动时明确 `-buildTarget WebGL` 后通过。修正的是隔离探针的目标平台选择，不是 SDK 源码或项目输入逻辑。保留失败日志，避免以后重新按旧推断修改第三方包。

## 本地检查入口

在仓库根执行：

```powershell
powershell.exe -NoProfile -File tools/wechat.ps1 -Task Check
powershell.exe -NoProfile -File tools/wechat.ps1 -Task Probe
powershell.exe -NoProfile -File tools/wechat.ps1 -Task Probe -BuildWebGL
powershell.exe -NoProfile -File tools/wechat.ps1 -Task BuildGameWebGL
```

`Check` 只读显示当前精确编辑器、模块目录、开发者工具位置及项目依赖。`Probe` 在 `test-results/wechat-environment/probe-<id>/` 复制已保存的 Assets/Packages/ProjectSettings，再加入仅该副本使用的 `tools/wechat/WeChatEnvironmentProbe.cs`：检查 SDK 程序集及 WebGL 能力，输出 `ProbeReports/installation.json`。`-BuildWebGL` 在副本以 WebGL 活动平台创建最小摄像机场景并构建开发包，输出 `ProbeReports/webgl-build.json` 和 `ProbeBuild/WebGL/`；不修改正式场景或平台、不进行微信转换。

Git 下载慢时可复用本轮官方干净检出：

```powershell
powershell.exe -NoProfile -File tools/wechat.ps1 -Task Probe -BuildWebGL -SdkCachePath test-results/toolchain/setup-2026-11-18/wechat-sdk
```

`BuildGameWebGL` 使用同样的隔离流程和可选 `-SdkCachePath`，按 Editor Build Settings 的顺序构建已启用的游戏场景（现为 `SC_Loading → Main`），不再生成最小摄像机场景。它输出不压缩、关闭多线程的普通 WebGL 开发包，检查当前游戏代码能否走完 IL2CPP → WASM；不读取账号凭证，不运行微信转换。普通浏览器没有 `wx` API，不能用这份包验证微信存档。

该选项检查 origin、HEAD 和工作区是否干净，只在子进程环境中将官方 Git 获取映射到本地检出，UPM manifest/lock 仍保留官方固定 URL；不改全局 Git 设置。缓存不在其他机器上时省略该参数，由 UPM 正常下载。构建进程清除继承的 `NODE_OPTIONS` 以避免外部 agent 注入影响 Emscripten/Bee；结束后恢复本进程环境。超时限制为 20 分钟，不用其他正在运行的 Unity 作为验证副本。

## AppID 准备好后

1. 用户在[微信公众平台](https://mp.weixin.qq.com/)准备本项目的真实**小游戏** AppID（不是普通小程序 AppID），确认管理员或开发成员可预览。主体影响后续备案和商业化；注册前先核对后台对所选主体的要求。有对应小游戏就复用，不新建。仅需提供 AppID，AppSecret、登录态和令牌不写进仓库或报告。
2. 在隔离项目打开 Unity「微信小游戏 → 转换小游戏」，填真实 AppID，设置 `Portrait`，先用「小游戏包内」验证首资源是否装得下，不预先购买 CDN。保持自动上传关闭，在本机忽略目录「生成并转换」。若超限，先实测转换后的主包、分包、WASM 和首资源体积，再选优化或合规资源部署方案。
3. 用户在微信开发者工具扫码登录，导入转换后的 `minigame` 目录。若工具提示 Unity 适配插件未授权，按[官方转换文档](https://developers.weixin.qq.com/minigame/dev/guide/game-engine/unity-webgl-transform/Design/Transform.html)在小游戏后台「能力地图 → 生产提效包 → 快适配」核对并开通；实际入口与权限以后台为准。
4. 工具内编译通过后点「预览」，用户用有权限的微信扫二维码。不用「上传」或「提交审核」做这次验证。首轮关注冷启动、竖屏与安全区、地图拖动/点选、一轮救助回站、切后台恢复和完全退出后续玩，并记录设备、系统、微信版本、首帧耗时、运行错误和包体。至少先验证手头一台，后续补另一系统；没有实测不宣称真机通过。
5. 实测下载与缓存后，再校准[图片预算](图片资源规格与首包预算.md)和[资源台账](../art-source/README.md)。本轮没有安装 Addressables/YooAsset、AB 下载器、CDN 或代码热更。
