# 逆塔防猫狗首批实现记录

2026-11-20。用户认可成套提案，要求评估画面成本，好做的尽快落地。本轮交付原 Unity 试玩入口内的首批猫狗攻防，不表示整套 12 类基础兵已完成。

后续更新：用户要求复杂能力逐个实现，本会话已接续猫的好奇按住与图片预算，见[后续实现记录](逆塔防按住实现与图片预算.md)。下文的首批数据和“未做按住”是首批交付时点，不否定后续实现；叼取等其他项目仍未完成。

## 入口与本轮范围

Unity 菜单 **Homeless Pet Helper > Preview > Open Reverse Defense Trial**，打开后 Play。底部新增的阵地按钮依次切换 **猫咪阵地 -> 狗狗阵地 -> 原型对照**；默认猫咪。切换会重开一局，不在场上偷偷替换单位。原状态按钮仍切换普通/高警觉/疲惫，种子和重试不混成阵地选择。

保留原场景、静态面板、手牌池、三路与策略窗口。只在 Prefab 内容编辑中追加按钮和动物图引用，保留 GUID，未重跑资产创建工具覆盖面板。Main/Game 的现有逆塔防装配与结果桥接未修改，目前仍走原型对照内容；本轮新增内容先在独立试玩选择，不声称 Main 已按猫狗自动选取阵地。

### 新能力的真实边界

- 骨头风车第一次接塔三连敲，目标固定；被推离、改道、目标消失则后续敲击取消，不转移到另一塔、不永久三连。
- 绳结基础自身抗推一次；章鱼自身抗推一次，并一次性给最近最多两位无稳绳同伴各挂一根。无目标时保留展开机会，实际展开后不会再补绳。抗推仍吃损耗，不叠层；被消耗后8秒才可接受另一只章鱼的同类稳绳。
- 减速区按真实空间判断，多个区域取较强减速，不连乘；区域独立到期，拆塔后已有区域不会无缘无故消失。与塔射击、施工、动物条和动画一起冻结。
- 推退机关先锁定地面区域，等待时间达到且实际经过一次玩家策略窗口才释放；不追踪移动目标。拆塔可以取消尚未释放的攻击。当前范围是可读圆区，不是提案中的精细扇形爪击。
- 狗飞扑有锁定区、实际起跳时段与落地判定；空中不提前结算伤害，收招不继续隔空守门。外观用整图位移/缩放，不是已有四肢骨骼动作已接入。

## 画面实现与成本

本批道具由 `SiegeTokenArt` 在既有 uGUI 战场 Mesh 内绘制，鱼形、毛线纹路、羽片、骨头、飞盘、绳结和机关轮廓各自可辨。按行进距离驱动摇摆/旋转/轻跳，不依赖现实时间，暂停时不自顾自播放。

合体用三件材料的形象向选定落点拼合，再呈现升级结构，不只是放大基础圆点。尚不是逐根毛线编织、完整折纸或真实散架；这类精细表演可在规则成立后替换表现，不需要改命中逻辑。

程序画面的定位是可玩的低成本白板，不是最终绘本美术。短屏对道具设最低显示尺寸，点击范围同步调整；判定半径、移动位置及技能锁区不因视觉放大而变化。普通保护用环和毛线形象、抗推用下方稳绳线，本轮未制作高精度布料覆盖。

猫狗复用现有临时 Sprite，不新增 PNG、图集或序列帧；狗图使用已补入唯一资源台账，仍 temporary。动物动作资源和图集同期成果未重做、未接进塔防。新增文案使用固定来源 Noto Sans SC 重生子集：155800bytes /622字形，较原133412bytes增加22388bytes；来源哈希、OFL许可不变，不使用系统字体替代。

## 数据与扩展点

- 旧 HTML 真值 `src/siege/definitions.json` 保留；新增 Unity 首批内容源 `src/siege/content.json`，独立中文 `content-text.zh-CN.json`。本轮不让旧 HTML 假装已经支持新塔/新能力。
- `tools/siege-content.mjs` 校验内容，`tools/siege-unity-data.mjs` 合并并生成 DTO/不可变定义、随包配置和文案；生成物不手改。
- `SiegeContentCatalog` 持有独立机关/相遇定义，单位和塔实例携带定义身份。`SiegeSession` 增加可空相遇 ID，旧四参数调用保持旧默认，原回放不改。
- 相遇引用本局单位、初始/新建机关、守门/大招文案、表现键和落地时长。动物图用序列化 ID->Sprite 绑定，没有在战斗内以猫狗/品种分支选择规则。新动物需要配置和相应绑定，不自动猜图。
- 稳定复用的机制继续在纯 C# 内；新机关节奏归 `SiegeDefenses`。能力类型仍是明确的受控集合，不声称已完成能解释任意技能的万能系统。新增真正机制仍要增加所属规则和测试。
- UI 校验当前相遇的基础/升级图形、机关表现和动物绑定，缺失不静默画成圆点。次数、落点、区域、连敲目标、飞扑时钟等都是单局状态，动画不决定命中。
