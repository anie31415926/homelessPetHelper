# 小院现场试玩

2026-11-22。用户认可[现场交互设计](救助与清路场景交互设计.md)，授权先做一版，并要求成年动物自然比例。本记录说明 Unity 实现；HTML 仍是设计参考，不是运行验证证据。

## 入口与操作

打开 `unity/HomelessPetHelper/Assets/Scenes/Main.unity`，Play 后从救助站外出，在社区地图选择“小院”及其求助并出发。原有种子仍决定挪箱搭桥或清理杂物之一；先真实连通，再点击继续进入救助。

- 清理：选择拾杂物/除杂草/洗泥斑，按住能从入口接近的物件；处理公共入口的杂物和杂草即可通行，旁边的可选物件可留下。
- 解谜：点箱子再点同行或同列的落点，也可拖动；直接点沟沿搭桥。箱子可移到旁边的空位；有撤回。
- 救助：点选手牌再点场内路口，或拖到路口；屏幕下方显示计划费用，点击执行才提交。点撤销计划可以取消，不扣费。
- 点场上道具后选择合体，再点另外两个同类材料；可跨路选材料，本回合新部署的道具可加入。最先选的主体决定合体位置。仅实际有改道能力的道具显示改道入口。
- 右侧“玩法 / 暂停”打开说明弹窗，可继续或回站；切后台、失焦会暂停并取消旧触摸。外出过程不新增存档，保留原来的站内检查点恢复边界。

此版只在小院启用。其他地点、旧回合与逆塔防独立试玩入口保留；不扩展森林或其他地点的新玩法。

用户看过Unity截图后追加的要求已纳入本轮：背景按原比例铺满Canvas、允许裁掉装饰边缘；可操作场地保持完整、与HUD一起位于SafeArea内。背景延伸到屏幕边缘不代表交互区也延伸进刘海。顶部中间留空，信任/时间/资源在左侧小区块，菜单在右侧且下移；动物动向贴近动物。长说明放暂停弹窗，普通状态不再占固定上下条，错误/选箱反馈短时浮现，计划费用按选择出现。当前没有新增持久化的新手引导标记。

## 实现与边界

首个场地配置为 `Assets/Settings/Game/YardFieldConfig.json`。同一 360×480 坐标系映射 7×8 开路格子和三条预设救助路线。小院路线共用入口，沿实际树篱间的通道分开并在动物处汇合。两阶段使用同一场地框和背景裁切方式，物件和动物跟随场地坐标，背景作为Canvas满屏装饰层；没有自由画线或按路付费解锁。

`GameContent._fieldConfigs`可绑定多份独立JSON，`OutingFieldCatalog`按`pointId`和外出种子选择；同地点可有不同`layoutId`，拒绝重复布局ID/未知地点。Main不再按“小院”硬编码分支；未配置地点沿用原版。每份数据独立描述坐标尺寸、网格覆盖范围、两种开路地形/入口/动物/箱桥杂物、三条路线格子序列及路口，因此车棚等地点可以按场景形状另排，不必复制小院路线。当前行列由配置的矩形`rows`推导，输入板Cell按上限1024复用；三路和四邻接规则保留，这不是任意路数或曲线编辑器。本轮只制作小院数据，测试里的车棚变体仅证明独立选择/几何，不作为可玩车棚关卡。

`OutingFieldLayout` 校验配置、路径邻接与端点，并从已有逆塔防配置创建独立的场地目录；不修改生成源数据或规则实例。进入救助前，除检查开路已完成，还检查三路的箱子、墙、水和阻挡杂物。完成时先捕获不可变展示快照，再关闭开路活动，所以挪开的箱子、桥和没清理的可选杂物继续留在原地。重新外出新建状态，不沿用上次清理结果。

`SiegeFieldPlan` 只保存可撤销的界面意图，最终仍由原 `SiegeSession.TryOrder` 校验和提交；费用、自然/手动合体、控制状态、改道能力、猫狗动作、结算和入站均保留原规则入口。路线长度变化属于试做场地参数，需重新验证可完成性，不能只把它当皮肤替换。

静态面板增量保存在原 Prefab，保留 GUID 和原版分支。新增 `OutingFieldView`/`OutingFieldGraphic` 提供场地展示，`SiegeFieldView` 管理现场输入；没有运行时拼面板或按控件名字查找。手牌沿用既有有限容量 Cell 池；回合/阶段变化立即刷新，其余动态显示最多每 50 ms 取快照，手牌仅在数据/选择/布局变化时重绑。这不是 0 GC 或真机性能结论。

复杂度复核：场景输入适配器保留一个意图所有者和一个规则入口，未另写救助算法；展示刷新函数集中组合 HUD/输入/场地，Editor 作者函数为一次性静态树装配，参数较多的 Rect/Text 辅助仅在 Editor。未通过 partial 拆分隐藏复杂度。后续调整保存在 Prefab Mode；不得再次运行一次性作者覆盖现有绑定。

来源、状态和精确字节以 `art-source/resource-catalog.json` 与本次检查报告为准。资源仍为 temporary，人工试玩、最终美术/许可和微信下载未验；不自动升级 approved 或正式首批。字体已按新增文案重建 Noto Sans SC OFL 子集（692 glyphs，173664 bytes）。
