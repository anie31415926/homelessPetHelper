# 逆塔防兵种与形象提案

2026-11-20。用户要求设计实际出兵内容、能力和形象，可以参考原救助选项但不局限于它们。本文是待讨论提案，不是全部兵种、美术或新能力已获批准；本轮只记录，不改运行配置、HTML、Unity 或图片。

最新包装方向见第 8 节：用户要求更天马行空，以动物经典印象中的食物、玩具直接作为出战单位。该方向优先于前文统一做成小车/发条装备的建议；较早兵种形象保留为候选，不视为正式定案。

用户随后要求先设计一套完整猫狗攻防内容，当前成套提案见[猫狗攻防内容方案](逆塔防猫狗攻防内容方案.md)：猫狗各 6 类基础/合体、各 3 种机关、各 3 种自身招式及建造/维护、供给与对局推演。具体新增效果仍待确认，未开始实现；本文较早“下一步只确认前三类”不再限制本次成套设计范围。

## 当前事实与提案分界

- 已有 HTML 与 Unity 独立试玩，见[HTML记录](逆塔防HTML首版实现记录.md)和[Unity记录](逆塔防Unity试做记录.md)。不重建原型，也不继续沿用较早“尚未开工”的状态。
- 当前三种基础单位是补给小车、引导球、遮蔽小队；已有升级分别为重装小车、跳跳球、护送伞阵。现有能力包含一次抗击退、升级改道及不叠层护盾；运行值以 `src/siege/definitions.json` 为准。
- 下文前三类补齐包装与形象方向，不声称新发明这些现成功能。摇摆玩偶、夹子工兵及其能力完全是新增候选，尚未实现。
- 双行动条、暂停窗口、场上三合一及点数机制不因兵种提案重开。不同物品的拟人化是游戏表达，不是现实救助方法或每只动物必然爱吃、爱玩、接受遮蔽的判断。

## 1. 总体形象方向

推荐“救助者想象中的道具小队”：食盒、玩具、软垫和日常工具组成微型发条装备，面对相对巨大的动物防线。不是派真人或其他待救动物上场挨打，也不把退开、慢眨眼等抽象行为全部拟成魔法士兵。

沿用现有绘本笔触、薄荷与珊瑚点缀。兵种用轮廓、材质、移动方式区分，不只换颜色：小车低矮方形、球圆形跳动、遮蔽拱形、玩偶竖长摇摆、夹子双钳。仅在玩偶等适宜物品上保留简短表情，不给所有车箱贴同一张脸。

主要行为必须看得见：轮子卡住是在受阻，护垫凹陷是在承受一次攻击，弹簧跨向新路才是改道。被打散用翻倒、零件散开或道具退场，不表现生物受伤；不把散落物做成可无限回收的合体材料。

合体沿用选定主体的位置，其他两件成为可辨认的结构部件，而不是三枚图标缩进一个发光圈。免费自然合体与付费主动合体结果一致，付款购买调度便利，不购买更强配方。升级不默认满血、无敌或重置已锁定预告。

## 2. 第一批：三类基础兵与三种合体

### 补给小车 -> 重装补给车

- 来源：放食、物资准备。不是要求每次救助都先喂一餐。
- 形象：矮四轮车，敞口食盒和固定绑带；升级增加双轴底盘、宽轮与前置软垫，仍能看出是同一辆补给车，不做炮筒或履带坦克。
- 普通能力：耐久较高、速度偏慢，遇沿路炮台停下拆除机关，是稳定推进和拆塔主力。
- 合体变化：保留当前重装的一次抗击退；前垫承受后明显瘪下。免除这次位移不免除损耗，之后仍会被推退。
- 弱点与取舍：行军慢，面对持续火力会掉耐久，不能靠一次抗推永久穿过守门。三车合一也会减少分担火力与分路的目标数，不默认所有数值都优于三辆总和。
- 爽点：顶住一次横扫，保留已经争取到的前进距离。

### 引导球 -> 弹簧跳跳球

- 来源：适宜玩具和转移注意的游戏化改编，不把玩耍变成正式救助前置。
- 形象：珊瑚色分瓣球，短布带标明前进；升级增加两个可见弹簧环和折叠支脚。滚动、压缩、弹起构成独立动作语言。
- 普通能力：跑得快、耐久低、拆塔弱；适合提前走长边路，在防守空档抵达。普通球不自带转线或躲避概率。
- 合体变化：保留当前升级球的一次主动改道。策略窗口预览目的地，恢复推进后实际经过空间路径，不瞬移、不自动免伤。
- 弱点与取舍：换路可能仍在同一个横扫圆或炮台射程内，得看真实落点；强行打密集塔线容易被消耗。不能把“跑得快”解释成永远无法被命中。
- 爽点：对方锁定一片区域后，选择另一条真正离开危险区的路线继续推进。

### 遮蔽小队 -> 护送篷车

- 来源：遮蔽、减少干扰。名称和形象提案不自动重命名现有配置。
- 形象：带布帘的拱形小推架；升级由三片篷布拼成更宽的移动顶棚，帘边和支架保留清楚的前后关系。避免只有漂浮的盾图标。
- 普通能力：保留现有近距离周期护盾，给附近友军一层抵挡损耗的保护；自身也能缓慢拆塔、独立推进，不是必须配另一张牌才可出场。
- 合体变化：覆盖范围更大、补保护节拍更快，变成混合队伍的护送核心。视觉上让被保护单位出现短时布纹边缘，挡住后立即消退。
- 弱点与取舍：盾不叠层、不自动抗击退；队伍离开覆盖就不能继续获得新盾。集中在篷车附近有协同收益，也容易被真实范围横扫同时命中。
- 爽点：保住塔下等待第三个同类的前线材料，但不是把它们放进安全仓库。

以上沿用当前能力骨架；篷车护送不代表新增自动编队、速度同步、自身无限补盾或无敌。如何表达单体护盾的演出在制作前核对真实规则。

## 3. 第二批候选：改变打法，不先全部塞入牌池

### 摇摆玩偶 -> 不倒翁诱饵

- 来源：注意力周旋的想象化扩展，不等于真实动物必然受玩具吸引。
- 形象：细长布偶装在摇摆底座上；升级出现重底盘与可脱离布偶罩壳，轮廓与球、车、篷都不同。
- 普通能力提案：进入一座炮台的真实射程后，短时吸引它的单体火力，让同路主力争取推进机会；同一目标不能被多个玩偶无限接力控制。
- 合体变化提案：本体被打散时留下短时假身，额外承接有限次已锁定的单体火力；假身不计进度、不算合体材料，到期消失。
- 限制：不吸引射程外炮台，不取消已锁定横扫，不冻结动物行动条，不强制动物换边。牺牲诱饵也真实损失这部分进度潜力。
- 战术区别：用一个单位换取火力空档，而不是给整队加防御数值。更适合提前部署，不是看到即将命中的炮弹才从出生点瞬间救场。

### 夹子工兵 -> 拆塔钳车

- 来源：新增的机关拆解兵种，不把专业救助、喂药或现场医疗包装成对动物攻击。
- 形象：两片宽木夹加发条轮，升级成为双钳小工作台；钳口只对着玩具机关，不夹动物身体。
- 普通能力提案：贴近炮台后夹住发射部件，短时延长该塔下一发的准备时间。自己也有弱拆塔能力和一次抵达作用。
- 合体变化提案：具备一次无需先摧毁炮台即可打断其正在进行修补的拆解动作；修补已结束则不能倒扣已补耐久。中断与守方已消耗修补次数如何衔接需核对规则，不能重复领收益。
- 限制：不能远程关掉塔或全场沉默；多工兵不叠加到永久停火，目标须有清楚恢复期。对动物近身守门和无塔路线价值较低，不能取代补给车的持续拆塔。
- 战术区别：抢一个施工/射击节奏，队友负责后续推进。目标清楚，效果可读，不依赖概率暴击或隐藏克制。

两类新增单位的强度、控制时长、触发次数、费用和材料存活均未验证。本提案不把它们作为玩家必须抽到的唯一解。

## 4. 同一局面中的不同用法

设中路塔下已有两辆受损小车，手中有第三辆；猫预告横扫前线，边路已有一只提前出发的引导球。

1. 花费出兵和合体点数，以前线车为主体成为重装，保留推进距离；仍吃损耗，是否撑得住看实际耐久。
2. 以后排车为主体合体，争取远离横扫锁区；可能保住材料但丢掉前进距离，不是免费避伤传送。
3. 这回合先给前线补护送，赌两辆撑到第三辆真正赶上，自然合体省费用；盾不防推，材料仍可能来不及。
4. 暂不追这组车，继续投入边路，借中路牵制争取另一端抵达；新的出生单位不能凭一句“分路”立刻赶上当前空档。

加入扩展后，诱饵多出分担单体火力的选择，工兵多出打断修补的选择。它们不应同时成为破解横扫的万能答案。

## 5. 为什么不把所有旧选项都变成兵

- 退开、等候、观察和低压姿态是玩家/动物行为，不适合每个都生出一个往前走的单位；是否转为战术指令以后另议，不借本提案扩建法术牌系统。
- 抚摸不做巨手兵，医疗不做注射/镇静弹，专业求援不变成抽不到就无法退出的稀有单位。
- 回消息、拍照等插曲保留轻松包装可能，不凭空生成社交增益或让手机远程给动物扣数值。趣味可来自小车绑带松开、玩偶挨打还在摇的画面，不必每张卡都讲段子。
- 所有兵的抵达仍只按当前挑战的“一次作用后退场”理解。食物、玩具、篷布的演出不证明动物实际需求满足、允许触摸或接受安全转运；正式接续另议。

## 6. 推荐顺序与下一步

先确认“道具小队”的主体形象，以及前三类是否值得继续深化。第一批只做三基础加三合体的清晰轮廓与效果；后两类先作为候选，不为了丰富度同时扩大抽袋，导致三个同类长期凑不齐。

如要试新增兵，建议在独立对照配置中一次替换一个基础类别，保留与现有三类相同的供给规模；是否采用替换方案仍待确认，不默认增加局外配队或养成。

待确认后才制作概念图/原型效果。需要实际检查小尺寸辨认、普通兵独立作用、三合一的材料与单位数量代价、范围反击和不同组合收益。当前只有设计推演，未生成图片、未修改代码、未运行新的战斗测试，不声称已经耐玩或平衡，不提交推送。

## 7. 多动物与持续扩展要求（2026-11-20 补充）

### 用户已明确的约束

- 防守方不限定为猫，至少覆盖猫、狗，并考虑其他动物及品种。前文以猫描述的局面仅为样例，不是动物类型限制。
- 我方会持续设计并加入新的救助手段；可从真实救助手段提炼、抽象，不把当前三类或本文候选当成固定兵种全集。
- 双方内容扩展须成为代码设计的正式要求，不能每增加一种动物或单位，就复制一套战斗、发牌、合体或防守流程。

本节具体拆分与例子仍是设计建议；不代表新增兵种、动物能力、克制关系或代码改造已经获准。

### 内容设计建议

我方统一按“真实方法 -> 战术作用 -> 出战形象 -> 合体变化 -> 弱点/反制”设计。食物引导、玩具引导、遮蔽降刺激、熟悉物与气味、清障和安全通道都可以提供灵感，但不是必须全部成为兵种，也不在本轮新增法术牌系统。装备修补等属于器材保障的衍生设计，不强称为直接作用于动物的现实救助方法。

动物拆开考虑种类/品种、个体状态、防守能力组合与表现。同种动物可以有不同打法；品种不自动等于固定性格或难度。状态可以影响行动条、能力参数和选择偏好，但能力集合及调整边界需明确配置，不能让所有动物只共用守门接横扫，也不能失去预告与反应机会。

机关优先使用纸箱、软垫、滚筒等环境道具作为共用基础；猫抓板等特定包装只用于合适的内容。动物可以拨、推、叼道具来表现布置与维护，不要求每种动物都有相同的拟人化造塔动作。

猫的拍击、狗的鼻顶可以复用合适的近身推离机制；狗的吠叫、其他动物的特色动作可另提能力，但范围、预告和效果须与动作对应，不能只换皮后仍显示不一致的命中区。这些例子不是已定技能。

### 代码演进建议与实际差距

继续沿用现有纯 C# 规则、配置、会话状态和 Unity 表现分离，不为扩展另建一套框架。当前检查到的实验版仍只有单一 `tower` 定义，动物决策含固定守门接横扫，单位能力限于 `none/aura/brace/reroute`；已经解耦不等于已经支持任意内容。

建议按真实新增内容逐步补齐以下边界：

- 单位定义引用能力组合与明确的合体结果；机关拥有独立定义，塔位/实例引用对应定义，不再共用唯一塔参数。合体仍保留现有场上三个同类规则，不借数据拆分新增混合配方。
- 防守配置描述可用动作、可布置机关、行动节奏和选择偏好；动物身份/外观与这些规则分开，装配时校验组合是否适用。个体状态和每局冷却、次数、锁定目标不写入共享定义。
- 能力将触发时机、目标/空间范围、效果和次数/冷却说清楚。推离、减速、保护、修补等真实复用的规则统一归属；全新机制允许增加专门逻辑和测试，不把所有行为强塞进万能配置脚本。
- 表现绑定动作、预告与效果反馈；命中、持续时间和结算由模拟规则决定，不由动画回调决定。不同身体尺寸和动作的预告区必须对应真实判定。
- 内容库与本局供给分开：新增定义不自动加入所有抽袋，也不自动替所有动物开放。如何保持三合一可达性仍需讨论，不默认引入局外配队或固定克制表。

扩展验收以具体操作为准：复用既有能力的新单位或动物组合应主要增加定义、引用和表现；真正的新机制新增所属实现与测试，不需要重写出牌、合体和战斗时钟。实施时再补组合、暂停冻结、合体状态转移、控制叠加/恢复、预告锁定与空间判定等回归验证。

本次只更新本提案，未修改配置、运行代码、Prefab 或图片，未运行新的战斗验证。

## 8. 最新包装方向：动物经典印象中的物品直接出征

### 用户明确的方向与例子

包装要比统一的救助工具小车更天马行空，可以使用动物经典刻板印象作为易懂的形象语言。用户举例：猫的食物引导可以直接出小鱼干，玩具是毛线球；狗的食物引导可以是骨头，玩具是飞盘、棒球。

真实救助手段提供创作来源，不要求物品写实移动，也不要求统一安装轮子、底盘或发条。可以让小鱼干摆尾前进、骨头翻着跟头走、飞盘旋转沿路前行。合体允许从三件物品组装、编织成夸张的新形态，不局限于加大同一张图。该表达不新增飞行绕塔、越过路线或自动克制规则。

### 进一步推演的形象候选（尚未确认）

| --- | --- | --- | --- |

| 猫 / 玩具引导 | 毛线球 | 毛线狮子 | 基础滚动、拖短线尾；三团毛线编成有鬃毛的玩具狮子 |

### 与扩展设计的衔接

区分救助手段类别、具体单位定义和表现资源。小鱼干与骨头可以复用适合的推进规则，也允许拥有不同能力；不以动物类型为条件，在战斗流程里散落换名、换图、换能力的分支。

动物主题可以作为内容组合的选择依据，但不直接确认自动换牌、局外配队或每只动物专属一整套单位。若未来按救助对象选择本局内容，应在开局装配时明确实际单位及合体结果，不能在场上静默换成另一种单位。经典印象用于快速识别和趣味，不自动成为物种间的硬克制表。

防守方也可以沿用这种夸张尺度：猫的纸箱阵地、抓板机关；狗的狗窝阵地、玩具发球机，以及拍击、叼走、飞扑等差异化动作。具体防守效果继续单独讨论，不只是给所有动物换皮后使用同一套招式。

本次仅记录包装方向与候选，没有制作美术、改动代码或新增战斗验证。
