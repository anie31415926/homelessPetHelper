# 社区援助金与救助站成长

首版试玩目标：每次成功救助除了接回动物，也能积累援助金，让救助站有更大的接收能力、更顺手的护理流程，以及新的出战选择。

| 产出 | 援助金 | 触发条件 |
| --- | ---: | --- |
| 成功接回 | 100 | 动物实际入住，结算存档成功后显示。续玩或重复打开结算不会再发一笔。 |
| 首次基本评估 | 50 | 每个存档首次完成评估时发放。 |
| 首次完成领养 | 50 | 每个存档首次完成领养时发放，登记待领养不发。 |

| 消耗 | 援助金 | 生效方式 |
| --- | ---: | --- |
| 扩建床位 | 250 | 一次性增加 2 个临时照护名额。新档默认 6 个，扩建后 8 个；旧档沿用原容量。房间可显示新增住户，首版沿用现有房间素材。 |
| 升级清洁台 | 150 | 洗护完成后，满足正常梳理条件时可直接转到梳理。基础评估、洗护、梳理仍然免费。 |
| 解锁木夹子 | 100 | 买一次，可自由装备或卸下。装备后从下一次逆塔防起替换牌组中的一张卡；局内继续用关卡能量部署。木夹子是独立干扰牌，不参与合体。 |

从救助站角落的菜单进入「站内建设」，逐项切换查看余额、价格和拥有状态。购买复用站内弹窗；余额或前置条件不足时不能购买。扣款、商品状态和扩建容量一次写入，写入失败不改变余额或床位。新档两次成功救助，加一次评估即可攒够首个扩建。

数值和木夹子单位引用从 `Assets/Settings/Game/StationEconomy.json` 读取。奖励、价格和初始容量可以独立调整；旧档不追发过去的奖励。站点存档从 v4 迁到 v5，新增余额、一次性奖励标记、购买和装备状态，原住户和出行记录继续使用。关卡中的木夹子沿用已存在的试做单位配置；不为已经出发的关卡改手牌。

这一版先看玩家会优先扩建、升级清洁台还是解锁手牌，以及奖励节奏是否让玩家愿意回访。暂不接实物补给、寻宠奖励、付费或每日周常限制。以上金额是首轮试玩值。

## 试玩与验证

本轮实现保留在 `test-results/station-economy-worktree/unity/HomelessPetHelper`，打开 `Assets/Scenes/Main.unity` 试玩。该工作树的业务文件基于 `9448265`，暂未合入主工作区。自动化测试使用内存存档；两个工程的手动试玩沿用同一个本机存档路径，如需保留旧版读档能力，先备份 `main-progress` 再让新版写入。

定向核对了救助、评估、购买失败回滚、扩建后 8 个显示槽的复用、洗后接着梳理、领养和装备编队，以及 v4 迁移和局中读档。定向报告保存在 `test-results/station-economy/`。
