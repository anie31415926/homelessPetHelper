# 逆塔防五卡构筑试做

2026-11-24，按已确认方向试做：单场携带五种，手牌仍为三张；普通出战卡区分 1～4 费，多数靠站位和时机搭配，少数可以合体。以下费用、耐久和技能参数是试玩起点。

Unity Editor 中选 `Homeless Pet Helper > Preview > Five Card Siege > Sustain`（续航）或 `Breakthrough`（突破）。两个菜单使用同一猫阵地、资源规则及随机种子，开局手里都有小鱼干、小羽毛和本套的特色卡，下一张先补毛线球。Play Mode 中可以再次选择菜单切换阵容，结束后点返回可以重试当前阵容。

| 卡 | 费用 | 出战用途 |
| --- | --- | --- |
| 小羽毛 | 1 | 快速抢空路，拆塔弱，抵达只贡献 3 点，避免单靠便宜卡刷进度。 |
| 小鱼干 | 2 | 慢速稳定拆塔；两只同类可以手动合成鱼干花束，另付 1 点，按材料耐久比例继承。 |
| 毛线球 | 2 | 给附近伙伴套护套。适合跟在重兵后面，分摊前线损耗。 |
| 木夹子 | 2 | 贴到机关并打中后延后下一次射击，每只成功一次，同塔有免重复干扰间隔；不取消已进入蓄力的攻击。 |
| 旧围巾（续航） | 3 | 有限次数修整最近的受损同伴，不能修自己。前排已有损耗时再跟进更合算。 |
| 重装补给车（突破） | 4 | 步速慢，首次打到机关有一击额外伤害。开局可以直接支付全额，但下完要等资源才有支援。 |

出牌后按队列补一张，刚打出的单位类型回到队尾。出牌被拒绝时手牌、资源和队列都不改变。队列状态随本场战斗回放恢复。合体只在鱼干上开放，试做中不自动触发；其余卡均靠部署和基础能力发挥。

[试玩配置](../src/siege/loadout-trial.json)定义牌序、原型数据覆盖和文案。由 `node tools/siege-unity-data.mjs` 生成本地 Editor 试玩配置，正式猫狗配置的内容与手牌生成方式保留。加一个现有能力的新单位时，填费用、能力参数和可选合体配方，再配置上阵列表；只有新增触发机制才需要改规则代码。表现复用现有战场、图标与效果缓冲，本轮图标是占位。没有新增商店、收藏存档、正式选牌页或正式场景入口。

试玩时重点看：1 费牌是否成为唯一合理的循环牌，4 费牌能否在命中关键塔时值得等，以及换一张卡是否改变了放兵顺序和落点。费用与技能强度按这些反馈分别调整。

验证覆盖了两套入口、正常与资源不足时的出牌、两单位合体、回放恢复，以及重车的一次重击和围巾的有效修整。下一张提示使用可复用战斗表现缓冲，只在牌变更时更新；手机触控、单位上量后的帧率和整体平衡仍待实玩。
