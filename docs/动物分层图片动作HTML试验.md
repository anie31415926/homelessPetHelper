## 可行性结论

**首版历史结论是分层图片+挂点+程序动画；后续已完成单图网格、单远后腿以及完整远侧前后腿补全，以上方检查点为准，仍不是把一张整图自动变成骨骼。** 首版两张图集可驱动九个部件，不需要每个动作重新生成整猫；同物种可以共用骨骼语义与动作采样，视角、体型、品种各自有挂点/比例/图集参数。

正侧站姿是比例参考，单张扁平图没有藏在身体后面的四肢、耳根或毛色。需要遮挡变化的大动作应评估同源分层与隐藏区域补画；不意味着轻微动作也必须逐件裁成图片。不同视角切换是替换贴图/挂点，不是连续3D旋转；猫狗不能仅换皮强共用完整解剖结构。短腿/修长仅参数试验，不是已确定品种资产。

本机ComfyUI五次生成画风接近，但九宫格/无头躯干/真透明未稳定遵循，因此本批通过可追溯裁切、去底和挂点人工校准才可动。不能承诺只输入正侧图就全自动批量生产。

## 当前限制

1. 耳和腿部分复用，后肢没有专用大腿/小腿，脚步是根部转动加轻微抬脚，不是自然步态或IK。前视与侧视精细程度不一致。
2. 尾巴目前整体绕尾根摆动，不是多节柔性尾骨；大幅卷曲需要沿尾部拆段或做网格形变。
3. 头身/耳根仍有裁切痕迹、白边；调到极限角度会露出拼接。动作切换是直接切姿态，不当成正式过渡系统。
4. 开心/伏低是小范围姿态样例，没有躺卧、翻滚、连续转身、真实跑跳。清洁遮罩/伤口位置随骨骼变形尚未接入。
5. 未安装Spine或其他运行时；本轮不选择生产框架，不声称微信兼容、目标机性能或商业来源通过。
