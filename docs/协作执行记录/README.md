# 协作执行记录

本目录保存按任务追加的 JSON 记录。共同方向和文件占用仍在[当前协作状态](../当前协作状态.md)及[任务目录](../协作任务/README.md)维护；记录用于检查本次协作上下文的版本、会话和申报范围，不另建任务状态表。

## 开工、接续与交付

在任务文件中先登记用户授权、状态及 `collaboration` JSON 块，精确格式见[任务模板](../协作任务/README.md)。`sessionId` 填实际会话标识；`writePaths` 使用仓库根目录相对路径和 `/`，列精确文件或以 `/` 结尾的目录，不使用通配符、绝对路径或 `..`。写入范围须包含自己的任务文件和 `docs/协作执行记录/<任务文件名去掉.md>/`。

以下命令从仓库根目录运行，使用现有 Node >=20.9，无第三方依赖。若工作目录在 Unity 工程下，脚本位置改为 `../../tools/collaboration.mjs`，`--task` 仍相对仓库根目录。不会修改 `package.json`、安装 hook 或改变工具权限。

1. 读取当前上下文：

   ```bash
   node tools/collaboration.mjs read --task docs/协作任务/<任务文件>.md
   ```

   命令完整输出根 `AGENTS.md`、当前协作状态、任务模板、本说明、全部未结束任务及本任务，最后输出 `contextDigest`。阅读输出并人工核对授权、其他任务范围和目标路径实际改动；出现重叠先协调。

2. 阅读后显式确认输出的指纹：

   ```bash
   node tools/collaboration.mjs ack --task docs/协作任务/<任务文件>.md --session <实际会话ID> --phase start --digest <read输出的contextDigest>
   ```

   `--phase` 使用 `start`（开工）、`resume`（接续）、`scope-change`（范围变更）或 `delivery`（交付）。每个阶段重新执行 read → ack，不沿用上次的指纹。ack 会再次读取并核对上下文，发现变化则拒绝生成记录；成功后在本任务目录追加新 JSON，不覆盖历史。

3. 开始写入及交付前检查：

   ```bash
   node tools/collaboration.mjs check --task docs/协作任务/<任务文件>.md --session <实际会话ID>
   ```

   检查最新记录与当前文件是否一致。失败时按具体原因更新任务、重新读取/协调并确认，再检查；不能直接修改 JSON 指纹消除失败。已完成或已取消任务只允许登记 `delivery`，不会隐式重启任务。收尾时先更新任务状态、验证和路径释放，再 read → ack（delivery）→ check，避免任务收尾后留下失效记录。

本工具的接入是本轮自举过程：工具可用前的实现没有开工记录，不追补为“此前已确认”。后续任务和本轮剩余操作使用实际时间的记录。

## 检查内容

- JSON 包含版本、任务、会话、阶段、工具再次读取上下文的 UTC 时间 `readAt`、申报的写入范围、每个输入文件的 SHA-256 和组合指纹。指纹按原始字节计算，换行变化也会使记录失效。
- 检查是**指定任务级别**：记录缺失、格式损坏、任务/会话不符、范围变化、文件内容或未结束任务集合变化均返回退出码 1。成功返回 0，表示这份记录与检查时的协作上下文一致，不代表全项目已补齐记录或所有路径没有冲突。
- 超过 60 分钟的记录视为过期；时间无效或在未来也失败。持续工作约 30 分钟以及范围/验证结论变化时，先更新任务，再重读并追加记录。过期不释放文件占用，历史记录仍保留。
- 按 UTC 时间文件名选择最新 JSON；最新记录损坏时失败，不回退到旧记录。最新时间相同的并发记录无法确定先后时也失败，需要重新读取和确认。
- 其他任务尚无结构化范围时仍完整展示并警告人工核对；缺少或不符合模板的状态也保守保留为未结束，不通过文案猜测已释放。只由原负责人补齐，本工具不修改其他任务。

## 能力边界

记录证明工具读取过这些版本，并保存了会话申报；不能证明模型理解、不能认证会话身份、不能验证用户授权，也不自动审定文件占用冲突。检查与后续写入间仍可能发生并发变化，遇到变动必须重读协调；这是协作记录，不是系统锁或强制写入拦截。

工具只追加本任务记录，read/check 不写入；不要把任何历史记录或本次 PASS 当作 Unity、源码快照可信度、玩法、图片、渠道或真机验证结果。统一工程验证入口尚未接入本工具。

针对本工具运行：

```bash
node --test tests/collaboration.test.mjs
```
