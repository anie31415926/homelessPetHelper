# 猫坐下：骨骼结构与当前试做纠偏

2026-11-23，Asia/Shanghai。用户要求先查网上猫坐下的骨骼结构，暂停继续凭观感调曲线。本轮只研究、留证，不改动画或正式Unity。

## 结论先行

上一版解决了“几何被压扁”，没有解决“坐姿结构正确”。定长IK可以得到不自然的姿态，101姿态骨长/面积通过不能作为解剖或运动验收。

当前最明显的结构问题是：骨盆仍高、膝低于髋、跗部仍悬起，跗到脚的段到终点几乎竖直且向后，而不是在后躯下方收拢。因此看起来是后腿折一下配合身体下沉，不是坐稳。

## 后腿应该怎样理解

从身体到地面的简化链为：

```text
骨盆/髋臼 -> 髋关节 -> 股骨 -> 膝关节(stifle)
         -> 胫骨/腓骨 -> 跗关节(hock，踝部)
         -> 跖骨 -> 趾关节/趾骨 -> 地面接触
```

- 向后突出的关节是跗部，不是膝。膝在它的前上方，常藏在大腿肌肉与毛皮轮廓内；不能沿外轮廓最突出的折点直接设膝。
- 站立时猫为趾行，跗部抬离地面；跗到趾并不是不存在的一小段“脚踝”。坐下时必须观察这段的转动，不能只折股骨和小腿、把末端继续竖着撑住身体。
- 在本轮坐姿骨架参考中，髋已降到膝的后下方，股骨从髋向前上方连接膝；胫部从膝向后下方回到低位跗部，跖/趾部再向前延伸，形成收拢的后肢。这个相对关系比套用某个角度更重要，不把单张装配姿态视为所有猫的唯一坐法。
- 骨盆、腰椎、胸廓和前肢共同决定坐姿。不能只让圆形大腿贴图向下转，胸腹/腰背仍沿站姿逻辑拉扯；也不能把外轮廓圆鼓部等同于整根股骨。
- 前后爪是否先调整落点、何时承重或允许趾部滚动，必须以选中的连续实拍为准。“四只爪全程固定”只是旧试做的约束，不是本轮查证的猫通用动作规律。

## 对照当前试做的客观问题

本轮只读采样`rig.apply(1)`，近侧后腿原图坐标如下，猫朝左，x增大是向后，y增大是向下：

| 控制点 | x | y |
| --- | ---: | ---: |
| 髋 | 311.00 | 405.00 |
| 膝 | 219.28 | 423.20 |
| 跗 | 281.93 | 431.01 |
| 足端 | 291.00 | 477.00 |

与上面的坐姿空间关系相比：

1. 膝仍低于髋约18像素，股骨接近水平向前下，不是骨盆落到膝后下方的收腿姿态。
2. 膝到跗几乎横走，跗到足端近乎竖直且向后；主要折叠与落地关系错配。单纯增大现有关节旋转幅度不能证明修好。
3. 终点脚趾比跗部更靠后，和所选常规坐姿参考的跖部向前展开相反，应先重设目标姿态和弯曲分支。
4. 旧说明称髋“向后26像素”，实际源码是`x -= 26`；猫朝左，因此这是向前。此处是先前说明错误，不据此直接断言所有猫坐下都必须向后移动。
5. 保持整块大腿完全刚性可防压扁，但真实肌肉/毛皮覆盖不等同于硬纸片。骨架正确后，仍须根据遮挡和体积做有限修形，不能反过来用修形掩盖错误的关节位置。

这组坐标只说明原型，不是生物测量。原图为Q版，不能直接把网上骨长比例硬搬进原图。

## 后续制作顺序，尚未执行

1. 先选一段全身入镜、固定侧面、无切镜的真实站到坐视频，记录帧率与首尾时点；训练视频里有剪辑的段不能拼成连续轨迹。
2. 在同一坐标中先标胸廓、骨盆、髋、膝、跗、跖趾与接地点，至少做站立/预备/下降/接触/坐稳5张无贴图骨架。骨盆朝向和腰背也一并核对。
3. 先看低位坐稳姿态是否成立，再检查中间轨迹、支撑和接触切换；允许真实参考中存在的调整脚步，不强制所有足点全程锁死。
4. 骨架小样通过后再绑同源图，补隐藏面与遮挡，最后才调毛皮轮廓和缓动。IK只负责约束求解，不替代参考动作设计。

## 2026-11-23 接续：实拍补看与骨架小样

用户认可结构解释后授权继续。补看[Best Friends Animal Society / HowTo Train Your Cat sit](https://www.youtube.com/shorts/wf2AHjtUclI)，播放器时长46.081秒。实际播放并暂停检查0.676、13.775、19.742、31.617、32.550、33.132、33.569、34.151秒：32.550时灰白猫站立，33.132时后躯下沉，33.569时已坐；34.151切到另一正面构图。33.569秒截图保存在`test-results/pet-transition-research/bestfriends-33-57s.jpg`。

这段能辅助看见后躯下落、前躯维持支撑高度以及尾部放落，但不是合格的骨骼轨迹测量：猫呈斜侧/背侧，毛皮和播放器悬浮缩略图遮挡局部，未取得逐帧关节标点、可信源帧率或完整固定正侧面证据。不得声称从该段量出膝/跗角度，也不把零散暂停帧拼成无切镜侧面动作采集。

因此下一产物明确降格为**解剖关系驱动的侧面动作blocking**，不是动捕复刻、生物力学仿真或最终动作验收。已单独实现[骨架小样](猫坐下骨骼小样.md)，保留站立/预备/下降/接触/坐稳5姿态和定长关节链。前爪交替小步与肩胛位移是为建立支撑的手工动画设计，不宣称本实拍精确证明了这些轨迹。旧贴图版、旧55项输入、Unity与ComfyUI均保持不变；待用户先看骨架，再决定是否进入贴图绑定。
