# 逆塔防单位情报与首战指引设计

2026-11-26 第三版。方向已由用户确认并追加要求：文案要像"产品介绍"而不是大白话，突出可爱与幽默；数值不再给具体数字，全部换成统一档位的形容词；费用只显示图标；没有特殊能力就不写，有合体就写合体；不写短板。

本文只解决"看得懂、学得会"，不改规则、数值、平衡、存档与美术绑定。

- 图标条：[8 个通用图标](../art-source/siege-codex-20261126/icons/preview.png)

## 1. 现在缺什么

| 现状 | 玩家因此卡在哪 |
| --- | --- |
| 手牌只有「名称 + 费用」 | 不知道小鱼干和毛线球有什么区别 |
| 脚标只有名称与耐久 | 看不到威力、射程、抵达贡献 |
| 机关只是纸箱/水碗占位 | 不知道它在打人、减速还是推退 |
| 动物只有意图条 | 不知道"按住/叼走"停的是谁、停多久 |
| 首战只有两步强指引 | 没有目标、资源循环、拆塔顺序 |
| `detail.*` 文案没有界面显示 | 数据在，玩家看不到 |

上一版的问题是：数字对新手没有意义（不会有人去算"30 的射程够不够"），而大白话又太像说明书、少了角色感。这一版把两者换掉。

---

## 2. 设计目标

1. **一个固定位置**：12 张道具卡、6 座机关、2 种阵地的动物技能都能随时查到。
2. **第一场能教会**：目标、费用与资源、拖牌到路线、预览与执行、机关威胁、动物干扰、合体、胜负。
3. **只讲感受，不讲参数**：属性用档位词，具体怎么算交给游戏自己；屏幕不堆说明。

## 4. 情报面板

### 4.1 结构与层级

- 纸底模态，进现有 `Widget_LevelOverlays` 弹窗栈，共用 88/255 黑遮。
- 标题「道具与机关」+ 右上关闭「×」（48 热区）。
- 两个 tab：「我的道具」/「对方防线」，选中用轮廓 + 字重。
- 卡片默认全展开；标题、tab、关闭固定，只滚动列表。
- 打开即暂停；关闭恢复；返回键优先关这一层。

### 4.2 尺寸与排版

| 项 | 取值 |
| --- | --- |
| 弹窗宽 | 安全区宽 − 32L，最大 360L |
| 弹窗高 | 安全区高 − 64L |
| 内边距 | 弹窗 16L；卡片 8L；卡间距 8L |
| 卡片 | 高 ≥ 136L，左图 64L，右文字区 |
| 名称 | 18 号 |
| 属性词 | 14 号 + 20L 图标 |
| 描述 | 16 号正文 `#2A3D30`，最多 3 行 |
| 能力 / 合体 | 14 号次级 `#384D41` |
| 应对 | 14 号暖棕 `#8E4D30` |

顶部固定副标题：**送到它面前，信任满 70 就能带回站。**

### 4.3 我方卡字段顺序

```
[道具图]  小鱼干                              [饭碗] 2
          ♡ 耐久 一般   ✿ 威力 一般   ⧗ 出手 一般
          ↔ 射程 近     » 步速 慢     ⌂ 抵达 一般
          描述：猫记食品厂出品，东海小鱼十八道工序慢烘，
          没有一只猫能拒绝它的味道。
          合体：三条小鱼干可以合体，能力全面增强。
```

- **费用只放图标 + 数字**，不出现"费用"两个字。图标用一碗饭（用户建议），全场通用易懂，也贴合"用食物换信任"的主题，不用新造货币符号。
- 属性在前，描述在后：先给判断，再给味道。
- 没有特殊能力就不写「能力」行；能合体的，写「合体」。

### 4.4 对方卡字段

机关卡：名称 + 属性词（耐久 / 射程 / 出手 / 预警）+ 描述 + 应对 + 同类（另一阵地叫什么）。
动物卡：一张写三条技能（守门 / 横扫或飞扑 / 按住或叼回），每条用"什么时候出现、打谁、多久一次、之后多久不碰它"，再加一张"出招节奏"卡。

### 4.5 属性词表（候选，**未定稿**）

用户要求属性词"先不定死"。下面三套候选只用来撑版式和示例文案，**定稿前不写进配置，也不改卡面相关键**。

| 方案 | 耐久 | 威力 | 出手 | 射程 | 步速 | 抵达 | 特点 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| A 三档形容词（预览现用） | 脆/一般/耐打 | 轻/一般/重 | 快/一般/慢 | 近/一般/远 | 慢/一般/快 | 少/一般/多 | 最短，扫一眼能排序 |
| B 感受句 | 一碰就散/还行/很扛 | 挠痒痒/一般/很疼 | 眨眼一下/一般/慢半拍 | 够不着/一般/很远 | 慢吞吞/一般/一溜烟 | 一点点/一般/很多 | 有角色感，但词长、卡面变挤 |
| C 只画档位 | ●○○/●●○/●●● | 同左 | 同左 | 同左 | 同左 | 同左 | 最省地方，但新手未必会读 |

A 的分档线（示例）：

| 属性 | 三档词 | 分档依据 |
| --- | --- | --- |
| 耐久 | 脆 / 一般 / 耐打 | 4–5 / 6–9 / 10 以上 |
| 威力 | 轻 / 一般 / 重 | 1 / 2 / 3 以上 |
| 出手 | 快 / 一般 / 慢 | 0.8–0.9 秒 / 1.0 秒 / 1.2 秒 |
| 射程 | 近 / 一般 / 远 | 26–30 / 32 / 48 以上 |
| 步速 | 慢 / 一般 / 快 | 20–22 / 23–26 / 32 以上 |
| 抵达 | 少 / 一般 / 多 | 8 / 10 / 24 以上 |

要你拍的四个点：

1. **档数**：三档够不够，还是四档（很脆/偏脆/一般/偏耐打）？三档省字，四档能拉开 7 血和 9 血的差别。
2. **词性**：形容词还是感受句（B）？
3. **是否共用一套**：每个属性各用一套（耐久脆、威力轻），自然但词表长；统一"低/一般/高"最省事，但没画面感。
4. **"一般"要不要换**：可换"普通""还行"。

不管选哪套，**映射只做一处**（数据层 hp/damage/attackMs/reach/speed/gain → 档位），UI 只取词，禁止卡面另写数字；"抵达"是否保留也一并定。

### 4.6 属性说明（解决"看不懂"）

面板底部固定一块「这些词是什么意思」，两列六行，永远可见，不需要点开：

| 图标 | 词 | 一句话 |
| --- | --- | --- |
| ♡ | 耐久 | 能挨几下才倒 |
| ✿ | 威力 | 一下能打掉多少 |
| ⧗ | 出手 | 两下之间隔多久 |
| ↔ | 射程 | 站多远就能打到 |
| » | 步速 | 跑得多快 |
| ⌂ | 抵达 | 送到它面前能加多少信任 |

底部再加一行小字：**这些词只是大概感受，具体怎么算，打一场就懂了。**

### 4.7 图标规格（已出图）

1 个费用（饭碗）+ 6 个属性 + 1 个合体，共 8 个：192×192 单色线稿，线宽 10px（显示 20L 时约 1L），图形限制在中央 150×150，四周 21 安全边，颜色 #2A3D30。由 `make-icons.mjs` 生成，改形状改脚本重跑，不手改 PNG。

## 6. 文案：6 座机关 + 2 种动物

机关同样不写具体周期，只写"快/慢""有/无预警"，让玩家先形成威胁感。

| 机关 | 属性 | 描述 | 应对 |
| --- | --- | --- | --- |
| 纸箱纸团台 / 狗窝发球台 | 耐久 一般 · 射程 远 · 出手 快 · 预警 无 | 纸箱改的自动投球机，一颗接一颗，专挑走在最前面的那个。 | 先拆它，或让厚皮的顶在前面。 |
| 毛线绊绊架 / 水碗泡泡台 | 耐久 一般 · 射程 远 · 出手 慢 · 预警 无 | 两根木桩绷着一团毛线，走过去就缠脚，越挣越慢。 | 别在区里磨蹭，一口气穿过去。 |
| 抓板拍爪台 / 拖鞋跷跷板 | 耐久 一般 · 射程 近 · 出手 慢 · 预警 有 | 猫抓板底下藏了弹簧，影子先亮，爪子后到。 | 看到影子先撤人；拆掉它就没这一巴掌了。 |

| 阵地 | 动作 | 玩家感受 |
| --- | --- | --- |
| 猫 | 守门 | 蹲在门口，一巴掌一巴掌地拍，只打最前面那个。最后一个路口最难挤，换一路或者先拆塔。 |
| 猫 | 范围横扫 | 防线快被压穿时急了一眼，扫一片还带推；扫完要收招一会儿。看到预告就散开。 |
| 猫 | 好奇按住 | 伸爪按住一个，只按一个，按一小会儿就松；之后十几秒不碰它。被按的那个等松爪，别的照走。 |
| 狗 | 鼻顶守门 | 用鼻子把最前面那个顶回去。 |
| 狗 | 蓄力飞扑 | 先圈一块地，起跳后过一会儿才落地，半空中不伤人；看圈提前挪人。 |
| 狗 | 叼回去 | 一口叼住往回拖，拖一段就放下；之后十几秒不碰它。别把唯一的单位留在最前。 |

出招节奏卡：**动物会建一座新塔，扛不住时会修补，但修补次数有限。拆塔要拆干净，不然会被补回来。**

## 7. 首战指引

### 7.1 触发与记录

- 沿用 `siege.field` 与 `guidance-progress`，新增 `siege.first-battle.cat.v1` / `.dog.v1`。
- 猫、狗各教一次；同一阵地跨地点不重复。
- 教学期间强制暂停；完成后按玩家设置。
- 跳过也算已学；目标页「重看操作指引」保留。

### 7.2 步骤

| # | 类型 | 气泡文案 | 放行 | 完成条件 |
| --- | --- | --- | --- | --- |
| 0 | info | 把这些玩具送到它面前。信任攒满就能带它回站，这次有时间限制。 | 仅"开始" | 点"开始" |
| 1 | step | 先点一张牌。右下角那碗饭是它的花费；点中以后，上面会写它是干什么的。 | 手牌 | 选中一张牌 |
| 2 | step | 把它拖到左边亮起来的路上，松手就能看见落点。 | 手牌、路径 | 选中路线 |
| 3 | step | 预览不要钱；点「执行」才真的出发。 | 执行、取消 | 执行 |
| 4 | inspect | 点右上「手册」，去「对方防线」看看纸团台——它会一直打最前面的那个。 | 手册、滚动、关闭 | 看过纸团台卡 |
| 5 | tip | 饭是一点一点回上来的，攒够再出下一张。 | 不限 | 3 秒 |
| 6 | tip | 它要守门了：在门口连拍。按住或叼走只针对一个，别的照走。 | 不限 | 首次意图后 3 秒 |
| 7 | tip | 三只一样的加一点饭能合体，会更强，但这次行动就用掉了。 | 不限 | 材料与花费都满足时 3 秒 |
| 8 | info | 胜：它愿意让你靠近了，可以带回站。／负：时间到，先回站，下次再来。 | 仅"知道了" | 点按钮 |

前 5 步必须真做一次；5–7 不拦操作。整套约 90 秒。

### 7.3 与现有指引契约的差异

现有 `LevelGuidance.json` 只支持"做动作才推进"，首战还需要 `info`（只读 + 继续）和 `inspect`（打开手册看到指定卡）两种步骤。属 `GuideSession` 小幅扩展，需单独确认并加测试。

## 8. 战斗内轻提示（不改规则）

- 选中手牌 → 手牌上方一行简介，取消即消失。
- 首次遇到某类机关 → 3 秒轻气泡："纸团台会打最前面那个，先拆它。"
- 花费不够点牌 → 卡面短抖 + Toast「饭不够，还差一点」。
- 材料满足 → 手牌角标"可合体"，不弹窗。
- 被按住/叼走 → 沿用现有脚标，首次补一句"只停它一个"。
