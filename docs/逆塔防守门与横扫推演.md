## 1. 这组要验证的乐趣

**动物把前排堵在一起，给了玩家免费合体的机会，但也让这群材料暴露在横扫之下。玩家需要在继续出兵、保住材料、保留前进距离之间取舍。**

难点不在必须凑出指定三张，也不在手动把三个单位拖到一起；附近免费合体和消耗出兵资源的主动合体都保留。未合体的普通单位也应有推进作用，不能抽不到三只同类就全局无事可做。

本轮不证明数值平衡、长期策略不会收敛或完整救助可通关；只核对同一局面下的因果、取舍和画面可读性。

## 2. 推演假设

| 项目 | 本例暂定 | 边界 |
| --- | --- | --- |
| 场地 | 左、中、右三路，自下向上接近动物 | 三路为解释用默认值，不是正式数量 |
| 普通单位 | 同类补给小车可推进，受阻时停留，可被反击打散 | 本例不确定完整耐久、攻击与推进数值 |
| 三合一结果 | 三辆补给小车合成重装车，可抵挡一次击退，仍可能受损或被后续反击打掉 | 只是这一配方的候选能力，不把所有合体都设为免疫横扫 |
| 当前资源 | 剩余 3 份；现有场上单位已付过出兵成本 | 不借此确定资源名称、上限、恢复方式和经济循环 |
| 眼前选择 | 主动合体花 2；手中的引导球出兵也花 2 | 只为同成本比较，非正式费用 |
| 抽牌 | 当前随机供给结果已发生，不预告第三只必何时抽到 | 三种处理从相同场况与手牌出发，不为不同分支偷偷改牌 |
| 时间 | 按预告、应对、横扫后分幕观察 | 分幕不是正式回合制或玩家思考时自动暂停的决定；实时/行动节拍仍待讨论 |

同一种三合一配方结果一致，不能在比较分支时把三辆相同小车随意变成重装或改道两种升级。真正的改道能力应在其他配方中另行设计。

## 3. 同一个局面的三种处理

### 共同起点

1. 动物守住中路，前两辆补给小车甲、乙在中路前沿受阻，尚未被打掉。
2. 玩家此前已将第三辆同类小车丙部署在左路后方，材料已经在场，不在手中安全保存。
3. 三辆没有靠在一起，暂不满足免费自然合体。当前手中有引导球，剩余资源为 3。
4. 动物开始蓄势横扫，明确预告中路前沿的一块区域，甲、乙在范围内，丙不在。预告后范围不再暗中跟着玩家调整。

### A. 中路原位合体，顶着防守突破

- 花 2 资源，以中路前排甲为主体，消耗乙、丙，在甲的位置生成重装车，剩余资源 1。
- 结果仍在横扫范围内，不因合体自动取消攻击或取得通用无敌。
- 本例中重装车消耗一次抗击退能力，顶住这次推退，利用横扫后的收招空档继续推进；后续仍可能受损或被打掉。
- **得到的是保留前进距离与前线压力，付出的是资源及一次性能力。** 若材料已重伤、后续防守更强，这条并非自动最优；耐久继承规则尚未确定。

### B. 左路后排作为主体，避开这次横扫

- 同样花 2，以丙为主体，把中路甲、乙消耗掉，在丙的左路当前位置生成同样的重装车，剩余资源 1。
- 横扫仍落在原先的中路区域，不追踪已消耗材料去打左路。
- **保住合成材料和一次性能力，但放弃了中路前排已有的前进距离。** 新单位需要从后方继续走，局内剩余时间紧时可能不划算。
- 这是既有“主动合体选择主体位置”带来的战术，不给重装车凭空增加改道技能。将来的真正改道单位可以在前沿横向切线、较少损失前进距离，与这种后撤合体区分。

### C. 暂不合体，继续在右路出兵

- 花 2 将引导球投到右路，剩余资源 1；没有偷偷把中路材料移出范围。
- 本例假设横扫足以打散甲、乙。丙在左路、引导球在右路继续推进，利用动物正在横扫和收招的时间。
- **主动放弃部分材料，换两侧攻势。** 不是无损答案，也不能凭示意就断言收益高于合体，要由实际突破效果与时间来验证。

### 免费合体的对照不是凭空新增的第四答案

如果第三辆更早部署在中路、并在横扫前赶到两辆受阻小车附近，可以免费合体、留下资源。但这需要更早的路线与时间安排，不是上述“第三辆已经在左路”的同一局面能立刻获得的结果。

不能让动物每当玩家将要免费合体就恰好横扫，把主动合体费变成隐性强制税。招式应遵守已有节奏、预告和冷却，普通推进与自然合体必须存在真实机会。

## 4. 动物自己的动作节奏

建议把这组读成四个可见阶段，而不是一排技能倒计时：

| 阶段 | 动物与场上发生什么 | 玩家看到的机会 |
| --- | --- | --- |
| 守门 | 一只爪压在某路出口，前排单位停住，后续单位可继续靠近；拍击节奏另定 | 可等待附近免费合体，也可从其他路线组织进攻 |
| 蓄势 | 动物重心和尾巴向一侧蓄力，地面同步出现实际扫击区域 | 判断材料会不会被扫，考虑合体主体位置、出兵或保护 |
| 横扫 | 按已显示的范围结算；只影响覆盖的前沿区域，不从动物面前一路扫到发射口 | 躲开该区域的单位继续推进，仍在范围内的按真实能力承受反击 |
| 收招 | 动物恢复站姿、收回爪尾，存在明确的短空档 | 普通单位也能趁机前进，不只高级单位能有作用 |

强动作时不叠加无预告的全路拦截或额外追踪攻击。何时再次守哪一路可结合可见场况，但不能在玩家已应对后立即凭空更换横扫范围。

## 5. 竖屏画面方向

### 一个连续场景，不做上下两个互不相干的小游戏

- 动物在场景上方，三条进攻方向从下方延伸到它面前，动物与单位共用地面参照。不是猫的头像放上面、下面另摆一个抽象消除棋盘。
- 动物和战场共同争取约三分之二的可用高度；顶部只留紧凑的时间、目标和暂停状态，底部沿用紧凑三行动条的思路。不把工具区重新做成大卡片墙。
- 路线用地面接缝、浅轨迹和底部发射位置表达，不画满粗边框。透视保持轻微，前线同一路不能因缩得过小而看不清单位与合体关系。
- 动物足够大，爪、尾与地面接触位置可辨认；单位是食物、玩具和小道具的游戏化形态，不做持械小人或伤害动物的血腥攻击。单位造型与数量尚未批准。
- 顶部完成进度暂用“突破防守”这一试验目标，不直接画动物红色生命条；具体成功目标尚未确定，不以表现代替正式接受、医护或转运规则。

### 把五件事直接画出来

| 需要读懂的事 | 建议画面表现 |
| --- | --- |
| 哪一路被挡 | 爪确实落在该路前沿，第一辆停住、后车排近；不是仅弹一句“无法前进” |
| 横扫打哪里 | 身体蓄势与地面弧形/斜线预警同步，既用形状也用色彩；实际范围与预警一致，不只显示“即将攻击”文字 |
| 哪三只将被合成 | 选主体后，主体有清楚的轮廓，另外两只材料同时高亮；在提交前显示费用与结果落点，不自动抽走未示意的单位 |
| 合体结果在哪里 | 两个材料沿短促轨迹汇向主体，原材料消失，原位出现更明确的高级轮廓；不让全屏闪光遮住动物预告 |
| 哪只被打掉/刚刚挡住 | 被打掉的单位有短促弹散/退场，确实从场上移除；挡住击退有接触反馈，一次性防护标记消耗，不用同一种烟花表示所有结果 |

高级单位应先靠轮廓和关键部件体现能力，等阶标记只是补充，不只放大原图或增加星星。硬突破可以体现更稳定的底盘和可消耗防护，改道则体现转向结构；具体包装不是本轮资源清单。

### 画风与信号

沿用当前柔和大眼、清新、细轮廓的动物方向，场地尽量清爽；强对比留给正在发生的战术信息。不重新发明一套与现有动物不一致的战争美术。

预警使用暖色斜线加清楚边界，合成选中使用冷色轮廓与连接提示，禁用保留可辨形状并附短原因；不能只靠红绿区分。具体主题 Token 本轮不另立平行契约，正式美术方向确认后再按唯一视觉契约维护。

本轮聊天内示意复用 `public/pet-mesh/cat-side.png` 整图，单位使用符号表示战术关系。原图不改字节、不新增拆件或导入、不代表最终视角与防守动画；原有台账保持 temporary / preview-only，补充此解释用途。

### 操作与动效的边界

- 出兵可先用“选牌 -> 选发射路线”的候选交互，合成用“选场上主体 -> 看清另两只材料和费用 -> 提交”；不额外叠大弹窗遮住前线。是否需要单独合成模式及具体触控待试看。
- 原有约 400ms 长按不直接当作新逆塔防的既定出兵手势。高频出兵、点选移动单位和合成确认要结合实时或节拍结构重新试，不擅改原入口操作。
- 合体、横扫和击退应短促且因果可追踪，预告必须留下足够看清并操作的窗口。当前不锁死动画时长，也不用演出时长偷偷重复扣游戏时间。
- 若采用当前单图网格方案，扫尾和抬爪不能只把部件拉长或旋转整张图冒充。需要真实接触姿态的地方先验证动作范围，必要素材另行确认，不能分别生部件拼装或覆盖现有动画试验。
- 聊天里的分幕选择方便比较，不意味着正式游戏允许在选合成材料时无限暂停，或在暂停期间继续积攒资源。

## 6. 这轮推演暴露的问题

1. **后排异地合体是否过强**：如果任何材料都能被免费带到前沿主体，可能成为默认运输。要结合主动合体费用、主体存活及材料损耗验证，不能再用强制靠近撤销已认可的便利性。
2. **硬突破是否自动压过改道**：如果抗击退还免除全部损耗、所有防守都能顶，就没有其他策略空间。不同能力必须有明确适用范围。
3. **横扫是否总逼人付费合体**：出现频率、范围与材料成形时间要给自然合体和普通推进留下机会。
4. **一波控制是否遮掉全部机会**：守门与横扫不应形成持续全路封锁，收招窗口要能被普通单位利用。
5. **触控是否来得及**：点主体、看材料、确认资源与选路，必须在普通手机大小上看得清、按得准；不能靠大屏鼠标验证代替真机手感。

## 8. 后续讨论：清路决定进攻路线

用户提出进攻路线可结合第一段清路。建议不是先完成清路、再切换到无关的三线棋盘，而是同一现场中，清路形成的通道、障碍和汇合位置继续用于逆塔防。以下具体结构与取舍仍是助手提案，未获逐项确认。

### 推荐的承接方式

- 先清出至少一条安全通道，再主动进入出兵阶段；清理结果保留，场景只切换操作模式和战术提示，不重生一套阻挡。
- 不要求全清，额外清理可开放绕行支路或横向连通口。先按战前准备理解，不直接加入边打边清、实时追逐或多任务操作。
- 不固定每关三条直线，采用少量、可读的通道结构：有的分叉后重汇，有的抵达动物另一侧，避免所有路线最后都进入同一个爪和尾巴范围而使侧路失去意义。
- 如果本次是既有的场景解谜开路分支，解谜后同样承接真实可通行结果；不因本提案改成每次必须先清理再解谜。原本无需清路的现场也不凭空长出垃圾。

### 停车棚示例

| 开出的路径 | 对攻防的影响 | 取舍与边界 |
| --- | --- | --- |
| 中间短通道 | 前进快，容易集中在动物正面 | 容易被正面守门及前沿横扫覆盖，不是所有动物都固定守中路 |
| 绕过固定场景物的侧面通道 | 路更长，可从另一个方向给动物压力 | 不是永久安全路线；动物下一次守门可提前表现选择另一出口，不在预告后临时瞬移追击 |
| 两条通道间的连通缺口 | 同类单位有汇合机会，也可组织换线 | 更方便自然合体，但可能产生扎堆；不能因此取消已认可的付费便捷合体 |

这些是可组合的地形关系，不是要求每关三个选项全部出现。固定安全建筑、花坛、长椅等地形与可清垃圾分开，不奖励故意保留危险垃圾来阻挡动物，不把清除危险变成错误操作。是否阻挡尾扫需按实际形态另议，不能所有障碍都自动提供防护。

### 必须正视的策略问题

**如果额外清理既免费又无限，而且只会增加好处，玩家合理的最优做法就是全清再开战。** 地形承接本身能让两段连贯，但不等于已经解决清路阶段的取舍。

后续可讨论给额外开路有限投入，或将其与出兵资源形成明确机会成本；目前不擅自消耗出兵资源、不增加体力条，也不把清理现实操作秒数计入救助倒计时。已有世界时间按行动推进的规则与新实验局内时限需分开。

第一轮可以先验证同一地形承接和不同路径是否有意义，再确认是否需要清路预算；不能未经验证就声称已避免全清支配策略。

### 画面承接

清路时从现场障碍上直接看出潜在去向，开放后显示贴地的浅轨迹和出兵入口。进入救助后保留同一动物、地标与清理成果，只弱化清理工具、呈现行动条和实际拦截/扫击区域。不做“清理画面结束 -> 无关战斗背景”，不画满规则格子，也不为每开一条支路强制再清相同障碍。

## 9. 最新方向：三路推线与动物布塔

### 用户提出的方向

- 动物拥有设置自主炮台的塔防能力，同时保留自身短距离攻击，不要求一只猫的爪尾覆盖全场。
- 地图借鉴 LOL 的三路结构：一条中线、两条边线；玩家从左下角出兵，猫咪在右上方防守。
- 建塔位参考三路塔的分布，最后的高地塔防线改由动物自身攻击承担；可包含轻量 LOL 趣味元素。

这是后续地图与防守的设计基线，不是实现授权，也不代表正式复制某张地图或加入完整 MOBA。塔位数量、建造规则和塔种尚未确认。

### 地图与清路承接提案

- 中路是左下至右上的较短斜向通道；两条边路分别从左/上与下/右绕行。首版只借用三条进攻方向的空间关系，不额外加入河道、野区打野和独立经济。
- 第一段清路是在既有三路骨架上打通可用段和可选转线口，不再需要玩家凭空清出任意寻路网络。至少一条安全完整路线即可进入救助，不要求三路全开或全场清零。
- 某路炮台射程覆盖不是“路没清通”。清路完成只解除实体通行问题，不清掉敌方塔、代替拆塔或保证后续救助成功。
- 固定安全地形、可清杂物、敌方可拆炮台分别可辨。动物布塔不让已清通路重新长出垃圾，也不取消清理成果。
- 额外支路是否消耗有限投入仍待确认；三路结构不会自动解决“清路免费且无限时全清最优”的问题。

### 塔位与动物职责提案

- 首个讨论版本每路先设外塔位与内塔位两层，最里面是动物的近身防区，不再叠三座高地塔。只是塔位候选，不表示开局六座塔全部造满。
- 炮台承担沿途持续拦截；动物自身在最后的多个入口之间选择守门、横扫或换边。三路应以不同角度接近，不提前合成同一条必经窄管，也不让一爪同时永久封住所有入口。
- 某一路被突破即可向动物施压，不默认必须清掉其他两路所有塔。实际胜利目标和如何映射动物接受救助仍未定。
- 动物可以根据可见场况决定把有限防守能力布在哪个固定塔位。建造需有清楚预告和可读过程；建造次数、间隔、代价，以及能否重建均另行确认，不直接加入无限即时补塔。

### 少量炮台种类候选

| 候选 | 与动物自身攻击的分工 | 对应进攻思路 |
| --- | --- | --- |
| 纸团弹射器 | 沿途单体拦截，射程明显长于猫爪；弹道和受击对象可见 | 普通单位分担火力、重装单位顶住，或换线绕过 |
| 毛线阻滞塔 | 向一小块路段发射毛线团，使经过的单位暂缓推进，效果需清楚可辨 | 受阻可能利于附近合体，也会耽误进攻，机动单位另找路线 |
| 吹风推退塔 | 蓄势后沿一个明确方向推动前排，不无预告持续全场击退 | 预读节奏、合体抗击退或改道；不能与动物横扫无缝重叠到无法推进 |

候选是游戏化玩具机关，不声称猫能按现实方式搭建机械。首版宜先选择一种普通拦截塔与动物守门/横扫配合，避免还没验证三路就堆满炮台类别。单位如何对塔进攻、塔如何被拆和伤害规则另行推演。

### 画面与趣味提案

- 固定轻俯视、同一连续场景；三路是可辨通道而非粗线棋盘，猫在右上但位于安全区内，左下出兵口不被底部手牌遮挡。
- 塔放在路侧的可辨塔位，射程覆盖道路；不把所有塔直接画成占据整条路的实墙。要不要碰撞阻挡须另行确定。
- 建造用塔位预告、道具出现、成塔三个阶段表达。放塔是游戏化能力，不要求猫穿越整图逐座搭建，也不伪装成猫的远距离伸爪。
- 终段画面应是猫真的伸爪、摆尾或转向，范围与位置一致；不把猫画成一个静态基地头像后从身上自动发炮。
- LOL 趣味来自三路推线、转线、拆外塔/内塔和猫亲自守“高地”的反差，可尝试原创短文案；不借此新增英雄、装备商店、兵营/水晶等系统或复用原作图标、音效、角色与地图美术。
