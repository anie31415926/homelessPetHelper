## 运动设计

30骨、19段定长连接，复用Three.js官方`CCDIKSolver`；每次采样先重置旋转，任意拖动/倒放不依赖上一帧。

| 姿态 | 归一化时点 | 动作草样中的关系 |
| --- | ---: | --- |
| 站立 | 0 | 趾行、跗部高于地面，髋高于膝，胸背近水平 |
| 预备 | 0.20 | 两前爪先后小步回收，至少一只前爪留地；骨盆开始落下 |
| 下降 | 0.55 | 髋明显下沉，股骨绕髋转，膝与跗逐渐折叠，胸腰链重排 |
| 接触 | 0.86 | 骨盆低，膝在前上，跗接近地面，跖部向前；这里的名称是动画阶段，不是软组织碰撞检测 |
| 坐稳 | 1 | 保留完整股骨/胫骨/跖骨，骨盆低于且后于膝；前肢接近伸直支撑胸廓 |

近侧终点：髋(-1.200,0.450)、膝(-0.452,1.036)、跗(-1.097,0.145)、趾(-0.300,0.075)。股骨0.95、胫骨1.10、跖骨0.80，Scale全1。灰色为远侧链，绿色为近侧后肢，橙色膝与紫色跗同时有文字标签，不只靠颜色区分。

脊柱为6段等长关节的简化中心线，胸廓/骨盆/头骨用示意线表现，不是完整医学骨数模型。肩胛三角可随胸廓滑移，前肢独立定长IK；尾巴只是位置示意线，不参与骨架或重心求解。没有质量/惯性、地面反力、肌肉或毛皮、软组织接触/关节囊碰撞，因此不称物理坐稳已证实。

沿用旧独立预览的React、Three.js、Lucide与浅中性/绿色控制风格，画面无卡片包裹。字号22/16/14/12px，按钮至少48px、间隔8px；手机五姿态标签另排编号。骨架本身是主要内容，不恢复被毛轮廓来掩盖位置。默认不自动播放；切后台暂停，显式播放可逐帧检查，未加入无意义入场动效。

这是桌面浏览器创作小样，不把CSS像素当Unity设计格或目标手机dp。最窄屏保留画面和控制，短屏允许纵向滚动而不缩小热区。移动端因正侧面整体跨度大，坐姿视图仍比站姿窄，未增加自动追焦/镜头缩放以免干扰固定地面参照。
