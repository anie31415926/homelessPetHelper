- 暂停或失焦拒绝输入，不推进；重新开始创建新会话，旧回合输入不能作用于新会话。退出场景结束本次试做，不提供存档恢复承诺。

## 参考走法

正常路径：留出空间 -> 放下食物 -> 等候进食 -> 等候或玩具使其放松并主动靠近 -> 准备安置，观察到入口嗅闻 -> 留出空间或等候，观察到自行进入并安顿 -> 独立完成救助 -> 查看总结 -> 回站互动。

替代路径：在其他回合先放食再退开，或先等候稳住后再提供食物。发牌与保留会改变实际行动顺序，不以完整输入串匹配判断成功。

误处理：紧张时接近 -> 显示退缩和原因 -> 退开恢复安全空间 -> 继续尝试，或随时呼叫求援结束试做。

资源耗尽：以只带一份食物的规则测试验证放食后库存耗尽，地上已有食物仍可在合适前提下进食。默认两份库存不会为了测试而强行放出无意义的第二份；零库存开局仍有安全行动与求援，但不承诺能救助饥饿样本。
