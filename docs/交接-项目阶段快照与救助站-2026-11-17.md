## 3. 试玩入口

Unity 菜单 `Homeless Pet Helper > Preview`，打开后 Play；打开场景前会询问保存当前未保存的场景。

| 菜单 | 当前可以体验 |
| --- | --- |
| `Open Option Whiteboard` | 选择、保留、使用及刷新；当前单选，首轮 3 个选项、最多保留 2 个 |
| `Open Rescue Case` | 正常起点：饥饿、紧张、无应激，观察回应、建立安全感、收尾及样例回站 |
| `Open Stress Recovery Case` | 已进食的应激恢复起点，与正常起点共用场景和状态规则 |
| `Open Station Whiteboard` | 只读回站总结、多只动物总览、单只近景、健康样例揭示、抚摸、局部擦洗 |

救助站操作：进入救助站 -> 选动物 -> 查看健康 -> 清洁护理 -> 点击、按住或拖动擦洗 -> 完成护理。中途返回保留局部进度；查看、抚摸、记录和闲置不推进游戏时间。完成一次护理才推进一次，暂停、后台或焦点丢失取消按住输入，恢复不补算。

全部预览场景位于 `Assets/EditorScenes/`，驱动位于 `Assets/Scripts/Editor/`，不参与 Player 打包。正式构建只包含 Main；目前不能在 Player 中体验这些白板。

## 5. 暂定与未实现

- 站内容量 4、三只样例、入站脏污 65/100、清洁 97% 可完成、每次 20 游戏分钟及笔刷参数均为可调试做值。干净样例不强制加脏，仍允许选择护理。
- 健康查看仅显示固定“暂无紧急情况（样例）”，不是疾病诊断；抚摸当前只有文案反馈，没有关系成长或姿态动画。
- 未实现真实外出到站内接入、完整开路、正式应激/失败结算、医疗/骨折处理、修毛剪指甲、游戏时间脏污积累/患病、昼夜背景、领养/长期陪伴、建设经济和存档。
- 用户已确认夜间可外出、行动推进时间、有限容量逐步扩建、最多 5 只长期陪伴且可调整、简单模拟领养等方向，但不能据此一口气扩完未讨论的具体规则。
- 两张样例 PNG 来自仓库 `src/Pet.jsx` 栅格化，导入/来源见站内记录；不是正式美术或商用资源选型。未采用 Addressables、UPF、Luban 或热更框架。
