# 地图交互点与双向过渡

用户于2026-11-23认可并授权实施；进入和离开独立配置，支持矿车驶入/驶出等多图组合表现。具体矿山、动作时长和新返回玩法未定案。

## 职责与编辑

- `MapPointVisual`：一个交互点的视觉子树。静态Prefab可包含矿山、小车、洞口遮挡等多张Image；稳定Button/热区保留在外层，不随动画改变。Enter/Exit各列独立部件，显式引用RectTransform及可选CanvasGroup，配置位移、缩放、旋转与末端透明度。关闭、取消及完成恢复初态，不写业务存档。
- `MapTravelView`：Main显式持有的表现流程，按稳定PointId绑定。每点分别配置Enter/Exit序列，每方向有Before Switch和After Switch；先播放源画面表现，执行一次业务提交/切换，再播放目标画面表现。支持PointAnimation、Fade、ZoomAndFade；数组为空表示直接进入，未配置地点兼容直接切换。
- `CityMapPresenter`：发起时锁定地点/外出会话/请求ID，过渡完成后再次预检容量、请求及宿主限制，再调用原出发接口。拒绝时保留源画面，释放输入，不替动画创建求助或动物。
- `MainLoopPresenter`：显式接入现有出发/开路退出/战斗退出。结算、返站、保存仍走原有接口；当前退出目的地仍是救助站，本轮不擅自改成可操作大地图。未来返回外部地图的业务获批后，可在切换回调显示外部地图，再用Exit.After Switch播放矿车驶出，不必重写播放器。

全屏纯黑转场与35%模态黑遮用途不同，转场覆盖完整Canvas；没有新纸板/按钮样式。交互点热区、名称牌、地图拖动和现有手绘样式保持。`Widget_MapTravel`仅含转场层，输入根在Main场景显式引用，关闭时恢复原CanvasGroup状态。所有资源静态保存，不运行时拼UI或按节点名查找。

## 配置例子

矿山Enter：Before Switch配置PointAnimation（小车驶入）、ZoomAndFade（视觉表面向洞口偏移并淡黑）；After Switch配置Fade（1→0）。Exit可反向配置：Before Switch淡黑，切换到外部地图后After Switch先淡入再播PointAnimation（小车驶出）。两个方向分别编辑，不自动倒放以免遮挡和部件初态不一致。

Zoom Surface必须是独立视觉节点，不能绑定稳定点击根/滚动根；Offset单位为该RectTransform的设计单位，Scale为相对原比例。保持地图Mask，动画范围需要在实际地点素材接入时检查；当前不伪造矿车图片，也不把技术样例当正式美术。

## 生命周期与兼容

- 独占一次播放；输入CanvasGroup锁定与Presenter防重入共同保护，重复请求不执行提交。
- 失焦/后台停止表现时钟，恢复前重新检查源会话；不以现实挂起时长补播，不消耗游戏分钟。
- 源失效、提交拒绝、组件禁用/销毁、异常均复位遮罩/缩放/部件和输入。提交后取消只结束表现，不撤销已完成的结算。
- 动画参数和Unity引用不存入玩家档，不更改存档schema；共享配置保持只读。未知/重复PointId、无效时长/非有限数、缺失动画或缩放引用启动拒绝。
- 沿用现有MotionPose插值，不扩充共享Hover/Press枚举，不引入第三方动画/异步框架。当前目标资源已随包且同步绑定，未声称实现异步资源加载；后续加载适配须由装配层接管取消、失败与准备完成信号。
