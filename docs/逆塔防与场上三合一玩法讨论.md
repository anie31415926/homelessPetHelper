## 最新方向：三路推线、动物布塔与近身防守

用户提出：动物除保留自己的攻击外，也具备设置自主防守炮台的能力，以扩展短射程动物的防线；地图参考 LOL 一条中线、两条边线的结构，玩家从左下角出兵，猫在右上方防守；建塔位参考三路防御塔分布，高地塔一层改由动物自身攻击承担，并可加入轻量 LOL 趣味元素。

按此作为后续推演的地图与防守方向，不再把三条平行直线或仅有猫爪/尾巴的全程防线当作目标。第一段清路与进攻地形承接继续讨论，具体方案见[推演第 9 节](逆塔防守门与横扫推演.md#9-最新方向三路推线与动物布塔)。塔位参考不等于完整复刻 LOL：塔数、建造时机/代价、塔与单位的战斗、清路投入、跨路口和胜利条件均未确定，也不自动加入英雄、野区经济、水晶、兵营或完整 MOBA 系统。

## 最新确认：便捷合成与合体能力分化

用户认可上一轮的两条合成途径：附近三个同类自然合体免费；场上已有三个同类时，可消耗出兵所用的资源主动合体，不强制要求靠近。主动合体以玩家选择的单位为主体，消耗另两个材料，在主体当前位置升级。材料仍必须已经部署在场上，等待期间可能被打掉，不另开安全备战区。费用数值、材料选择交互、同阶要求和具体范围仍待细化。

用户进一步明确，合体后的硬突破和改道能力可以同时存在于不同合成结果中，不必只选一种策略。按不同合成拥有不同能力继续设计；这不等于每个高级单位都同时获得所有能力，也不代表已批准具体单位表或跨类型合成配方。

本轮接续重点改为动物的自主防守手段。下文新增招式与防守组合为讨论候选，未获逐项确认，尚未实现。

**后续授权与记录**：用户认可先推演“守门＋横扫”，并要求同时考虑画面表现。已整理[同局面三种处理与竖屏分镜](逆塔防守门与横扫推演.md)，用原位硬顶、后排主体合体和分路续兵比较材料、资源及前进距离的取舍。三路、费用、重装能力和具体画面仍为推演假设，聊天内分幕示意不是可玩战斗引擎，也不代表完整防守招式库获批。

## 前轮反馈：合成不能强制依赖靠近

用户指出必须让三个单位靠在一起会使合成/消除过难，要求提供更方便的合成途径，并提出消耗出兵资源来合成作为例子。以此修正此前的局部自动合体提案：**空间靠近不能是所有合成的唯一硬条件**，场上材料承担风险的核心仍保留。

该轮提出时，消耗出兵资源的主动合成仍是候选；后续认可结果见顶部最新确认，不再重复等待两条途径及主体位置的方向确认。具体费用和规则边界仍未定，不自动增加新币种或安全备战仓库。

## 背景

用户反馈现有救助玩几局后策略容易同质化，提出以逆塔防结合合成/消除重新探索核心玩法。重点不再只是增加选项数量或更换出牌顺序，而是让随机供给、前线存续、动物反击与合成机会相互影响。

此前的读招、连锁和变局实验及验证继续保留，见[脑内过招 HTML 耐玩性实验](脑内过招HTML耐玩性实验.md)。本方向尚无新试玩入口，不将旧实验的测试结论用于证明新方向成立。

## 已确认的试验方向

- **逆塔防**：玩家将救助选项转为可派出的进攻手段，动物自主反击，可以打掉玩家的进攻。用户提出在有限时间内化解防御、完成救助；时间结构、失败后果和正式救助收尾如何承接仍待细化。
- **随机抽牌继续保留**：并非自由挑选任意单位。确认随机性，不代表直接沿用旧实验或 Unity 样本的完整供给、同组去重和保留规则。
- **合成发生在场上**：用户明确不是在手里安全攒牌，也不是连续使用三张后仅强化第三张；三个场上同类单位合成一个更强的救助手段。
- **路线与推进**：用户认可玩家选择出兵路线，单位自动向前推进；受到阻挡时会停留，后续同类有机会追上。
- **两条合成途径**：附近三个同类自然合体免费；主动合体消耗出兵所用的资源，不强制材料靠近，以玩家选择的场上主体当前位置生成结果。具体费用、同阶要求、选材交互和范围尚未确定。
- **合体能力分化**：不同合成可分别支持硬突破、改道等能力，不要求只有一种合成策略，也不要求所有结果都具备相同能力。具体单位、能力效果和配方未定。
- **合成材料承担前线风险**：前两个单位需要留在场上等待第三个，期间可能被动物反击打掉。阻挡既可能阻止推进，也可能帮助后续同类追上；这正是用户认可的玩法张力。

用户确认依据：先提出“逆塔防+合成/消除”，再明确“场上三个合体，毕竟攒牌太稳了”；对“选择路线、受阻停留、后续追上、附近三个自动合体”的提案回复“就是你喜欢的这种”，随后明确修正必须靠近的限制并提出便捷合成需求。按最新反馈继续，不将较早认可当作不可调整的正式规则。

## 概念循环

随机获得选项 -> 选择路线并派出单位 -> 单位推进、动物反击 -> 场上三个同类自然靠近免费合体，或消耗出兵资源主动合体 -> 利用不同合体能力争取突破，在有限时间内达成试验目标。

此循环只解释方向，不规定抽牌和出兵频率、时间何时推进、合体过程或胜利判定。尚未实现或测试。

## 动物防守手段候选

本节是游戏化攻防设计，不是现实动物行为判断或救助教程。防守针对场上派出手段，不借此引入动物受伤或死亡。

| 招式候选 | 画面和实际作用 | 希望形成的应对差异 |
| --- | --- | --- |
| 抬爪拦路 | 守住一路前方，单位受阻停留，按可读节奏拍击或推退前排 | 可以换路分流、利用停留等同类赶上，或合体顶住拦截；堵点既是风险也是集结机会 |
| 尾巴横扫 | 尾巴摆向明确区域，预告后对该区域成群单位造成损耗或击退 | 可以分散部署、将脆弱材料提前合体或用保护抵挡；不是无预告全场清空 |
| 点名扑住 | 凝视并标记一个大目标，蓄势后扑住，使其暂时无法推进；扑住期间动物占用一个防守动作 | 可以让其他路线趁空推进、利用改道能力避开或用支援处理；高级单位不再是无条件最优解 |
| 叼走战利品 | 优先叼起可叼走的食物或玩具单位，暂时退出拦截并忙于处理；被叼单位不再算可用合成材料 | 小单位可以有意吸引它占用防守时间，其他单位趁空通过；不等于普通单位完全白送或动物自动接受转运 |
| 拖来纸箱 | 将现场纸箱推到一条路线形成可见阻挡，不同时封死所有路线 | 可以顶开、改道、转投另一边，或利用堵点聚合；路线改变不重置已取得成果 |
| 一爪拨偏 | 将某个前排单位拨到邻路，保留其实际存续状态，不直接判消失 | 可以拆开集群，也可能意外促成附近合体；玩家可重新组织路线或使用付费合成，不因位置变化无解 |
| 换边防守 | 动物提前表现转向，移动到另一侧集中防守，原防区暂时减弱 | 可以佯攻一边再突破另一边，也可以利用改道；不把目标移动做成既有成果清零或无限追逐 |

以上仅提出作用方向，攻击损耗、阻挡时间、可叼走类别、控制是否可解除及具体数值均未确定。不同动物可以从招式库组合出防守风格，不按物种强制绑定同一套行为。

### 防守组织建议

- 一只动物首轮只带两到三种主要招式，以普通拦截、特点招式及可选地形变化形成风格，不将整张表全部堆进同一局。
- 根据可见场况与自身冷却选择招式，例如局部扎堆时准备横扫；预告后明确锁定区域或目标，不能在玩家应对后无解释改成全场追踪攻击。
- 每次强防守伴随另一个可争取的机会：扑住大件时其他路线出现空档，叼走物件时暂缓拦截，守住一路时其他路线仍可组织进攻。不是要求抽到唯一克制牌。
- 主动合体可以用于抢救材料，但不默认附送无敌或清除已锁定的攻击；是否成功避开取决于实际位置和合体能力，具体锁定承接规则另议。
- 防守风格示例：拦路与横扫偏守门，叼走与纸箱偏收集和改造场地，拨偏与换边偏游走。不能只换动物形象和损耗数值，也不自动加入针对玩家手牌的隐藏克制。
