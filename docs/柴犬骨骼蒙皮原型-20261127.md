# 柴犬骨骼蒙皮原型（2026-11-27）

目标只有一个：回答“柴犬能不能从帧序列改成骨骼蒙皮”，先用离线原型给出可判读的证据，再决定是否投入正式绑定。

## 做法

- 素材：`unity/HomelessPetHelper/Assets/Art/PetSit/T_Station_ShibaMotion.png` 第 0 帧，裁 `4,2,126×126`，放大 2× 到 252×252（原帧只有 128px，放大是为了光栅输出不至于太糊）。
- 网格：6 输出像素一格，43×43=1,849 顶点、3,528 个三角形，UV 取顶点在源图的位置。
- 骨架：19 骨。`root → spineA → spineB → neck → head`、`root → tailA → tailB`、四条腿各 `upper → lower → paw`，全部用第 0 帧上的关节坐标（head 枢轴 (80,76)，肩 (104,120)，髋 (170,116)，尾根 (180,96)）。
- 权重：层级式占位，先算头/尾的门控，再把余量按 x 分给躯干前后段，四肢只在各自门控矩形内按“到最近骨段距离”的高斯权重叠加；不做手工笔刷。
- 变形：线性混合蒙皮（LBS），2D 仿射按父链复合，每根骨绕自己的静止枢轴旋转。
- 光栅：自有 CPU 三角形光栅，重心坐标插 UV + 双线性采样 + 2×2 超采样，预乘 alpha 还原后存 PNG。
- 复现：`node tools/dog-rig-prototype.mjs`，产物在 `art-source/dog-rig-prototype-20261127/`。

## 能到什么程度

成立的：

- 单帧整图能被骨链带着动，头、尾、躯干分得开，脚不离地。
- 小幅度（头颈 ≤5°、尾 ≤10°）观感可用，适合呼吸、点头、尾巴轻摆这类 idle。
- 不需要拆层就可以先跑通“骨架 + 权重 + 光栅”的整条链路，后续换正式素材时参数可复用。

不成立的：

- 头部转向超过约 7° 时，颈部与胸口交界出现 1–2px 的轮廓漂移和细缝（空洞 415px），因为头是一个整块像素，没有“头后遮挡”的补绘。
- 尾巴卷曲的高光/描边在旋转中有轻微撕裂，卷尾这种自我遮挡结构最怕单层图。
- 单帧 128px 是硬上限，放大后细节软；正式用至少 256px 单帧。
- 腿能弯但很难看：单层图没有前后腿遮挡关系，弯膝后会出现“腿穿过腿”。
- 因此**不能**用它做 walk（步态需要四肢大角度摆动与遮挡补绘），只能做小幅度 idle。

## 下一步（如果继续做骨骼蒙皮）

1. 拆层：头/躯干/前腿×2/后腿×2/尾，共 7 层，尾巴单独一层解决卷曲自遮挡。
2. 补绘：头后颈部、腿后腹部、尾巴背面各一张遮挡图（约 3 张）。
3. 单帧提到 256–320px，或直接按矢量重生一次柴犬。
4. 骨架改犬类专用（约 24–28 骨），不复用猫的 36 骨——两物种体长和前肢角度不同。
5. Unity 侧复用猫的烘焙管线：网格 + `SkinnedMeshRenderer` + `.anim`，再挂 `PetMotionPlayer`。

成本估算：拆层与补绘 1 张图约 0.5–1 天；绑定与权重 0.5 天；Unity 接入与 idle/walk 两条动画 1–1.5 天；合计 2–3 天，且 quality 才可能超过现有帧序列。

## 当前建议

先保留已经可用的帧序列 idle（第 0–7 帧 4fps 乒乓），把骨骼蒙皮当作“正式美术重做柴犬时顺带做”的选项；如果这周就要在游戏里看到“像骨骼一样连贯的柴犬”，不建议在现有 128px 单帧上硬上蒙皮。
