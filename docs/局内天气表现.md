# 全图天气与局内继承

2026-11-25，表现首版。天气属于整张地图，不按地点分配。类型为晴朗、雨、雪、雾，后三种各有小、中、大三档。当前世界初始值为固定小雨，仅用于试玩，不代表正式天气生成规则。成功出发进入现场时取一次世界天气，清障/解谜和救助读取同一份快照；正在进行的外出不会随调试中的世界天气切换。室内保留状态但不直接画室外雨雪雾。

## 试玩与调整

1. Unity 打开 Main，进 Play 后点外出。地图全屏显示当前天气。
2. 在地图上打开 `Homeless Pet Helper > Preview > Outing Weather`，设置天气类型和强度，点 `Set World Weather`；再选小院或停车棚出发，现场继承同一天气。关闭 Play 会恢复默认小雨。
3. 从代码切换用 `MainLoopPresenter.SetWorldWeather`，初值集中在 `OutingWeather.InitialWorld`，改效果密度、速度、颜色走 `OutingWeatherGraphic`。

## 表现与预算

- 雨：短、半透明、有柔边的雨滴，近处略粗，落下的方向与滴尾一致。地面涟漪仅在现场出现，大地图不模拟地面落点。雪：大小不一的松散雪团随风飘落，不再用六角晶体或菱形符号。雾：两股缓慢漂移的冷灰雾带，重雾增加背景层的密度。
- Main 大地图视口和两个现场 Prefab 静态共用同一绘制类。大地图层覆盖视口，不随平移被拖到边外，保留地图昼夜及原区域雾。现场层在动物和机关下方；不拦射线、不重排 HUD、不加贴图、Shader 或粒子对象，动画网格最高约 30 次/秒。晴朗只清空；大地图失焦停，现场复用 `MotionScope`。
- 本轮不接天气时间表、随机权重、玩法修正或存档。调试天气和本次外出的天气快照只在当前运行中有效；重启按固定默认值恢复。将来一旦接天气变化或玩法影响，再让业务会话持有快照并按已有外出保存契约续玩，不让绘制器决定规则。
