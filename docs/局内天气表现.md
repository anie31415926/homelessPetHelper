# 全图天气与局内继承

2026-11-25 表现首版，2026-11-26 接时间表。天气属于整张地图，不按地点分配。类型为晴朗、雨、雪、雾，后三种各有小、中、大三档。世界天气由 `WorldWeatherSchedule` 按行动时钟推导：每 180 游戏分钟一块（1440 分钟一天共八块），按配置 seed 与已累计分钟取确定性样本；晴朗约 55%，雨 20%、雪 10%、雾 15%，非晴朗再分小 45/中 40/大 15。结果不写存档，重启和读档按同一分钟复现；成功出发进入现场时取一次世界天气，清障/解谜和救助读取同一份快照；正在进行的外出不会随之后的世界天气切换。室内保留状态但不直接画室外雨雪雾。概率与块长度是试玩参数，不是正式玩法规则；天气暂不影响战斗、计时或奖励。

## 试玩与调整

1. Unity 打开 Main，进 Play 后点外出。地图全屏显示当前天气。
2. 正常试玩时地图天气随行动时钟变化：每次开地图、回站、从现场回地图时重采样。要固定看某一档，在地图上打开 `Homeless Pet Helper > Preview > Outing Weather`，设置类型和强度后点 `Set World Weather`（调试覆盖，之后出发的外出继承该值）；点 `Resume Schedule` 交回时钟时间表。
3. 从代码取当前值为 `MainLoopPresenter.WorldWeather`，调试覆盖用 `SetWorldWeather`，恢复时间表用 `ResampleWorldWeather`；规则和权重在 `WorldWeatherSchedule`，改效果密度、速度、颜色走 `OutingWeatherGraphic`。外出期间天气冻结在出发值。

## 表现与预算

- 地点现场也读取大地图共用的行动时钟与昼夜色阶。进入探索、清障/解谜或逆塔防时按当前时间给现有场景图调色：室外较明显，室内较轻。不加图片、遮罩或 Shader，动物、可操作物、天气和 HUD 保持原色，不影响时间或规则。
- 雨：短、半透明、有柔边的雨滴，近处略粗，落下的方向与滴尾一致。地面涟漪仅在现场出现，大地图不模拟地面落点。雪：大小不一的松散雪团随风飘落，不再用六角晶体或菱形符号。雾：两股缓慢漂移的冷灰雾带，重雾增加背景层的密度。
- Main 大地图视口和两个现场 Prefab 静态共用同一绘制类。大地图层覆盖视口，不随平移被拖到边外，保留地图昼夜及原区域雾。现场层在动物和机关下方；不拦射线、不重排 HUD、不加贴图、Shader 或粒子对象，动画网格最高约 30 次/秒。晴朗只清空；大地图失焦停，现场复用 `MotionScope`。
- 表现层不决定玩法：时间表是纯 C# 推导，绘制器只接收样本，天气暂不参与战斗、计时或奖励。天气不新增存档字段，只依赖已持久化的分钟与配置 seed 复现；若以后天气影响玩法，再按玩法确认流程讨论规则，并把快照纳入外出保存契约。
