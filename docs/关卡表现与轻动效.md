# 关卡 UI 与轻动效

2026-11-22；接续[关卡物件素材](关卡物件素材接入.md)，本轮只改表现。用户要求补图四遗漏 UI，统一控制可复用的 hover、障碍物等小动效。当前仍为临时美术与试做规则，不改变规则、数值、存档或首批承诺。

## 已接入的范围

小院救助场景的手牌改为手绘纸卡，图标与名称/费用左右分区，选中/禁用有独立表现；双蓄力条复用手绘轨道/填充，分别用行动与爪印标识，真实零值无填充。状态和意图有纸底，意图移到右侧菜单下方避开动物；正文沿用本地化 Key；可选提示保持原显隐，不遗留空白底板。顶部中央继续避开关键控件，交互仍在统一安全区内。

清障与救助按钮、手牌及共享暂停/设置/目标/确认菜单已接入缩放反馈。动的仅是静态 Prefab 中的 `MotionVisual` 子层；原根节点、点击范围、拖拽与强指引目标保持稳定。草木轻摆、水面呼吸；清障成功后的消散、箱子/箱桥落位仅观察已成功的场地快照变化。撤销/恢复清除旧特效，不倒放或重做业务。

保留手绘控件页、27 个物件切片与统一全屏黑遮 `88/255`。没有新生图、改导入参数、新纹理或第三方依赖；此次增加的是静态 Prefab、共享动效资产及代码。资源台账检查结果另见本轮证据，图片仍 temporary。

## 轻量选型与所有权

| 层 | 职责与状态 |
| --- | --- |
| `Framework.UI.Motion/MotionLibrary` | 共享只读 ScriptableObject：七个预设、曲线、时长、偏移、缩放/旋转及场景采样率；不存播放进度 |
| `MotionScope` | 面板显式绑定资产，持有 UI/场景两个非缩放时钟；暂停冻结场景，菜单反馈继续；失焦/切后台冻结两者 |
| `UiMotionFeedback` | 每个按钮独立持有输入、过渡起点与进度；中断从当前姿态过渡，禁用/关闭/复用/失焦/后台复位 |
| `OutingFieldGraphic` | 每个场景独立固定 16 槽表现缓冲；共享预设采样，默认 20 Hz 刷新自己的物件网格；无粒子对象生成 |

普通方法足以连接规则与表现；重复的是视觉预设、时钟与生命周期，因此抽取以上四个具体职责。未引入全局管理器、注册表、事件总线或补间库，也未新建程序集。Framework 不反向依赖业务；现有救助战斗动作继续使用原业务时钟，不全量迁移动画。

代价是每个活动面板一份时钟、每个活动控件一次轻量状态比较，运动期间更新独立视觉层；草木每 50 ms 更新网格。背景、物件、手牌与救助交互层按职责拆 Canvas，未按每个按钮创建 Canvas。UI/场景动画均不阻塞交互，不延迟结算；失焦后不补播后台的时间。共享配置查找缓存只保存定义，不共享实例进度。

配置启动时拒绝缺失/重复预设、非有限数值、非法时长/缩放/透明度、缺失曲线及不合法采样率。循环曲线首尾应连续；Hover/Press/Selected 曲线结束为 1，Place 结束为 0 回到原尺寸。Clear 只作用于独立物件顶点透明度，不改变整张 Image 或叠加全屏遮罩。

## 后续实例如何使用

1. 在 Prefab Mode 编辑已保存的 Prefab，保留业务绑定；在面板放置 `MotionScope`，引用 `Assets/Settings/UI/LevelMotion.asset`。不要重跑旧面板创建/换肤工具。
2. 按钮根保留 Selectable、透明 Image 点击区及 LayoutElement；视觉子层使用拉伸锚点、零偏移、单位缩放、零旋转，承载底图/图标/文字。`UiMotionFeedback` 的 Scope、Control、Visual 显式绑定，Button.targetGraphic 指向视觉底图；视觉图片不接收射线。
3. 列表 Cell 沿用现有池：救助手牌在 Bind 时显式注入面板 Scope；Cell 资产的 Scope 留空是装配边界，不能自行寻找全局对象。每次换数据、禁用/归还都复位，不把进度写回共享资产。
4. Scope随所属面板一起启停，业务拥有者通过 `SetScenePaused` 设置场景暂停；只在成功快照后触发表现。触屏只有按压反馈，鼠标才有 hover；拖拽让视觉回位，原拖放处理继续持有业务输入。
5. 扩展效果先判断只是参数还是新的表现种类：参数优先改共享资产；新 Cue 需同步枚举、配置校验与契约测试。不要用动画回调当作清障/扣费/结算凭据。

`LevelPresentationAuthor` / 隔离 `LevelPresentation` 任务是本轮一次性增量迁移入口，会拒绝已接入资源。只在无该动效接入的保存快照使用；当前源 Prefab 已保存，后续直接编辑。导入曾在临时副本因可注入 Scope 留空被旧 Bind 帮助函数拒绝；修复为显式可选注入后在同一隔离副本重跑成功，失败副本没有直接覆盖源工程。
