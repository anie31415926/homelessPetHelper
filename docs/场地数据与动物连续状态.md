# 场地数据与动物连续状态

2026-11-22，用户同意把场地尺寸和同地点布局提升为数据，并要求动物从初遇、救助到返站的状态与表现延续。本文描述当前实现；具体数值仍是试玩样例。

## 场地配置

入口仍为 `GameContent._fieldConfigs` 的显式 TextAsset 引用。每份 JSON 的 `pointId` 指向地图地点，新增可选 `layoutId` 标识该地点的一套布局；小院现为 `yard.main`。同一地点可绑定多份不同 `layoutId` 的配置，重复标识、未知地点报错。旧版缺失或空 `layoutId` 兼容为 `pointId`，已有单份配置选择保持不变。

- 行列由两种 `approach.templates[].rows` 的矩形字符串数组推导，不再固定为7×8。行不能为空、长度相等，格子数上限1024仅为资源保护，并非可读性或触控验收上限。
- 同一场地的两种开路模式须使用相同尺寸与出入口；路线、箱子、桥和杂物索引都按本份配置的列数解释：`cell = row * columns + column`，原点仍在左上。
- `width` / `height` 描述场地坐标尺寸；`grid` 描述格子在该场地的覆盖矩形；动物比例、三条路的格子序列与路口继续独立配置。仍保留三路、四邻接及原有两种开路规则，不支持任意曲线或任意路数。
- `OutingFieldCatalog.Get(pointId, outing.Seed)` 先按布局ID排序，再用稳定哈希选择，结果不依赖输入数组顺序或进程。配置集合改变时选择可能改变；没有引入局中存档或已出发关卡热切换。
- 两阶段沿用同一选中布局。坐标转换、输入命中、Cell摆放和指引跟随实际行列；Cell来自已绑定静态原型，按需扩充且复用，隐藏多余实例，上限同配置。引导按模板ID匹配，加载时拒绝越界目标。

当前运行内容仍只有原来的小院布局。9×10与同地点多套布局用于测试，不自动作为新关卡投放。地图点位的实际美术/按钮排布仍在静态Prefab中编辑；扩尺寸、增加布局后还需验证可解性、三路可完成性、动物比例、热区、文字和图片成本。

## 动物状态与阶段

唯一可变状态仍由 `AnimalIndividual` 持有；各界面只接收不可变 `AnimalSnapshot`，不从图片推断业务状态。

| 阶段 | 状态来源与变化 |
| --- | --- |
| 进入开路 | 按求助对应的 `rescueEncounters` 创建一次身份；初始饥饿、脏污、杂毛、护理权限来自配置，情绪/应激/行为来自 `initialDisposition` |
| 开路完成、进入救助 | 把同一个 `AnimalIndividual` 交给 `SiegeRescueActivity`，不重建、不重置脏污或身份 |
| 救助成功 | 一次性应用 `rescuedDisposition` 的情绪/应激/行为；保留当前饥饿、脏污、杂毛、健康和护理权限，不自动进食/清洁/治疗 |
| 返站、入站 | 原有入站协调器继续移交同一身份和状态；总结采用入站快照，历史总结的文字与图片都反映当时状态 |
| 站内与护理 | 场景读取当前状态；实际清洗/梳理才修改对应污渍场和数值。暂停、检查、界面切换不自动清洁 |
| 存档恢复 | 沿用已有站内检查点，恢复身份、当前状态和实际局部污渍；旧档中已保存的污渍不重新生成 |

两个当前样例仍为：初始紧张、无急性应激、观察；成功后放松、允许靠近；饥饿保留，初始脏污65、杂毛50。`initialDisposition` / `rescuedDisposition` 的枚举值沿用 Animals 中已定义枚举，非法枚举拒绝。schemaVersion仍为1；旧内容缺少整个对象时兼容原样例默认，现有配置已显式填写。缺省语义仅供旧内容兼容，新增内容应显式配全。

健康目前仅支持已明确 `knownHealthy` 的样例来源；工厂和救助入口都拒绝把未知健康直接当健康。此实现没有新增伤病生成、诊断或治疗规则。提前返回/失败不入站，局中进度仍不保存；重试是新遭遇身份，已入站动物保留原身份。

## 表现与资源

`Animals.UI/AnimalCoatView` 共享只读脏污表现：复用现有 Image/RawImage 和图片透明通道，按动物身份稳定产生归一化污渍/杂毛，强度跟随0～100状态，零值清除对应表现。已接清路动物、小院救助移动动物、旧车棚救助动画动物、返站总结和站内静态/动画动物。不同姿态的污渍是同身份的归一化表现，不承诺不同轮廓逐像素同一位置。

每个启用实例拥有一份128²派生纹理与材质，数据不变时不重建纹理，关闭/销毁释放，重开恢复；Shader、Graphic和拥有者均在Prefab/场景显式绑定。未新增图片文件、资源加载框架或运行时面板树。站内初始护理场同样按动物身份和实际强度初始化，已有局部护理场继续原样保存/恢复。站内小动物概览按当前数值显示程度；护理近景保留实际局部擦除位置，概览暂不逐像素复现擦除位置。

## Mask下动效整改

用户追加指出暂停页hover被裁切。共享 `Widget_LevelOverlays` 四类弹窗的滚动正文原内边距为0，按钮放大后越过RectMask2D。已按共享 `LayoutMetrics.gap` 增加正文四边动效空间，保留Mask、热区和弹窗栈；长内容仍滚动。规则与验收清单已加入[UI排版规范](UI排版与可读性规范.md#7-画风与工程落地)，要求检查完整动效轨迹、超调、首尾和滚动两端。
