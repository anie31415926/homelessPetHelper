# 大地图拖动与布局

本轮授权：大地图支持大图，并可拖动。沿用现有地图和建筑素材，Main与`SC_CityMap`共同使用静态`Panel_CityMap.prefab`。

## 操作与布局

- 地图独立双向拖动，有轻惯性；四边限位，不把背景拖出空白。背景、建筑及名称都在同一地图画布中，移动时保持相对位置。
- 点建筑或名称仍然选地点。从建筑上滑动超过uGUI阈值后取消点击，避免拖地图时误选地点。拖动只由第一根有效手指接管，另一根手指不能抢走手势。
- 开地图和切换选中地点时定位到该地标；状态刷新和暂停恢复不抢回玩家已经拖开的视野。关闭、暂停或失焦会清理旧手势与惯性。
- 顶部标题/状态和底部返回/出发操作固定在安全区。地图约占中部可用空间的三分之二；地点说明独立纵向滚动，切换说明或重开时回到顶部。
- 地图边缘的其他建筑允许自然裁切；地标/文字始终受地图Mask裁切，不通过关闭Mask绕过可见区。

## 代码与编辑入口

`Assets/Scripts/Modules/Outing/UI/CityMapScrollRect.cs`继承uGUI `ScrollRect`，管理地图等比尺寸、选点聚焦和手势所有权。`CityMapView`使用已保存引用管理选点显示、说明回顶与暂停状态，不查找节点，不拼装运行时UI。规则、地点回访及存档代码没有变更。

后续在`Assets/Prefabs/Panels/Panel_CityMap.prefab`的Prefab Mode编辑：

1. `SafeArea/MapBodyViewport/MapViewport`的`CityMapScrollRect`中，`Minimum Map Width`是1080设计基准下的地图宽度，当前1680U；背景较宽或可见区较高时会继续等比放大以铺满窗口。尺寸只在布局变化时更新。
2. `Content`与`Map Image`均指向`MapArt`；地图高度按Sprite真实宽高比计算，不再绑定固定竖图比例，也不缩放Canvas或拉伸图像。
3. 建筑是`MapArt`的直接子节点，继续使用归一化锚点。替换为不同地形排布的图片时，需要一并调整地标锚点；拖动组件不会推断建筑位置。
4. 中部两个区域的`LayoutElement`控制地图/说明的空间分配；保留最小热区、字号、安全区和独立滚动，不用缩字解决长说明。

`Assets/Scripts/Editor/CityMap/CityMapPanUpgrade.cs`是本轮一次性增量编辑工具，使用`PrefabUtility.LoadPrefabContents`保存现有Prefab，没有重建图片绑定；在隔离工程运行。Main和预览场景原有`MapArt`的`AnchorMax.x/y`及`SizeDelta.x`覆盖值已定向清理，避免覆盖新Prefab造成变形。其他场景覆盖和所有素材/meta GUID保留。日常编辑无需重跑该工具。
