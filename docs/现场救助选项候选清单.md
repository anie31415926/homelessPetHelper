## 作用分工补充（用户已确认）

**低压交流**改变玩家自己的朝向、目光等姿态，减少这部分压迫；**轻声回应**接住动物已经主动发起的关注或交流，不是不断呼唤来刷信任。二者都不自动解除距离压力，也不直接取得触摸或转运许可。以下具体表现与后果仍需讨论，不把分工认可扩大为全部效果已经定案。

每项按“已有线索 -> 玩家动作 -> 动物/环境回应 -> 后续机会”设计。表中的不同回应依条件选择，不是隐藏随机分支；这里不新增距离数值、信任条、固定回合门槛、资源消耗或动画资产清单。

### 跨选项的画面承接

1. **真实位移与镜头变化分开。** 后退/接近须有稳定的地面或物件参照，不能只缩放动物图或拉远镜头假装移动；玩家动作与动物自主移动分开表达。本轮不确定第一/第三人称或正式距离实现。
2. **动作有结束，事实不自动复原。** 玩家后退后停在新位置；食物与遮挡保留，食量按真实取食变化；已消除来源保持消除。一次慢眨眼可以结束，但合适姿态不会随换轮无故变回压迫姿态。
3. **动物回应不等于统一奖赏。** 它仍原地观察、拒绝伸手、躲进遮蔽都可以是可读结果；不是所有正确行动都让它走近或同时解除全部问题。表中是游戏表现草案，不以单一姿态推断现实动物情绪或同意。
4. **错误要有局部因果。** 不合时宜的伸手可使它避开手、暂停靠近；逗玩可转移探索注意。保留已发生的进食、环境与个体经历，不全清，也不新增一次误选必应激/失败的规则。方法正确但前提未齐时，维持已有的“不额外恶化”边界。
5. **表现不代替结算。** 当前条件、历史与行动先决定结果；动画结束、叫声次数、现实等候秒数不判成功。自由观察不额外走回合，其他行动也可带来动物自主回应，并非只有选等候它才会行动；游戏耗时不按动画长度重复计算，数值另定。
6. **接近、接触、接受安置分别可读。** 原地允许靠近、主动交流/玩耍、闻探安置处、明确接受不是同一动画换文案。已满足既有收尾条件就提供独立收尾，不新增互动打卡；遮蔽也不自动变成接受安置。

### 连续两次退开的处理提案

- 首次退开后仍有距离压力、且有安全可退空间：再次退开就有新的实际位移；动物可以仍留原处，不能强制它跟着后移。
- 若动物期间自己靠近，后续退开也从双方最新位置计算；把双方动作都表达出来，不能悄悄重置站位，或只因净距离没变就省略动作。
- 首次已留出足够空间，本次再退没有独立用途：建议不再新发“退开”，维持空间由“安静等候”承接。失效的锁定退开保留并说明原因，不执行、不消耗；这属于本轮正式分工提案，不直接替换现有样本的“保持距离”反馈。
- 已到安全可退边界仍有压力：说明空间限制，转向其他适用方法或常驻求援，不假演穿墙后退、不把它算成玩家操作失败。边界与距离数值本轮不定。

### 同一现场的因果推演

以下是有食物需要、谨慎但允许非接触共处的普通猫样例，不是固定通关串，也不将十类方法全部塞进同一现场：

1. **放食**：食物出现，它仍因玩家过近没有取食；画面与记录都是“食物已放，尚未吃到”，不是食物卡一出就减饥饿。
2. **退开**：玩家实际后移；其他前提适宜时，它自主到食物旁吃。若仍需空间，再次退开应继续移动；若空间已经合适，则等候承接，不再凑一张同义退开。
3. **等候**：它继续完成取食，吃过的事实保留。之后主动关注玩家且愿意听声音，可以轻声回应；若它转去探索安置处，则不必把它叫回。
4. **分支 A，继续相处**：当前愿意玩时可以互动；回避手就不抚摸。关注已经转向玩具，不能同时把这一段算为检查安置处。
5. **分支 B，不做亲密互动**：不给玩具或人手干扰，留出适宜检查空间；符合该样例的探索条件时，它自主闻探。短暂探入不算接受，按既有明确接受与安全条件支持独立收尾，不加一张必抽牌。

若在第 3 步误伸手令它退避，后续画面应是它与手拉开距离、已吃的食物仍已吃过；给回空间后按最新条件恢复机会，而不是重新演开局整套流程。任一分支若始终缺少接受条件，仍要能稳住、调整或求援，不能等固定轮数自动成功。

先按用户最新反馈继续[重复后果与趣味插曲](重复行动与趣味选项设计.md)，同时核对“动作改变哪件事实、对应画面如何承接”，尤其是连续退开与等候的分工、交流不等于接触、玩耍与安置探索会竞争注意。用户尚未认可本表全部分支，不进入制作图片、动画或正式状态系统。

## 范围与读法

- 先设计现场救助选项，同步讨论动作画面与局面影响，确认后再实现正式距离系统与画面承接。复用已经确认的行动分工和供给约束，不把停车棚五方法当完整方案，也不为填满三个位置硬加同义牌。
- 资料分为真实个案、机构一般指南和游戏改编。家庭适应、长期照护不等于街头救助；表中行动名称、效果和出现条件是游戏提案，不是声称每项都在某次真实救助中发生过。
- 本批聚焦已经有介入理由、且没有迫在眉睫危险的接触局面。身份不明、疑似重伤、强烈防御、道路/高处等危险情况，先核实或专业求援，不用安抚操作代替紧急处置。
- 同一行动可以影响空间压力、注意力、需求或现场干扰，也可以暂不推进；不统一换成“信任 +1”。猫的慢眨眼等行为不直接套给狗，个案偏好也不泛化到所有个体。
- 编号用于讨论保留/合并/暂缓，不代表发牌顺序或必做步骤；本批不是完整性声明。暂不确定数值、耗时、物资数量、失败幅度或随机权重。

## 不作为抽取门槛的入口

- **自由观察、查手册**：仍是常驻自由操作，不把看清已有线索变成消耗一回合、必须抽到的能力。02 等候是让情境过程继续，不是收费看状态。
- **联系专业救援/兽医**：保留常驻出口；疑似重伤、危险位置、超出现场能力时清楚提示，不要求先抽求援牌。具体交接与结算仍待确认，不捏造普通救助成功。
- **准备安置、确认收尾**：按已有规则开放，不让玩家为已经成立的安全机会空等牌。
- **停止不适用互动**：收起玩具、停止伸手等优先作为行动结束或情境调整，不另加唯一“停止牌”，防止已确认的“不因等牌卡住探索”倒退。
- **简单现场医护**：已有方向按另一个专题细化；本批不列徒手抓捕、追堵、镇静、喂药、强行抱起或专业器械操作作为普通安抚选项。真实资料提到的操作不因此自动获得游戏化许可。
