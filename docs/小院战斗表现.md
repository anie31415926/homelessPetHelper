# 小院战斗表现样板

2026-11-24。沿用 Main 实时救助的手绘玩具图；小院用于看清落牌、出手、命中和退场的前后关系。不重画场景，不修改单位、塔位、寻路、命中判定、数值或存档格式。

## 表现规则

- 落牌只在实际提交成功时播放。骨头与鱼干短跳，羽毛飘动，毛线球和风车随位移旋转；选中圈、点击位置与实际路线不随绘制姿势漂移。
- 机关冷却尾段收紧，出手回弹。纸箱发射不规则纸团，落点带碎纸；其他常见投射物也有抛物线和基本材质区分。现有范围预警仍显示真实边界，结算则换成有方向的刷痕，不再用满区域的圆形闪光。
- 确认损失的玩具从最后位置缩淡，散出几片纸屑。抵达目标和合成不会误用损失特效；塔被拆时也有短暂散开反馈。
- 五条本机 ComfyUI 短音效覆盖落牌、纸团发射、纸团命中、狗窝发球和退场。合成继续用已有音效，普通走动不逐帧触发声音。音频沿用 Main 的音量/静音和有限声道；每音效最多一路，并有至少 110 毫秒冷却。

## 实现与修改入口

1. 战斗事件由 `SiegeState.EmitEffect` 记录已成立的动作与结果。环节和坐标来自规则快照；事件序号只用于消费，不写入存档格式。暂停不推进战斗表现；结束后只允许短暂的纯视觉尾段。
2. `SiegePresentation.cs` 集中管理移动姿势、机关动作、弹道、受击、碎片与音效路由。新动作先复用这里的姿势或碎片函数；片数、曲线、颜色、寿命应在这里调整，不在各关卡复制脚本。
3. `SiegeBattlefield` 仍承担投影、绘制接线和命中测试。碎纸复用现有 Canvas 网格批次，不新增每粒物体、常驻发射器、材质或 Shader。每个碎片簇固定 3–6 片，战斗记录池仍限制 192 条。
4. 音效源和配置见[生成批次](../art-source/audio-basic-20261120/yard-combat-20261124/README.md)；声音替换优先保留 ID，增删后验证 Main 音频资产契约。

## 试玩入口

正式启动或 Main → 救助站「外出」→ 地图「小院」→ 开路 → 救助。先安静看落点、走路、守方预警和退场，再开声音比较。小院的普通遭遇是狗，适合看小骨头与狗窝机关；停车棚的猫遭遇可看纸箱纸团台。自动化演示在小院背景中注入可重复的纸台遭遇，不改变正式地点绑定。
