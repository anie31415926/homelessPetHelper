# 逆塔防：狗叼回去

2026-11-20。用户在本轮明确确认以下边界，只落地叼取，不扩做拖鞋/替身、牵制、修整或新的单位族。当前是独立 Unity 试玩机制，数值可调，不代表正式平衡、Main已按物种接入或渠道验收。

## 已确认规则

- 预告锁定合法近身单体，至少给一次实际玩家策略窗口；出手复查同一目标。目标损失、正在转线、已离开范围或受保护时落空，不临时改抓其他单位。
- 预告期间允许正常操作；合体后公共流程映射目标ID，在合体结果的实际锚点重新检查范围，不因为换ID免费避招。
- 命中后沿叼起时所在路线有限后搬，不转线、不传回出生点、不扣耐久，不把搬运当作抵达或合体。
- 搬运期间暂停该单位自主行走/拆塔，不能改道、付费或自然合体，也不成为机关单体/区域攻击目标。其他单位和机关正常运行；被搬单位暂离场面交互，不发放或接受护套/稳绳。
- 稳绳/抗推和护套不免抓，也不会被这次搬运消耗；抓取取消尚未完成的连敲，不在落地后补发。
- 动物从叼取出手起停止旧守门，搬运及收招期间不能再释放守门/飞扑；落地恢复正常推进，并获得明确再抓取保护。已落地单位再合体仍继承保护，不洗掉它。
- 策略窗口、手动暂停和失焦冻结模拟毫秒与演出；命中不依赖UI/动画回调。结束局面冻结在当时状态，重开产生全新Session。

## 技术归属

`SiegeCarry : SiegeAnimalSkill`只拥有合法目标、叼取/原路位移和落地效果。仍由`SiegeAnimalCasting.Plan/TryRelease/Advance`处理窗口、行动条消费、Windup/Active/Recovery、唯一命中、冷却与互斥。公共执行器增加统一`AdvanceActive`回调，重复调用同一模拟时刻不会重复搬运；没有在Session或Combat再建一套叼取释放分支。

单位显式保存`IsCarried`、起止模拟时刻和原路线距离；不是借用普通改道。只在技能的Active回调按时间插值，落地这一拍不额外再自主移动一整拍。快照复制这些值与独立Cast/冷却表，不在静态处理器存局内状态。

`HoldProtectedUntilMs`沿用旧快照名称，现在作为按住/叼取共同的再抓取保护时刻；没有维护两套会漂移的保护计时。旧枚举编号保留，新增`Carry = 5`。配置继续改源并运行现有生成器，未手改DTO/Settings生成物。
