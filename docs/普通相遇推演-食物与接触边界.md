# 普通相遇推演：食物与接触边界

创建日期：2026-11-17；更新：2026-11-18。状态：用户已确认可选互动、接近/安置反馈与重复选项处理方向；具体触发、供给覆盖和实现边界仍待细化，不是已实现或已执行测试。

## 只验证一个问题

**不增加操作负担，能否让同一只普通动物按自己的需求行动，让玩家有不止一条合理救助路径？** 本案例不加入高难、多次相遇、随机成功率或新资源系统。

沿用[普通相遇推演方向](回合交涉与组合流程.md#文字推演提案普通相遇为主挑战复用)，用[真实参考](真实救助案例与行为参考.md)校正三个容易混淆的关系：吃东西不等于接受接近；暂时躲藏不等于全部进展丢失；愿意靠近或玩耍不等于接受抱起和转运。

本文是综合资料后的虚构游戏情境，不是复述某次真实救助，也不是现实捕捉指导。参考中的犬只个案只启发边界区分，不据此给猫套用犬只姿态或处置办法。

## 场景与开局

场地为安静停车棚旁的遮挡处。求助信息已明确这只猫需要临时安置，现场没有正在发生的紧急危险或明显急伤；核实身份和专业检查不在本案例展开。开路已完成，适宜的开放安置处已就位，不另抽一张唯一的“准备运输箱”才能推进。

这只猫有些饿、对陌生人谨慎、对小玩具有兴趣；不喜欢手突然伸近。它不是固定的“谨慎型”或“好奇型”，以上特征可以同时存在，也不规定所有猫都如此。

开局表现：它从遮挡边探头，注意食物袋；玩家动作稍大时会缩回去，但还在原处看。画面线索表达它想取食又想保持距离，不直接标出下一张正确答案。

| 区分的事情 | 当前情况 | 不能顺便推定 |
| --- | --- | --- |
| 需求 | 有取食需要 | 吃完就完全信任 |
| 情绪与距离 | 谨慎，不接受直接逼近 | 它讨厌人或已经应激 |
| 当前关注与行为 | 看食物，暂留遮挡边 | 每回合都会逃跑 |
| 互动与安置边界 | 接触和转运是否合适仍需读回应 | 有玩具就能摸，能摸就能抱走 |

这些是叙事判断维度，不是新增四条 UI 数值，也不确定正式字段、阈值或状态枚举。

## 决策点一：它想吃，但不想贴着人吃

**可读倾向**：身体留在遮挡边，视线追着食物，玩家靠近时缩身。

| 玩家选择 | 本案例拟定回应 | 后续仍缺什么 |
| --- | --- | --- |
| 先退开，再提供食物 | 它不再继续往里缩，仍盯着食物；后续有取食机会才会去吃 | 退开不消除饥饿，也不直接得到触碰许可 |
| 先放下食物，再退开 | 食物出现时先闻或观察；距离压力解除后，再从遮挡边出来取食 | 放食不让它无视玩家距离，也不强制走到玩家脚边 |
| 前提不足时先等候 | 局面不因这一选择额外恶化，但不能靠原地等待自动同时解决距离和饥饿 | 当前为什么没推进要读得出来 |

前两种合理顺序可以到达相同的取食局面，不判谁输给唯一操作串。动物取食位置也不等于玩家位置：它可以取到食物后退到边上吃。具体移动和取食形式只是本案例表现候选，不保证所有食物形态都能叼走。

## 决策点二：吃到了，它依然留意着你

**可读倾向**：它在边上吃，偶尔抬头看玩家；不再寻找更多食物，但还没有邀请接触。

- 若现有空间已合适，等候可以让它继续完成取食；若仍因玩家位置停下来戒备，退开解除剩余的距离压力。两者依据当前线索选择，不把所有等候都写成加信任。
- 在这个明确已经获得足够食物、投喂没有其他用途的局面，不再新发同一投喂方法。若玩家此前已锁定投喂，不偷偷移除或解锁；保留并说明当前不需要，暂不可执行，不消耗选项或物资。玩家自行解锁后按正常回合刷新处理，具体提示形式待细化。
- 它可以吃完后整理自己、观察周围，再改变关注对象。这些是动物回应，不要求玩家为每段表现点击一次，也不规定必须多耗一回合。

这里记录“已经取食”的事实，同时保留“还不接受伸手”的边界；后续退缩不能重新把它设为开局饥饿。

## 决策点三：它愿意探索，但不一定想被摸

**可读倾向**：它走到遮挡边外观察，开始留意玩家身边的小物件，也会闻向安置处；人不动时愿意多停留，伸手时仍回避。这个组合表示探索机会，不是直接宣布愿意被带走。

这里比较两种策略，不要求两条都做，也不是固定连续发出的两张牌：

| 策略 | 玩家如何改变条件 | 动物可以主动做什么 | 不自动取得的结果 |
| --- | --- | --- | --- |
| 保持距离的互动 | 在它确实关注玩具时提供互动机会，不借玩耍突然伸手 | 向玩具探爪、走近一点，再回到自己舒服的位置；玩家读到它接受互动但仍回避手 | 互动不直接解锁触碰、抱起或安置；持续吸引它玩也不必然推进转运 |
| 给它自己检查的空间 | 退开安置处旁造成压力的位置，保留其可观察、可探索的空间，不持续用道具吸引 | 它可以按当前探索倾向走近闻看安置处，而不是必须先走到玩家身边 | 若仍有明确干扰或接近压力，单纯等候只是稳住，不能直接判定接受 |

这两种策略的差别是改变它的关注与机会：前者争取互动、看清偏好；后者减少干预，让它探索适宜安置处。不是一个加两点、另一个加一点的同类收益。前者可以转向后者，不要求玩够固定次数；玩具不是每次救助的必经步骤。

**具体回应是候选规则**：同一相关状态与同一行动得到一致结果，不对“探爪还是靠近”另外随机抽签。实际采用哪一种表现、机会何时形成，需确认后按条件细化，不能从表中的多个描述任意摇出一个。

## 决策点四：可以靠近，不等于已经能带走

如果它主动靠近或愿意互动，玩家不必再消耗一个接近选项来证明距离达标，但也不能直接结算救助成功。

**本案例收尾方向已确认，具体触发待细化**：它在空间合适时自行检查开放安置处；只是闻一下或短暂探入，不立即判接受。适宜条件满足，并主动进入、放松安顿，明确接受当前安置时，再提供独立收尾操作，不等待抽到另一张牌。此处只讨论这只猫适宜的安置表现，不要求所有动物都进同一种箱子。

- 若它已主动检查安置处，持续用玩具把注意力拉走不应算新的转运进展；玩家可以不继续干预，读它接下来的回应，不另要求抽到唯一“收起玩具”牌。
- 若它拒绝玩家伸手，退开可以让它恢复探索机会；此前取食、偏好和允许相处的事实保留，不必从头重新喂。
- 如果一直没有接受安置的条件，不靠“等了几轮”自动完成；继续调整或求援的出口保留。无物资仍须有安全选择，不保证任意条件都能完成救助。

“自行进入并放松安顿”已获认可为本例的游戏收尾反馈方向，不是现实中保证可以安全关闭运输箱或徒手处理陌生猫的判断标准。具体触发条件与静态资源怎样清楚表达仍待细化，不在本轮补写捕捉步骤。

## 用分支核对，而不是数回合

| 文字分支 | 需要成立的因果 | 要避免的假策略 |
| --- | --- | --- |
| 放食 -> 退开 -> 取食后留空间 -> 自主检查安置处 | 可以不玩耍、不抚摸，基于合适条件完成普通救助 | 必须把全部按钮按一遍才成功 |
| 退开 -> 放食 -> 适时互动 -> 停止干预，给出探索空间 | 顺序合理；互动改变关注与接触机会，但不是万能加分 | 玩具只换一段文案，或必须累计次数 |
| 取食后突然伸手 -> 它退缩 -> 退开后重新观察 | 普通失误影响当前机会，已吃过的事实保留；不在这里自定应激或逃离阈值 | 一次失误进度清零，或者无论如何都没有影响 |
| 已给足食物却连续投喂，或前提不足却一直等候 | 说明为什么不推进，供给不持续诱导空转；安全选择仍在 | 无效操作也反复加分，或抽不到一张牌就强制失败 |

以上是桌面推演检查，不是测试已通过。具体供牌不按分支脚本控制：仍沿用首轮三个选项、使用一个、最多锁定两个，以及每回合可稳住的选择；暂缺前提但有准备价值的方法可以保留，不能把手牌过滤成每次只剩正确答案。

## 接近与安置反馈

**2026-11-18，用户已确认以下反馈区分与本例表现方向；未实现。** 下面区分可读反馈，不是固定关卡阶段，不要求每只动物按顺序经历一遍，也不增加新的进度条。

| 当前表达的边界 | 本案例的表现方向 | 玩家应当读到什么 |
| --- | --- | --- |
| 仍要求空间 | 玩家动作接近时缩身或后退，注意力持续落在玩家的手与距离上 | 当前还不能直接逼近；结合已有线索留空间或处理干扰，不直接等同于应激或离场 |
| 允许接近或互动 | 在合适距离放松停留，或主动来闻看、接触玩具，但避开伸手或安置动作 | 可以相处，不代表允许任意触碰或带走；已经主动走近时不再要求多打一张接近牌 |
| 正在试探安置处 | 闻入口、探入后退出，仍在外面观察 | 有探索进展，但不是接受安置；不因为碰到箱子或短暂进入就结算成功 |
| 已接受当前安置 | 适宜安置条件已满足，动物主动采纳该方案；本例表现为自行进入并放松安顿，而非僵住不动 | 规则已支持收尾，给出清楚的完成反馈，独立收尾不再等牌或判隐藏成功率 |

**接受判定的已确认方向**：当前方案适合这只动物，且不存在阻止安全安置的距离压力、现场干扰或必要医护未处理；动物作出明确接受该方案的回应。不能只检查累计互动分数、吃没吃过、是否离玩家够近或是否没有反抗。不是所有需求都必须清空，不强制所有动物先吃饭、玩耍或抚摸。具体前提与触发条件仍待细化。

本例“自行进入并放松安顿”是游戏反馈，不将现实中的静止、僵住或停止挣扎解释为同意，也不提供关箱或抓取教程。停留不按固定秒数或回合数过关；具体触发及静态资源怎样清楚表达，需在明确试做范围后验证。

反馈文案候选：“它闻了闻入口，又退出来看你，还在试探。”与“它自己走进去，放松地安顿下来，已经接受这处安置。”前者保留观察与调整，后者明确支持收尾；不让玩家靠点击完成按钮来猜是否已经满足条件，也不在交涉前直接标最优行动。

动物仍可保有不喜欢伸手或抱起等边界，接受安置不等于彻底亲人。收尾不增加倒计时；接受之后玩家主动改变现场导致条件失效的具体撤回规则另行讨论，不借本节擅自增加失败触发。

## 选项供给与重复处理

**2026-11-18，用户已确认以下处理规则；尚未接入代码。** 先处理方法与当前局面的关系，不先增加冷却系统、组牌或复杂抽取权重。

1. **已完成且本次再用没有意义的方法，不再新发。** 本例已经得到足够食物、也没有其他明确用途时，停止新增同一投喂方法；不能为“活人感”给重复操作虚构收益。食物以后有其他用途须有不同的真实前提和回应，本轮不靠改牌名继续投喂，也不新增食物引导方法。
2. **仍有准备价值的方法可以出现。** 暂时不接受接近，不代表接近方法永久退出本次选项池；允许提前保留。缺前提但能稳住的合理行动不能一律禁用或过滤成只有当前最佳答案。
3. **同一手牌不新发相同方法挤位置。** 锁定项中已有的方法也计入本轮去重；这针对当前手牌，不禁止后续在条件需要时再次出现。退开、等候等安全方法仍可重复使用，不按“上轮用过”一刀切屏蔽。
4. **已锁定项保留归玩家决定。** 若局面变化使它本次已经没有作用，保留锁定项并说明原因，当前不能执行、且不消耗选项或物资；玩家可自行解锁，随正常回合刷新，不增加回合内手动重抽。具体提示形式未设计；不能因此把缺前提但仍安全有效的行动也标成不可用。
5. **已经得到的机会不再卡牌。** 动物已主动走近不再要求形式上的接近；已明确接受适宜安置就独立收尾。是否接受仍读状态和回应，不因缺少某个未锁定选项而把已有事实撤销。

去重必须与首轮三个选项、最多锁定两个、每回合至少一种安全应对同时成立。**如果某局面扣除无意义重复后不足以补齐位置，表示当前方法内容或供给方案尚不完整**：实现前核对并补足合理方法或另行确认边界，不用无效重复凑数，也不擅自减少位置、自动解除锁定或把全部内容变成必定推进的答案。单纯去重不能宣称已经解决全部空转问题。

| 用来核对的局面 | 已确认的处理方向 | 不能出现的结果 |
| --- | --- | --- |
| 已取食满足需求，下一回合刷新 | 不再新发无用途的投喂；继续读距离、关注与安置机会 | 为同一餐不断补投喂，占满手牌 |
| 前回合锁定投喂，当前已没有作用 | 仍保留，明确不适用原因；玩家解锁后按正常刷新处理 | 偷偷丢牌、自动解锁，或可点击浪费后还声称有推进 |
| 接近前提尚不足，但以后可能用到 | 可供提前保留；当轮仍有实际可稳住的选择 | 只给当前正确答案，或因暂缺前提将所有准备方法删掉 |
| 当前仍需要距离，上一回合用过退开 | 允许仍然有意义或承担安全兜底的重复 | 因全局去重或冷却，移除唯一安全应对 |
| 已主动靠近，或已明确接受安置 | 分别跳过形式接近、开放独立收尾；不把两者混同 | 等接近牌或收尾牌空转，或靠近直接判成功 |

以上仅为文字核对项，不是自动化测试结果；物资、锁定、短期无作用与未来有用的边界仍需结合具体方法核对。

## 已确认与下一步

**2026-11-17，用户已确认：玩耍、抚摸是可选策略，不是普通救助的必经步骤；只要适宜安置条件和动物明确接受已经成立，就可以独立收尾，不要求先完成亲密互动。** 这不绕过安全转运和必要现场医护的既有约束，也不将吃东西、愿意靠近或愿意玩直接判为接受转运。

**2026-11-18 补充已确认**：用户认可上述接近/安置反馈区分与重复选项处理规则。本例采用适宜条件下自行进入并放松安顿作为接受安置的表现方向；无意义锁定项保留并说明原因、当前不可执行也已确认。具体接受触发、动作效果、去重/过滤算法及候选不足方案尚待细化，不强制全部动物主动进箱，也不将本次规则确认扩大为 Unity 改动授权。

**本轮覆盖核对已完成**：见[源码事实、候选集合检查与最小试做范围](普通相遇选项覆盖核对.md)。现有码有五种方法且案例供给已经同手牌去重；主要差距为状态无意义投喂、锁定项可用性，以及准备安置无条件接受。本例可先复用现有方法，候选集合检查不代表 Unity 新规则已通过；试探安置与其他个体偏好仍有覆盖边界。下一步确认所列现有案例的小范围开工范围，不重复讨论两组规则。未改 Unity，不设计完整性格、多次相遇、存档或新 UI。
