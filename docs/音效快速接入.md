# 音效快速接入

2026-11-20。复用既有 AudioService，不另建播放器、全局单例或逐帧扫描。

## 按钮接入

现有 Main 的救助站、地图、逆塔防按钮已配置默认轻点音；手牌/材料动态 Cell 从静态 Widget 继承组件。禁用按钮不因鼠标/键盘输入发声，点击关闭面板也保留已成立的那一次反馈。

**新按钮只需加 `ButtonAudio` 组件**（Add Component → Audio → Button Audio），默认 `ui.tap`，不用再给 On Click 手动加播放回调。在 Inspector 的 **Cue 下拉**改音效，勾 **Silent** 则该按钮不响。支持多选批量改；Custom cue 可填写后续目录新增 ID。

**整组按钮一键加**：在 Prefab Mode 选中面板或按钮父节点，执行菜单：

`Homeless Pet Helper > Audio > Add Button Audio To Selected Hierarchy`

工具包含隐藏按钮，已有组件不会重复添加，不覆盖既有回调、Cue 或 Silent；支持 Undo。它只加音频组件，不重建 UI、不添加 AudioSource，也不会给每个 Widget 新建遮蔽父级的 Scope。

## 新面板与动态列表

Main 已有三个显式绑定的 `AudioScope`。新增按钮或克隆 Cell 放在这些面板内，默认使用最近的父级 Scope，不用逐个传服务。

新建独立面板时，在面板根节点加 `AudioScope`，由装配 Owner 明确绑定：

```csharp
scope.Bind(audio); // audio 是 Main 传入的 AudioService。
// Owner 释放时先解绑，再释放自己持有的播放器：
scope.Unbind();
```

采用 MainGameRoot 的新面板，须将保存的 Scope 加进 Main Inspector 的 `Audio Scopes` 数组。不要在复用 Widget 根节点另放一个未绑定 Scope，否则会遮蔽外层依赖。独立预览未绑定时安静跳过，不私自新建 Listener 或另读存档。

`ButtonAudio` 在启用/直接换父级时缓存局部 Scope；池化 Cell 按正常禁用 → 换父级 → 启用流程复用。活动对象整条祖先树迁到另一个 Scope 时，也应禁用/启用 Cell 更新缓存。特殊跨层级展示可在 **Scope Override** 显式绑定，不按名字或全局 Find 查找。

## 代码与事件

普通代码一行，服务由构造参数/绑定取得：

```csharp
audio.PlayEffect(GameAudioCues.Merge);
```

需要观察结果时保留返回值：

```csharp
AudioPlayResult result = scope.TryPlayEffect(GameAudioCues.Notice);
```

Inspector 的动画/面板 UnityEvent 可绑定某个局部 `AudioScope.Play(string)`，输入同一 ID，不需要再写转发脚本。不要在已有 ButtonAudio 的同一次 On Click 再挂一次 Play，否则是两次请求；冷却不是重复订阅的替代修复。

| 常量 | ID | 建议语义 |
| --- | --- | --- |
| `GameAudioCues.Tap` | `ui.tap` | 普通按钮确认点击，默认 |
| `GameAudioCues.Open` | `ui.open` | 弹窗/小面板打开 |
| `GameAudioCues.Merge` | `game.merge` | **合成真正成功后**，不是勾选合成计划 |
| `GameAudioCues.RescueSuccess` | `game.rescue-success` | 救助确认成功，Main 已接 |
| `GameAudioCues.Reward` | `game.reward` | **奖励实际领取成功后**，不新造奖励流程 |
| `GameAudioCues.Notice` | `ui.notice` | 轻提示，仍需配可见反馈 |

本轮自动触发是默认按钮轻点和 Main 救助确认成功，其余音效已入目录、可选可调用，不虚称已经存在全部业务触发。没有 hover、滚动、逐帧或每次攻击声音。单独 Siege Editor 试玩未装配 Main 服务，不因此擅自常驻另一套音频。

## 音量与叠音

目录：`Assets/Settings/Audio/BasicAudioCatalog.asset`，通过 `GameContent.asset` 静态引用。按 Cue 改 Gain/并发/冷却；当前按钮 Gain 0.45、其他 0.7，按钮最多2路/间隔0.06秒，其他最多1路/间隔0.15秒，全局仍8路短音效。没有 BGM。

复用总音量/音效静音、应用失焦/暂停和外部打断；返回结果中的静音、冷却、声道满是正常拒绝，不逐次刷日志、不排队恢复补播。额外 `NotBound` 表示局部 Scope 未注入服务。ButtonAudio 只消费 Button 已成立的 onClick；直接程序调用 onClick.Invoke 也会像原有业务回调一样被视作一次明确事件，不代替调用方判断按钮能否执行。

偏好保存仍按[基础音频系统](基础音频系统.md#音量与存档)显式进行；本轮没有新增玩家设置面板，不把 Inspector 的 Silent 当玩家全局静音开关。
