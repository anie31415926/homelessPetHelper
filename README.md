## Unity 正式工程

工程目录：`unity/HomelessPetHelper`，版本 **Unity 2022.3.62f3 LTS**。在 Unity Hub 中添加该目录，打开 `Assets/Scenes/Main.unity`。

已搭建工程底座、启动入口、救助循环阶段模型与测试。正式 Main 场景仍只有相机和启动组件，不是完整可试玩客户端；用户已允许独立无图片白板验证，正式图片资源后续单独制作，HTML 原型完整保留。

已新增独立[选项管理规则模块](docs/选项管理模块实现记录.md)：可扩展数量、锁定、消耗与回合刷新，当前只开放单选。尚未接入主场景、动物效果或随机抽取，不代表完整交涉已完成；实现进度、测试与待讨论项均记录在该页。

白板体验：Unity 菜单 `Homeless Pet Helper > Preview > Open Option Whiteboard`，打开后 Play，可操作选择、保留、使用换轮、暂停与重开。验证场景不参与 Player 打包，样例供给不代表正式动物行为；静态 Prefab 支持后续设置 Sprite，资源管理的阶段判断见[白板 UI 与资源管理](docs/白板UI与资源管理.md)。

具体案例试做：`Homeless Pet Helper > Preview > Open Rescue Case` 为正常起点，`Open Stress Recovery Case` 为已进食的应激恢复起点，打开后 Play。体验观察、回应、主动靠近、独立收尾、只读总结和回站轻互动；状态连续保留，不因恢复或回站重置。为单只无明显伤病动物的 Editor 白板实验，未接存档，不是完整救助、医护或地图；假设与验证见[案例记录](docs/停车棚救助案例试做.md)。

救助站试做：`Homeless Pet Helper > Preview > Open Station Whiteboard` 后 Play。可看回站总结、选择站内动物、查看健康样例、抚摸和局部擦洗；完成护理才推进游戏时间。未接真实外出、医疗、领养或存档，详见[站内记录](docs/救助站模块实现记录.md)。项目恢复先看[最新阶段交接](docs/交接-项目阶段快照与救助站-2026-11-17.md)。

## 最新：开路 + 回合交涉

运行 `npm run dev` 后打开 `/outing.html`。随机进入场景解谜或清理开路，通道连通后“走近它”，根据动物表现选择食物、等待、玩具或接近，获得信任后邀请进箱并回站。设置可指定开路分支、三种初始状态或直接测试交涉。

- [回合交涉与组合流程](docs/回合交涉与组合流程.md)：共识、操作、规则、变化边界与待验证问题。
- `npm run test:outing` / `npm run test:outing:browser`：规则、160 个种子的开路可解性、完整流程、反应锁定、触控与多尺寸验证。
- 当前是有限模板与受约束变化，不是无限随机解谜生成器。几分钟是一轮体验目标，尚待真人试玩。
- 本轮没有持久化，不读取或修改其他原型的存档。

## 新增：外出救助原型

运行 `npm run dev` 后打开 `/rescue.html`，体验“走迷宫 -> 移动站位 / 投食 / 出网 -> 安全回站”。默认从花园下方进入；设置可改上方入口或猫狗。手机用方向按钮，电脑支持方向键 / WASD、空格出网、F 投食。首次测试只聚焦迷宫与救助，站内互动仅为简单反馈占位。

原有养宠入口 `/` 与存档完整保留。新原型没有存档、账号和后台，不会修改旧存档。

- [游戏设计总纲](docs/游戏设计总纲.md)：完整循环、逐模块共识与待定问题。
- [外出救助原型](docs/外出救助原型.md)：当前操作、参数与验证范围。
- `npm run test:rescue`：救助逻辑测试。
- `npm run test:rescue:browser`：救助全流程与响应式截图，需先启动开发服务器，默认端口 5173，可通过 `RESCUE_BASE_URL` 指定。

下方是原有养宠原型说明，后续新方向以游戏设计总纲为准。

竖屏养宠游戏原型，包含软萌玩具质感 3D 版与手绘 2D 版。React + Vite + Three.js / React Three Fiber，无后端，无远程素材依赖。

## 已实现

- 布偶猫与可卡犬，领养、改名和宠物切换。
- 三阶段洗澡：打泡泡、冲洗、吹干。可点击宠物、拖动揉搓，或点击护理按钮。
- 梳毛、修整毛发；量体温、听心跳、治疗；追毛线球。
- 三种食物、库存、购买、蝴蝶结和小方巾装扮。
- 饱食、洁净、健康和心情；每日照护奖励和睡眠推进。
- 幼年、成长、成年三个阶段，体型变化、相册和成长手记。
- 浏览器本地存档，可关闭音效、确认后重置。
- 3D 猫狗模型、小窝、浴室与诊所，真实灯光与阴影。可点击模型互动、转动 / 复位视角。
- 3D 泥斑随洗护消失，泡泡、护理工具、食盆和装扮与玩法同步。幼年到成年体型逐步变化。
- 3D / 2D 一键切换，共用原存档；WebGL 不可用时可回到 2D。

默认打开 3D，可用 `/?view=3d` / `/?view=2d` 直接预览对应版本。3D 模型为代码生成的原型美术，不是最终制作的绑定模型或真实毛发。绘本缩略图仍保留原有插画。

第一只猫已救助到家，第二只狗可免费领养。成长阈值为 75 / 180；首次完成每日动作获得成长值，重复照护只恢复状态。晚安需当前宠物饱食至少 60、洁净至少 60、健康至少 75。每次推进一天，所有已领养宠物都会更新状态，获得 60 币。

## 验证

```sh
npm test
npm run build
npx playwright install chromium
npm run test:browser
npm run test:3d
```

浏览器测试要求开发服务器正在 localhost:5173 运行。截图位于 `test-results/`。2D 测试覆盖原有养成流程；3D 测试额外覆盖 WebGL 画布像素、模型点选、视角、清洁分层、成长、场景切换、响应式构图与动画 / 减少动态效果设置。

3D 模型和道具位于 `src/PetWorld.jsx`，无外部模型、贴图和 HDRI 下载。空闲动画约 30fps，像素比最高 1.5，离开可视区域或浏览器后台时停止循环；系统开启减少动态效果时按需渲染。所有宠物和房间 2D 插画为项目内原创 SVG。两套画面均可在后续替换正式游戏美术。
