# Loading 原图拆层

用户授权直接拆附图并接入 Unity Loading 场景。原件 `reference.png` 为261×451；完整SHA-256与原图/图页坐标保存在 `slices.json`。由本批 `derive.py` 使用既有Pillow/NumPy本地提取，未调用付费生成、未使用ComfyUI或新模型，不将放大显示称高清重制。

## 派生内容

- 一张512×512透明元素页，32切片：房子、13个环绕节点（原图相互重叠的两只兔子保留为一组）、2只门边动物、爱心/星星/花朵及加载条元素。
- 一张261×451背景：原图两侧干净纸纹采样修补，以免移动后露出静止动物残影，底部部分光点保留。不是原图完整背景的无损还原。
- 动物以原像素裁切、暗轮廓连通域及外部洪泛提取alpha，轮廓保留浅色贴纸边。兔子组与房子使用记录在脚本中的人工多边形；房子原本被门边动物遮挡的两角作局部墙面修补，不生成新形象。
- Loading标牌清除原烘焙文字，填充条清除原烘焙完成量，由Unity真实进度和动态文字覆盖。运行图与本批坐标一致，不新增相同动物的重复贴图。

## 检查与边界

深浅底边缘图及重组对照输出到 `test-results/loading/extraction/`。低分辨率原图的细线与纸纹上限保留，尚非正式美术或商用许可认可。完整原图仍在Unity外，未伪称用户提供了商业来源证明。

运行路径：`Assets/Art/Loading/T_Loading_Elements.png`、`T_Loading_Background.png`。仅Loading场景静态依赖，进入Main后随Single场景替换释放，不引入全局资源框架。临时首启依赖登记 `temporary/first-play`，微信下载与内存仍需真机测量。
