# 柴犬换色变体（黑柴候选）

2026-11-27。用户要求“做第三只动物并给柴犬加 idle”。本目录是**第三只动物的换色候选素材**，只解决配色，
不改轮廓、姿态、帧序或 alpha；它不是新物种，也不是已验收的美术。

## 产物

| 文件 | 尺寸 / 字节 | 用途 |
| --- | --- | --- |
| `black-shiba/atlas.png` | 1024×640，238,768 字节 | 与 `T_Station_ShibaMotion.png` 同样的 8×5 姿态图集；现场 idle/走动用同一套 UV |
| `black-shiba/standing.png` | 128×128，10,004 字节 | 站内单帧站姿（第 0 帧），供站内 Sprite 使用 |
| `black-shiba/derivation.json` | — | 源哈希、参数、产物哈希；`--check` 用它复核 |

## 做法

`tools/pet-shiba-variant.mjs` 读原图集，逐像素转 HSV；只处理色相 8°–55°、饱和度 > 0.18 的暖色像素
（橘色被毛），保留亮度起伏后压到深炭灰（基准 0.30 + 亮度×0.35），白色胸毛、口鼻和描边不参与。

复核：alpha 与原图逐字节一致（0 个差异像素），RGB 变化 257,969 / 655,360 像素（39.4%）；
尺寸、帧格、朝向不变。`node tools/pet-shiba-variant.mjs --check` 两次生成哈希一致。

## 边界

- 只是**换色皮肤**：同一只柴犬的骨架/序列，不是独立物种，不能当作“第三只品种”验收。
- 未导入 Unity、未接配置/文案/存档、未做站内护理遮罩对齐验证（遮罩按轮廓复用，理论上可直接套）。
- 视觉与许可均未审核；`status` 为 candidate，不进首批、不计正式预算。
