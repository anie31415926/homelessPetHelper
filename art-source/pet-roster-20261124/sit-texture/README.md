# 奶牛猫与柴犬：原图站坐绑图样板

同一个离线烘焙器读取各自的蒙版、站姿关节点、动作关键点及接地参数。纹理来自本批既有清图，动作中没有切换整张图，也没有生图。这里的 JSON 是预览烘焙配置，不等于 Spine 文件或现有 Unity profile。

- **奶牛猫**：采用原图三分之四站姿，保留大头、黑白斑、粉围巾和短腿。头脸基本刚性；围巾以下只在颈部过渡，躯干底层用原胸毛补出围巾后方。
- **柴犬**：采用原三视图侧身，保留奶油胸、立耳和背卷尾；动作继续使用独立犬类关键点，先挪前爪再折后腿。尾巴由胯部锚点带动，卷尾纹理不重画。
- 大腿、小腿、足段使用定长求解，贴图在关节附近连续混合；爪面保持朝向，臀部只在坐稳时做局部接地调整。远侧腿使用原图单独拆出的纹理，但空间运动是二维近似，不是四条腿独立 IK。
- 复用时先锁定站姿身份，再画可变形的重叠区，最后看剪影与深底上的边线。不用缩放整腿来做坐下；图上被遮住的边缘，宁可补同色毛边，不复制出第二条围巾或胸毛外线。

## 复现

如果本机还没有同批清图与 manifest，先按[上一批说明](../README.md)生成，再从仓库根运行：

```powershell
node tools/pet-roster-sit-texture.mjs
npm run assets:check
```

按从左到右的时序检查两张五姿、双底色审阅图。动画 GIF、透明分层 PNG、关键帧及检查 JSON 写入 `test-results/pet-roster-20261124/sit-texture/`，不进 Unity。当前仍是轮廓验证样板：远侧腿和柴犬胸毛切边继续手修后，再考虑接现有角色配置与播放链。素材使用权、Unity、微信和真机未验。
