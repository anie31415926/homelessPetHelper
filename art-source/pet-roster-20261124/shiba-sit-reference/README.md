# 柴犬侧坐结构参考

[并排对照](comparison.jpg)：左为原三视图侧身，中为既有站坐样板末帧，右为本机 ComfyUI 生成的侧坐结构参考。示意排版对齐地线，不是骨点测量或同一角色的像素比例校准。

- 选第一张看坐姿：前腿从胸口近垂直撑住，近侧后腿收在臀前，后脚与圆臀形成清楚的地面接触，而不是让几只爪子挤在空中。尾根留在臀后，保留卷尾。
- 参考图头脸和体型偏写实，不用来换图；原图的大头、短吻、胸毛和卷尾仍是身份锚点。双参考复修图出现另一只眼睛，臀部也没有第一张坐得实，不选为动作目标。
- 下一轮先用站立原图和地面坐标对齐，锁定前爪、臀部支撑和后爪落点，再调中段，暂不重画或绑定参考图。

## 绑图定格

[坐稳定格与骨骼叠图](seat-target.jpg)使用原三视图的侧身贴图。前肢从胸下支撑，后爪收在臀前，臀底贴地，卷尾保持原纹理且不承重；只让近后掌露出，靠上部分在躯干后。近侧后掌和上段共用同一套变形，不用生成参考图换脸。前胸轮廓仍略斜，后爪上方的内线可在过渡阶段继续精修。

只生成末姿，不覆盖已有 GIF 或动作关键帧。运行 `node tools/pet-roster-sit-texture.mjs shiba-seat-target`，输出透明 PNG、叠图、审阅图和带接地栏位的 JSON 到 `test-results/pet-roster-20261124/sit-texture/shiba-seat-target/`。

## 四肢重做参考（当前）

[新版对照](leg-study.jpg)从左到右是原三视图侧身（认角色）、上一版绑图定格（失败对照）、第二次生成的侧坐（只看腿与臀）。三张对齐地线，经过排版缩放，不用来量骨长。旧定格虽通过像素接地检查，但前腿拉着胸毛和胸廓一起斜下去，近侧大腿又几乎被躯干遮完，不再作为动作终点。

- 新参考里，前爪落在肩下，小臂近垂直；近侧后腿能读出圆大腿、折回的跗关节和完整后爪，臀部和爪子同面支撑，卷尾不承重。
- 生成图的头脸、毛色和腿长仍和原图不同，且带少许远侧眼的痕迹，不整张换图。保留原图大头、圆眼、短吻、奶油色胸毛和卷尾。
- 重绑时让胸毛跟胸廓走，近侧前腿由肩到腕独立旋转，只在肩根小范围混合权重；近侧后腿从圆大腿到跗关节、后爪做连续轮廓，只把大腿与腹侧交接的一小段藏进去，不把大腿整体压到躯干后。先用游戏显示尺寸看原图绑出来的静态末姿，再做中段；不要靠缩腿或整图淡入解决。

本机 ComfyUI 使用原侧身裁图锁定身份，早期侧坐图只提供姿态。运行 `node tools/pet-roster-standard-comfy.mjs shiba-seat-legs`，第二张加 `--refine`。两次工作流随目录留存；全尺寸图和执行历史见 `test-results/pet-sit-accepted/standard-stand/shiba-seat-legs/` 及 `shiba-seat-legs-refine/`。本轮只完成参考，不替换动画或 Unity 资源。
