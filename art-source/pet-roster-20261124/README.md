## 形象配置怎么拆

2026-11-24 标准站姿接续：[四张候选对照](standard-stand/review.jpg)，上排奶牛猫、下排柴犬，左初版右定向复修。由身份原图加工程橘猫侧站参考，本机 ComfyUI / Qwen Image 2.1 生成。右上已接近正侧面，但原背斑合并、围巾有长边；右下腿收短一些，但眼睛与吻部仍比原柴犬更写实。暂不绑定这四张，也不覆盖既有猫狗动作试片。工作流和两个输入哈希在 `standard-stand/`；全尺寸 PNG 与 Comfy 作业历史在 `test-results/pet-sit-accepted/standard-stand/`。下一轮优先保住身份而非继续压缩比例。柴犬后续仍沿用独立犬类动作草样。

运行数据仍使用既有 [动物形象配置与制作流程](../../docs/动物形象配置与制作流程.md)；该批的 `roster.json` 用于选素材和追踪工作，不是 runtime profile。各形象至少独立持有身份参考、图集与裁切偏移、骨点、脚底基准、尾根、遮挡、镜头；只在同轮廓与拓扑成立时共用关键帧及绑定，不共用可写资源。

| 形象组 | 先做什么 |
| --- | --- |
| 橘猫 | 既有橘猫坐下作为参照，不覆盖。新的母图与既有侧图不是同像素身份，需人工决定侧身母图，不能直接套旧坐标。 |
| 奶牛猫／布偶猫／狸花猫 | 三视图里的猫侧面多是直立造型，仅参考头脸、围巾与花纹。以四足画面为身份参考，补真正侧面的站立母图，再拆头、躯干、四肢和尾；逐只判断能否复用猫的动作参数。 |
| 柴犬 | 以三视图中间的侧身四足为标定原图，厚颈胸、耳形和背上卷尾保留。先攻克站立→坐下→起身，不借猫的臀尾曲线。 |
| 二哈／伯恩山／泰迪 | 各自独立部件与骨点。二哈卷尾的静态朝向与摆动约束另调；伯恩山垂耳、长毛尾与较重胸臀独立处理；泰迪以侧视图球尾为本批对照，单张里的蓬尾不能直接混进同一身份。 |

建议依次通过「同一侧身母图 → 补遮挡拆件 → 关节与接地标定 → 可见轮廓深浅底对照 → 离线烘焙 → 隔离导入」；独立配置不等于必须复制播放器。狗的前后足步态、坐起轨迹和尾巴控制是不同动作数据；若需要多段软尾、垂耳二级运动或另一视角，再考虑表现模板，避免现在硬改已工作的猫/Unity管线。

## 柴犬骨架草样

- 按用户柴犬三视图的侧身四足剪影标点，保留原侧图作为骨架叠图。参考 [明尼苏达大学兽医学院 Carnivore Anatomy Lab 7](https://vanat.ahc.umn.edu/carnLabs/Lab07/Lab07.html) 的髋、膝和跗关节区分，[AKC 的训练动作示例](https://www.akc.org/expert-advice/training/how-to-teach-your-dog-to-sit/) 仅作坐姿动作参考；未将它们当作关节角度或步态测量资料。
- `dog-shiba-sit-study.json` 保存独立关键姿态、脚点、躯干/跗部角度；鼻向左，Y向下，单位是源图缩至 1000 px 宽后的像素。前足预备、前足落稳、后足收向身下、骨盆下沉、坐稳；卷尾目前只验证尾根跟随，不做尾巴摆动或变形。
- 241 个时点检查前后近侧骨长、躯干长度、可达性、无双足同时离开各自原接地高度、关节连续性以及坐稳定向。输出关键姿态 PNG、31 帧 GIF、验证 JSON。当前仅有侧视近侧骨架，未验远侧四爪承重、臀部/毛发轮廓、贴图、起身和走路，不能当正式动作。
