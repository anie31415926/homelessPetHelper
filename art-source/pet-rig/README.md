- 仅删除与裁切边界连通的近白底色，保留封闭轮廓内的白毛；曲线遮罩隐藏带耳头图/带腿躯干的多余部位。
- 正面头、双耳、尾和腿取front母图，躯干取front-body；侧面头取side，躯干取side-body。
