## 动作与骨骼

- `src/pet-layers/motion.js` 管理确定性采样、四脚相位、走动路径、趴下时序和官方IK调用。每腿沿用40×48连续网格，最多4根归一化权重；近腿的挂点和混权纵向范围同步移回原近腿坐标，不把远腿骨骼直接套上去。
- 使用已有Three.js的官方 `CCDIKSolver`，没有手写新IK求解器或新增包。上/下肢只允许平面Z轴旋转、分前后解剖限幅；以腕/跗为effector求到目标，脚爪反向补偿保持接近平地朝向。每腿含6个原链骨骼加1个目标骨骼。
- 踏步周期1.1秒，支撑阶段占68%，四腿错开四分之一周期；每时刻至少两脚处于支撑目标。支撑目标匀速后移、摆动脚前移抬起，配合身体下沉/轻起伏。前后腿不是两组同时划动。
- 走动在有限范围内来回，路径速度与稳态支撑脚后移速度一致，避免只移动整张猫图；到端点短暂停留后**水平翻转侧面**。这是2D朝向切换，不是连续转身或3D旋转。
- 趴下起身是5.2秒循环：0.4–1.6秒屈腿降身、停留至3.2秒、4.5秒前起身，随后站定。最大身体下降58源像素，脚目标保持各自原纵向接触基准，前脚略前伸、后脚收拢，尾部网格抬弯；不是缩小整猫假装趴卧。
- 头身尾仍在一张同源网格上，用原8根头/耳/尾骨骼；移除身体网格的前腿骨骼权重，脚不再被头身连带拉伸。绘制顺序为远后/远前、头身尾、近后/近前。
- 30fps上限、页面隐藏不推进/不补挂机动作时间，暂停不重复绘制；resize重绘但不重置姿态。所有纹理、几何、共享骨架、helper、observer、事件与RAF有卸载/失败清理。纯动作时钟，不连接游戏事件或存档。

## 仍需观察

原图浅边、近腿贴回身体的局部接缝仍可见，关节大弯曲有压缩；这是动作观感小试验，不是最终蒙皮/自然步态验收。CCD只追腕/跗目标，无完整爪底碰撞、地形适配、动力学或尾巴碰撞。当前镜像换向、动作菜单切换直接回该动作起点，没有连续跨动作混合；头不会从侧面变成正面。

下一步先试玩踏步落脚、近腿根连接和趴下时身体轮廓。认可后再决定优先修毛边/接缝还是加具体互动动作，不自动扩成所有品种、护理遮罩随动、Unity/Spine生产框架。
