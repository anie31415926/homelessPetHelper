2026-11-22。用户授权小院试玩并要求真实身体和场景比例。沿用用户指定的本机ComfyUI，使用现有小院作为画风参考，制作自然比例成年猫狗。工作流、提示、模型、seed、提交与历史分项保存。状态和加载时机以唯一resource-catalog.json为准。
