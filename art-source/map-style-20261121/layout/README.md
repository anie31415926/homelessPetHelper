# 林缘社区布局示意 v1

2026-11-21，按用户“大概示意图”要求绘制。尺寸900×1600，六处地点、救助站、森林、溪水木桥与详情面板均为布局提议，未修改当前运行地图。

- [PNG预览](forest-edge-layout-v1.png)：直接供查看。
- [SVG源图](forest-edge-layout-v1.svg)：可编辑文字、图形与位置；原生形状绘制，没有使用生图模型或拼贴用户参考。

绘制依据为[地图设计](../../../docs/地图美术与地点设计.md)。橙色标记单车棚、小院、门廊三处优先细化，绿色标记其余三处后续细化；颜色只说明制作顺序。森林占地图上部，社区在中下部，桥、溪流及林间路共同指向下一张森林图。救助站独立于六处地点，图中只表达回家方向。

这张图用于评估布局、手机画面密度及地图承接，未模拟水彩纹理，未实现点击或正式UI。图上标注和详情占位不会烘焙进未来游戏底图。示意与参考仅在唯一资源台账按 reference 关联，不作 runtime/candidate，不影响已有首批统计。

导出方式：本机 Windows Node v24.14.1，以现有Playwright启动已安装的Chrome `156.0.8078.80`，将SVG放入无边距HTML，viewport 900×1600、deviceScaleFactor 1，等待 `document.fonts.ready` 后整页截图。字体优先 Microsoft YaHei；PNG不裁切、不放大。SVG是可复查的绘制源，重新导出可在浏览器按原尺寸截图；字体/浏览器版本改变可能改变字形和抗锯齿。

实际检查：36个SVG文字元素均在画布内，人工查看PNG确认中文、六地标与上方衔接标记可见。Playwright默认浏览器缓存不存在，首次导出未完成；切换到已安装Chrome后，一次边界读取使用了不支持的SVGRect方法，随后改为读取x/y/width/height完成导出，未安装浏览器或修改项目依赖。没有Unity运行或微信验证。
