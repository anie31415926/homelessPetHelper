## 本地 ComfyUI

使用本机已有模型，没有下载模型或切换云端服务：

- UNet：`qwen_image_2.1_int8_convrot.safetensors`。
- CLIP：`qwen3vl_8b_int8_convrot.safetensors`；VAE：`qwen_image_2.1_vae_bf16.safetensors`。
- `TextEncodeQwenImage21` 两图编辑：图一是灰色待补区+原后爪引导，图二是原整猫的毛色/解剖参考；同时传入 VAE 参考，不只传文字描述。
- Euler / simple，24 steps，CFG 4，shift 3.1，denoise 1，resolution 768。
- 第一张 seed **2026111911**：引导图的 Sharp 裁切/合成顺序错误，后爪错位，模型也重画了下段。保留在 `ai-completion/`，不用于运行。
- 修正引导后 seed **2026111912**：保存于 `ai-completion-v2/`，当前补图采用此母图。原爪仍被模型改画，因此其下段全部丢弃，不能声称模型自动保持原像素或布局。
- 完整正负提示、节点连接、crop、seed 与历史分别在各目录的 `workflow.json` / `history.json`。提示核心是仅补灰色上段、参照同一猫咪的浅橘白毛色和细暖色轮廓、不加其他身体部件。

生成采用两参考编辑，**不是扩散阶段的 masked inpainting**。`tools/pet-layers-composite.mjs` 在解码后识别暖色腿轮廓、逐行适配到引导区，仅取补图遮罩内 RGB；靠近原后爪的生成侧做 10px 颜色过渡。原可见 RGBA 原样复制，前景不取任何模型像素。确切映射和输入哈希见 `ai-derivation.json`。

隐藏解剖是合理补画，不是找回真实被挡像素；当前轮廓、分区与骨骼仍手工标定，没有自动拆图流水线。
