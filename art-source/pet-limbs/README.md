## 来源和后处理

唯一整猫来源为 `public/pet-mesh/cat-side.png`，452×512、76254 bytes；SHA256 为 `b1889c797e975a625a746ab530a4c7d9231a068ca387871b5306b2fedfd9b727`。其母图和最早生成依据归原 `pet-mesh` / `pet-rig` 记录，本批不重新设计头身、近侧腿或比例。

`tools/pet-limbs-process.mjs` 保存完整轮廓、原可见区和前景切口于 `spec.json` 及各遮罩图。轮廓以4倍采样、面积平均取得抗锯齿 alpha；模型颜色逐行适配回完整肢体轮廓，原可见核心随后逐像素覆盖回去，接近核心的生成侧做10px毛色过渡，并局部修正浅色边缘。不是整图模糊或直接采用模型重画的爪子。

## 复现

已有母图时，只需设置可解析 Sharp 的 `CODEX_NODE_MODULES` 并运行：

```powershell
node tools/pet-limbs-process.mjs
npm run test:pet-limbs
npm run test:pet-limbs:browser
npm run assets:check
```

仅在明确需要重新生成时，先运行 `node tools/pet-limbs-process.mjs --prepare`，启动本地 ComfyUI，再运行 `node tools/pet-limbs-art.mjs`。已有 `master.png` 时脚本保留，不覆盖；要制作新版本应另设批次路径，保留当前母图、实际输入及工作流。当前后处理可独立运行，不必为文档检查重新启动生图。
