# 山谷地图重绘与地标素材

**当前使用**：游戏用[去可见水印的山谷原画](../city-map-valley-20261124/README.md)作底，12 个已接入图标按用户最新参考图排列。下文的 ComfyUI 重绘背景是历史对照，不再运行。

2026-11-24。用户提供山谷底图、地图布局参考和目录内 21 张独立图。来源文件保留在原目录，不上传或覆盖；使用 `source-record.json` 中的原始编号与 SHA-256 追溯。矿洞使用 12 号带矿车版，不再使用 4 号；树屋 6 号只保留一个，71/72 号重复菜园只用 72。最终 19 个不同图标。

## 处理

- 本机 ComfyUI / Qwen Image 2.1 INT8 ConvRot，根据原图重绘山谷背景与三组无字图标。每个作业的 API 工作流、实际 history、提交 ID 与原始输出均在 `comfy/`。既有模型，不安装新节点或权重。
- 采用 ComfyUI 直出的山谷全图，保留山体、左侧河湾、浅色小路与整体构图，树林纹理有重绘差异；不是原图逐像素复刻。用 `derive-terrain.mjs` 导出 704×1024 / 165,704 bytes 的运行 JPEG，没有使用上一版右下角模糊修补。
- 树屋、矿车洞、爱心救助站、菜园、泡泡湖、彩虹桥选用重绘版再抠透明。其余保留原图主体，去外围底纸和可见角标，不用模型重写中文。尤其工厂、花语花园、云朵乐园、糖果山谷、迷雾森林、雪境驿站不猜字、不替换招牌；输出 PNG 使用 256 色调色板压缩。模型有时漏画或更改局部，未采用全部重绘候选。
- `derive-icons.mjs <地图小图标目录> <输出目录> [ComfyUI 母图目录]` 可重做透明件；括号编号与具体重绘选择见源记录。引用原图的派生件保存原始 AIGC XMP，ComfyUI 工作流与来源也留档。可见角标处理不是发行许可或生成内容标识声明，发布前另核验。

## Unity 接入

底图保持原路径、GUID 与导入设置。7 个图标替换 Prefab 原地图节点（保留现有 6 个可点地点和救助站视觉标识）；云朵乐园、蘑菇丘、冻干工厂、泡泡湖、月光湖为 5 个不挡拖动/点击的景观。原地名、详情、配置、事件、关卡及存档不改。其余 7 张整理到 `preview/`，未塞进 Unity 或加入可点地点。

地图图形专项及截图见 `test-results/city-map-icons/`。采用的 12 个 Sprite 是现有 Main 静态依赖，按 temporary / first-play 登记，另外 7 个不计运行包。临时素材仍需视觉、来源许可与目标端审核。
